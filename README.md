# 殖民地综合管理系统

版本：0.1 · 适用《边缘世界》1.6 · 开发测试首发

以总控中心串联人员组织、车间生产、物流运输、库存经济与历史档案。

## 主要功能

- 总控中心：殖民地概况、系统入口及已接入的运行指标。
- 车间管理：班组、班次、倒班、岗位、作息与班中三餐。
- 制造管理：俯视图、设备编排、设备详情、工单信息和产出统计。
- 农业与物流：自动农机、设备储物、传送带和管道运输。
- 库存与经济：财富与库存市值、数量 K 线和分类热力图。
- 人员与档案：职业成长、工时、人物经历、物品流转、战役和地点记录。

## 安装

1. 将“殖民地综合管理系统”文件夹放入游戏 Mods 目录。
2. 先启用 Harmony 与 RUI 界面框架（RUIF 1.3.0 及以上），再启用本模组。
3. 从“总控中心”进入管理界面；记录统一在“人员系统中心”的“档案总览”和“人物档案”中查看。

本模组使用独立工坊条目发布，后续更新沿用该条目。
请勿与旧“殖民地档案馆”同时启用，两者包含重叠的运行类型与资源。

## 当前状态

- 本版为开发测试首发，部分系统入口为预留，部分自动化设备仍采用测试期建造配置。
- 岗位管理会联动相关工作档位和作息；生产仍使用原版工作与工单。
- 库存经济只做观测与记账，新增历史从启用后累积。
- 建议使用新存档；切换旧存档前请备份，迁移尚未完成实机验证。
- 封面为品牌宣传图；About/Screens 中的图片为已有游戏截图。

## 开发版：经济机构首版（2026-10-08）

新增“经济机构”建造分类：劳务站、工坊管理处、工资结算处、生活用品商店和体检中心。通过柜台按钮或“总控中心 → 经济中心 → 经济机构”打开RUIF管理页。旧存档默认关闭，首次手动启用一次性分配1000内部单位，不生成白银。

先配置有生产工单的车间，在工坊管理处发布岗位，再选择搬运者将真实衣物搬进商店。具备衣物改善需求的成年殖民者会在合法自由时段签约、生产赚取计件工资、购买和穿戴。原版相应工作必须已启用，已有手动排班的人员不被自动改派。体检医生需医术4级且医生工作开启；入职体检由公共账户支付，个人预约由本人支付。

此版已通过编译、离线回归及Def接口检查，完整游戏场景仍待实机验收。柜台暂用原版桌子贴图；治疗、培训、住房和配送等后续机构尚未实现。
