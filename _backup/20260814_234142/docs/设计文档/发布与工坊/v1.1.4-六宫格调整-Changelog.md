# Changelog — 人物档案「档案」Tab 六宫格调整

## [v1.1.4] - 2026-08-13

### Added
- **新增「损耗」宫格（替换原「战役」宫格）**：人物日常消耗品（食物/药品/成瘾品等）按物品基价折算银币累计。
  - 大值 = 累计损耗银；同行显示日均损耗（银/天）。
  - KPI 行 = 周损耗（近 7 天）/ 日均损耗（近 30 天均值）。
  - 进度条 = 损耗构成前 3 类目（食物/药品/燃料/成瘾品…），不足 3 类以 `--` 占位。
  - 数据源：进食/用药经 `Thing.Ingested` 捕获点累加，持久化到人物档案，不生成高频事件流。
- **六宫格统一基准**：所有宫格采用「大字 + 同行指标 + 2 行 KPI + 3 条进度条」布局。
- **全宫格默认进度条**：无数据时保持 3 条空进度条占位，空态与有数据布局一致、视觉稳定。
- **进度条等距分布**：第 1 条贴近分割线下方、最后一条贴近卡片底部，各条间隔平均分配。

### Changed
- **产出宫格**：大字下方新增「周产出（近 7 天）/ 净值（近 30 天）」KPI 行；产值贡献进度条固定 3 条。
- **击杀宫格**：猎物种类并入大字同行（如 `4 种`）；KPI 行收敛为「参战战役 / 生涯伤害」2 行；击杀构成进度条固定 3 条。
- **足迹宫格**：KPI 行收敛为「主驻地 / 远征次数」2 行；新增「停留时长前 3 地点」进度条（原 Top2 列表移除）。
- **神器传承宫格**：锻造者移至「神器传承」标题右侧（右对齐小字）；传承链由文本列表改为击杀占比进度条（右侧显示各代击杀数）。
- **进度条文本位置**：说明文字（caption）统一固定在进度条上方；文字与进度条间距扩大。
- **战役数据去向**：colony 级战役数据完整保留，可在完整档案馆「战役」分类查看；击杀宫格「参战战役」指标继续显示个人参战次数。

### Fixed
- 修复击杀宫格有数据时进度条数量不固定导致的布局抖动。

### Compatibility
- 兼容 RimWorld 1.6 + Harmony；纯只读记录，不修改游戏机制。
- 战役数据不删除、存档无需迁移。

### Localization
- 新增翻译键：`Kpi.ConsumeTitle`（损耗 · 累计消耗）、`Kpi.WeekConsume`（周损耗）、`Kpi.DailyConsume`（日均损耗）、`Kpi.DailyAverage`（日均）；中英双语同步。
- 宫格标题/指标文案统一走翻译键，无硬编码中文。

### Performance
- 损耗数据采用持久化累加器（按天桶 + 类目聚合），不写高频事件流，避免存档/事件表膨胀。
