实践考试

报名后需要亲手完成一批指定物品：数量、最低品质与时限见考试任务。一次报名最多制造 上限件数，达标（件数与品质都满足）即通过；超限或超时未达标即失败，可重新报名（每档职称需重新考试）。

理论考试

通过阅读书籍、完成研究、技能成长与理论学习活动积累考试依据，四方面齐备后提交。每档职称需重新提交一次。

论文

选定课题后引用已读书籍与研究成果撰写论文。高级档（Lv3+）每档需独立完成论文与答辩。

答辩

论文完成后召开答辩，同阵营资深同行将组成评审委员会为你的论文打分。
