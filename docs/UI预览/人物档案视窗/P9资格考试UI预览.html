实践考试

报名后需要亲手完成一批指定物品：数量、最低品质与时限见考试任务。只有真正达标（件数与品质都满足）才算通过。

理论考试

通过阅读书籍、完成研究、技能成长与理论学习活动积累考试依据，四方面齐备后即可提交。

论文

选定课题后引用已读书籍与研究成果撰写论文，论文质量由依据的深度决定。

答辩

论文完成后召开答辩，同阵营资深同行将组成评审委员会为你的论文打分。
