        \____◆                    ◆____     ← 切角落在别人行上，像接到母亲卡

  ┌叶日艇┐────────┌尹陟菁┐

2. 同排（夫↔我）：还算能看，但线从中心穿出，不是边对边。

## 方案 A · 边到边直连（星形）— 推荐先做对照

每人一条线，从**我卡边缘**连到**对方卡边缘**，不拐弯。自我网络语义最清楚。

```
  ┌卜救源┐                    ┌和心黎┐
       \                          /
        \                        /
         \     ┌好汇恬┐         /
          \         │          /
           \        │         /
            ┌叶日艇┐─┌尹陟菁┐
```

- 同列：竖直线，上卡底边 ↔ 下卡顶边。
- 同排：横直线，左卡右边 ↔ 右卡左边。
- 对角：斜线，取两卡朝向对方的边中点。
- 线色按关系：配偶鎏金 / 血亲暖金 / 朋友淡蓝 / 已结束暗灰；现行只分 Active 粗细。
- 线先画、卡后画，线不压字。

适合：人数 ≤ 8 的自我网络。不适合：以后要画「母—友」这类第三人边。

## 方案 B · 正交 L，轴对齐时塌成直线（推荐默认）

保留「家谱网格」阅读，只修几何。2 段（先竖后横，或先横后竖），**禁止 45° 切角**。

```
  ┌卜救源┐                    ┌和心黎┐
       │                          │
       │                          │
       └────────┐        ┌────────┘
                │        │
              ┌好汇恬┐   │          ← 母只接我，友的横段在母行之上，不贴母卡
                │        │
                │        │
  ┌叶日艇┐────────┌尹陟菁┐
```

规则：

| 相对位置 | 画法 |
|---|---|
| 同列（Δcol=0） | 一条竖线，边到边，无折 |
| 同排（Δrow=0） | 一条横线，边到边，无折 |
| 对角 | L：从我卡边先走到「不经过第三人卡片」的通道，再折向目标。外圈走「更靠外的那一格」：上侧朋友的横段在 row=-1.5，不要取两中心的 midY |

通道：横段放在两行卡片之间的 gap 中线，不穿过任何卡。

双描边（史诗主题）：先 3px `Border` 再 1.5px `Accent`，金线镶边。哥特主题内层改血红。

适合：现有 GridSlots，改动最小。

## 方案 C · 家谱树（只画亲缘，朋友作卫星）

线只表达「家庭结构」，朋友不进主干。

```
              ┌好汇恬┐ 母
                  │
                  │ 血缘
  ┌叶日艇┐════┌尹陟菁┐     ════ 配偶（双线或更粗）
     夫

     ·  ·  ┌卜救源┐  ┌和心黎┐     · 虚线/细点接到我卡四角，不进主干
           友            （图上有、表上可没有）
```

- 父母：我上边中点 → 母下边中点，单金竖线。
- 配偶：我左边中点 → 夫右边中点，双横线（两条 1px，间距 3px）或 3px 实线。
- 子女：对称向下。
- 朋友/宿敌：不画正交主干；卡仍放外圈，用 1px 虚线（短横间隔）接到我卡角，或只靠位置+左边色条、不连线。
- 线上可写一字标签（夫 / 母），`GameFont.Tiny` + `Accent`，避免只靠猜位置。

适合：截图这种「一家三口 + 两朋友」。改动量中等（按 `SocialRelationTier` 选画法）。

## 方案 D · 无连线，位置 + 色条（保底）

彻底避开 `Widgets.DrawLine` 斜线质量。

```
              ┌好汇恬┐
              ▌母亲

  ┌叶日艇┐    ┌尹陟菁┐    ┌…┐
  ▌丈夫        我（无色条）

  ┌卜救源┐              ┌和心黎┐
  ▌朋友                  ▌…
```

- 卡左侧 3px 色条：配偶金 / 血亲暖 / 友蓝 / 敌红 / 结束灰。
- 关系名已在卡内第二行（缩放够时）；不够进 Tooltip。
- 网格位置仍是家谱。

适合：人多（接近 24）或低缩放。可与 A/B 做成「节点 > N 则降级到 D」。

## 几何铁律（无论哪套）

1. 线的端点是**卡片边中点**，不是中心。同列只连顶/底边，同排只连左/右边。
2. `sx==0` 或 `sy==0` 时禁止切角、禁止折返。
3. 线先画、卡后画。
4. 横竖通道走 row/col **间隙中线**，`midY = (center.y + node.y) / 2` 在有中间节点时会穿卡，外圈必须用「更外一档」的 gap。
5. 颜色走 `UITheme`，禁止 `new Color`。
6. 与表「重要关系」同一数据源更佳（图上有 和心黎、表上没有，是数据源分裂，见 FIX-002 连带）。
