缺口与必需的最小改动（登记，不得静默补齐）

#缺口处置
1岗位 / 凭证 / 报告**未按机构过滤**（BuildJobs/BuildLedger/BuildReports 返回全量）实装结论：岗位改按**政策绑定的车间区**（InstitutionPolicy.ZoneId ↔ EconomyPosition.ZoneId）归属 —— 这是新体系唯一的机构↔岗位关联（旧 InstitutionId 指向已停用的旧模型）；凭证与报告**没有机构字段**，如实标注为全殖民口径（PC_PEA.Workspace.NoInstitutionField），不伪归属
2行高真值依赖引擎（Text.LineHeightOf；Tiny 在「禁用小字体」时静默降级为 Small）落地一律调 Measure.RowHeight()，**不得写死 18/22/30**（Measure.cs:14-18,42-43）
3凭证（EconomyReceipt）**无机构字段**工资结算处窗口的「凭证」只能按「与结算相关」语义取，无法真正按机构归属（EconomyModel.cs:74-81）——如实标注，不伪造成机构流水
4术语双源：Def label（劳务站/工坊管理处/工资结算处）vs Policy.Kind.*（劳务所/车间管理所/结算处）按已批准决策统一为 Def label；改 10 条键值（「劳务所/车间管理所/结算处/商店」→ 与 Def 同词），zh/en 同批
5字体与贴图网页用系统字体近似（B 类降级）；图标用 Def 既有 uiIconPath（PC_PEA_*_north.png 已存在），缺图显示占位而非隐藏
