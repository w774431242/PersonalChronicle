## 0. 这是什么（先读这段）

本集群是**挂在 CodeBuddy 上的「多 agent 工程门禁体系」**：1 个总控 + 6 个专项 Gate agent，配套 **确定性路由 / 合规审计 / 回归测试 / 文档门禁** 四类**可执行脚本**，以及**机器可解析契约**（agent 定义文件里的固定字段）。

它解决的问题不是"写代码"，而是**让 AI 的产出自证合规**：

```text
任务入口（AI-001 声明） → 确定性路由（命中谁） → 派发前置审计（全员合规才准派发）
→ 各 Gate agent 出结论（PASS/BLOCKED/N/A + Evidence） → 总控裁决（P0>P1>…）
→ GATE-DELTA 客观终检（变更标注 ⟷ git diff 双向互含） → 交付
```

**设计要点（也是优化时最容易踩的地方）**：
1. **契约即代码**：agent 定义里的 `ROLE / OWNED_GATES / FORBIDDEN_GATES / TRIGGER_KEYWORDS / NO_TRIGGER / SKILLS` 六行是**机器解析契约**，脚本按行正则读取；改格式 ⇒ 审计与路由同时失效。
2. **唯一真相源**：路由表**不另维护**，直接由 agent 文件的 `TRIGGER_KEYWORDS` 生成；skill 注册表硬编码在**两个脚本**中并要求**双源一致**（`audit-subagents.ps1` 会交叉校验）。
3. **可证伪优先**：所有 Gate 结论必须带 Evidence；没有运行环境时按 Tier A/B/C **降级并如实标"未执行"**，禁止伪造 PASS。
4. **不做第 11 道 Gate**：文档治理（`doc-standard`）与记忆规范（`memory-standard`）是**挂在 `pc-release-clerk` 名下的横切规范**，验收并入既有通道（GATE-DELTA + `doc-guard.ps1`）——10 道 Gate 的归属被 `$expected` 表锁死，新增 Gate 需同步改 7 处。

## 1. 快速上手（3 分钟自检）

```powershell
# ① 集群合规审计（7 agent 结构/契约/要素/触发词/skill 全覆盖）
pwsh -NoProfile -File audit/audit-subagents.ps1 -Blocking
#    期望：结论: PASS  (PASS=7 / BLOCKED=0 / Gate覆盖=10/10 / skill覆盖=9/9)

# ② 路由回归（22 条真实任务用例，防触发词改坏）
pwsh -NoProfile -File audit/route-task.tests.ps1
#    期望：路由回归: PASS=22 / FAIL=0

# ③ 单次确定性路由（看某任务该派给谁）
pwsh -NoProfile -File audit/route-task.ps1 -Task "改 Save schema 加持久化字段并写 Migration"
```

> ⚠ **本包环境的退出码不可靠**：在被导入的沙箱（如 CodeBuddy 工具链）中，PowerShell 子进程退出码**不传播**（实测 `pwsh -Command "exit 2"` 返回 0）。因此：
> **一切判读以 stdout 的判读行为准**（`结论: PASS/BLOCKED`、`路由回归: PASS=n/FAIL=n`、`GATE-DELTA: PASS/BLOCKED`），脚本内的 `exit 2/3` 在真实 shell 下有效，但在沙箱里不可凭 exitCode 判 PASS。

|---|---|---|

| `pc-ui-loc-guard` | UI, LOC | UI State 与领域状态分离、Theme Token、状态完备、全 Keyed 本地化、预览→实机 1:1（LAND） |

## 4. 机器契约（改 agent 前必读）

每个 agent 文件必须含以下**六行契约**（脚本按行正则读取，格式不可改）：

```text
ROLE: ORCHESTRATOR | GATE-AGENT          # 角色
OWNED_GATES: NONE | ARCH | DATA,SAVE | … # 归属（不得与其它 agent 重复）
FORBIDDEN_GATES: <全部 Gate − OWNED>      # 越界禁列（总控为 NONE）
TRIGGER_KEYWORDS: 词1,词2,…               # ≥3 项；全局唯一；不得与自身 NO_TRIGGER 冲突
NO_TRIGGER: 词A,词B                       # ≥1 项；命中即不得调用本 agent
SKILLS: 已登记 skill 名,…                 # ≥1 项；须 ∈ 脚本内 $knownSkills 注册表
```

**硬校验（`audit-subagents.ps1`）**：结构 7 段 · 契约齐备 · 通用要素（`AI-001` / `GOV-012` / `Tier` / `Evidence` / `references/` / `.codebuddy/audit/gate-records/` / `toolchain-registry.md` / `doc-standard`）· 触发词 ≥3 且全局唯一 · skill 注册表覆盖（**注册表里每个 skill 至少被一个 GATE-AGENT 声明，总控"全声明"不算数**）· **双源交叉校验**（`route-task.ps1` 与 `audit-subagents.ps1` 的 `$knownSkills` 必须逐字一致）· 无未登记 agent 文件。

**改注册表 = 四处同步（漏一处不报错、静默漂移）**：
① `audit-subagents.ps1` `$knownSkills` ② `route-task.ps1` `$knownSkills`（①↔② 有机器交叉校验）③ `subagent-audit-checklist.md` §0.3 注册表 + 挂载点清单 ④ 新 skill 自己的「与子 agent 集群联动」节。

## 5. 运行与验证（命令集）

| 目的 | 命令 | 期望 |
|---|---|---|
| 集群合规审计 | `pwsh -NoProfile -File audit/audit-subagents.ps1 -Blocking` | `结论: PASS (PASS=7 / BLOCKED=0 / Gate覆盖=10/10 / skill覆盖=9/9)` + `注册表双源: OK` |
| 路由回归 | `pwsh -NoProfile -File audit/route-task.tests.ps1` | `PASS=22 / FAIL=0` |
| 单次路由（文本） | `pwsh -NoProfile -File audit/route-task.ps1 -Task "<任务描述>"` | 命中 agent 列表 + 命中词证据 + P 级裁决 |
| 单次路由（文件/落盘） | `pwsh -NoProfile -File audit/route-task.ps1 -TaskFile t.txt -JsonOut r.json -Blocking` | JSON；UNROUTED ⇒ exit 3 |
| skill 触发路由 | `pwsh -NoProfile -File audit/route-task.ps1 -Skill summarize` | 该 skill 声明的 agent |
| 文档门禁 | `pwsh -NoProfile -File audit/doc-guard.ps1 -Blocking` | `结论：PASS（新增 n / BLOCKED 0 / WARN 0）` |
| 文档存量检索（DOC-003） | `pwsh -NoProfile -File audit/doc-guard.ps1 -Find <主题词>` | 文件名/内容命中清单 |
| 文档基线刷新（**仅存量收口轮 + 用户确认**） | `pwsh -NoProfile -File audit/doc-guard.ps1 -Rebaseline` | 重写 `doc-baseline.json` |
| GATE-DELTA 终检 | `pwsh -NoProfile -File spec/gate-runner.ps1 -Base HEAD -Annotation <标注.md> -ExcludeFromFile <范围外清单> -Blocking` | `GATE-DELTA: PASS — 标注覆盖 N 个改动文件，无遗漏/超范围/残留` |

**GATE-DELTA 三个实战坑（本包内已踩过并留档）**：
1. 标注 front matter **只认** `- path: <相对路径>`（可随行 `type: A|M|D`）；写成 `- <路径>` 不识别（会退化去扫表格首列）。
2. **git 忽略区**（如本工程 `.codebuddy/**`、`_scripts/**`）的文件**不能写进 front matter**（判 phantom）⇒ 只能写进标注 body 逐项登记。
3. 范围外清单必须用 `git status --porcelain -uall` **逐文件**生成（未跟踪目录聚合条目会前缀排除整目录，反把已声明文件判 phantom）；且**标注不得声明自身**（脚本会主动移除标注文件）。

## 6. 如何扩展（加 agent / 加 skill / 加触发词）

**加 skill（最小路径）**：
1. 建 `<skill>/SKILL.md`（含「与子 agent 集群联动」节，写明归属 agent 与产物边界）；
2. 在**四个位置**登记：两处 `$knownSkills`、`checklist §0.3` 注册表、挂载点清单；
3. 在**至少一个 GATE-AGENT** 的 `SKILLS:` 行声明；
4. 跑 `audit-subagents.ps1 -Blocking` + `route-task.tests.ps1`，并在后者补 1 条 `S1/<skill>` 用例。

**加 agent**：需改 5 处 —— 文件新增 + `$expected` 映射 + `$gateRules`（Gate→规则 ID）+ `checklist §0` 预期映射表 + `route-task.tests.ps1`；且 `OWNED_GATES`/`FORBIDDEN_GATES` 必须保持**互补且不重叠**（脚本强校验）。**新增第 11 道 Gate 属规范级变更**（波及 `$allGates`、全部 FORBIDDEN 互补、P 级裁决表），不要顺手做。

**加触发词**：≥3、全局唯一、与 NO_TRIGGER 不冲突；改完**必须**重跑审计 + 回归（脚本会校验全局唯一性）。

## 7. 已知限制与优化切入点（**接手优化从这里开始**）

| O3 | **注册表四处人工同步**（③④ 无机检） | 静默漂移 | 给 checklist/挂载点做机器校验（例如扫描 skill 目录比对注册表） |
| O4 | **路由为词匹配**：同义改述不命中 | 漏路由静默发生 | 引入同义词表/向量召回；或保留词表 + 让 orchestrator 做语义兜底（现行方案） |
| O5 | **无 Gate 结论的机器 schema**：Gate Record 是自由 markdown | 难以自动汇总/统计 | 定义 Gate Record JSON schema，让各 agent 产出结构化结果 |
| O6 | **doc-guard 的 C5 相似度保守**（2-gram Jaccard ≥0.62，仅 WARN） | 改名搬运式重复漏报 | 引入标题+内容双通道相似度；或接入 embedding |
| O7 | **git 忽略区盲区**：`.codebuddy/**` 不被 git/gate-runner 覆盖 | 治理资产改动只能靠 body 说明 + 实测证据 | 将治理资产纳入 git（或独立备份仓库）；扩展 gate-runner 支持忽略区哈希清单 |
| O8 | **基线刷新靠纪律**（`-Rebaseline` 即放行） | 存在绕过风险 | 给基线加"刷新需附用户确认字符串/时间戳签名"的软约束 |

| O10 | **Gate agent 无写权限**（tools 只读 + execute） | 结论与落盘分离（主 Agent 落盘） | 可评估放开受限写权限，但会引入"自证"风险，需权衡 |
