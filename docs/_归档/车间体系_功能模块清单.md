## 3. 三条主链

```
① 归属与统计
Zone_Workshop.cells/ownedCells → WorkshopZoneUtility.WorkshopAt → WorkshopStats.ScanDevices
  → 管理面板设备页/配方页/农业页 + 俯视图 BuildBay

② 加成
zone.WorkshopType → NotifyDutyStarted → WorkshopBonusResolver.Resolve → bonusCache
  → StatPart_Workshop{WorkSpeed,Product,Research} + Patch_GenRecipe + Building_ConveyorSegment
  → ratingOffset → WorkshopRatingShift → ProfessionalBonusView

③ 排班调度
slots / shifts / rotations → RebuildDutyPlan（固定班 > 班组 > 轮岗）→ dutyPlan
  → WorkGiver_Workshop（NonScanJob）→ JobDriver_WorkshopDuty → NotifyDutyStarted（触发②）
  → FailOn(IsScheduledForDuty) 收工 → WorkTimeSample 上报
```
