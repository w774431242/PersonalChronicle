## [v1.2.0] - 2026-09-03

### Changed
- 职业推荐算法重构为「**内在禀赋主导 + 行为佐证**」六维模型：
  `Fit = 原版等级 0.40 + 背景加成 0.15 + 特性加成 0.15 + 热情 0.10 + 实践 0.12 + 品质 0.08`。
- 推荐现以 pawn **背景**（`BackstoryDef.skillGains`）、**特性**（`Trait.CurrentData.skillGains`）、技能等级/热情为核心——即使当前等级低，只要天生适合（如艺术背景 + 艺术特性），也能被正确推荐，符合玩家直觉。
- 删除原「成长潜力」假数据维度（避免 passion 双重计入）。
- 基础分曲线由 `(1−(1−L/20)^1.6)` 调整为 `^1.15`：高等级人物得分差距拉大，不再被同压缩抹平。
- 背景/特性加成归一 `AptitudeNorm(a)=clamp(50 + a×6.25, 0, 100)`（a=0 中性 50，±8 → 0~100）。

### Fixed
- 修复实践维度键空间断裂（P0）：`practiceCountBySkill` 的职业技能键（`ProfessionalSkill_*`）经 `ProfessionalSkillDef.sourceSkills` 映射回原版技能键，实践维度首次真实影响适配分；旧档 `CareerEvent` 聚合改为「映射为空才回退」，消除双重计数。
- 修复内置权重矩阵 4 处 `Medical`→`Medicine` 错键（原版无 `Medical` defName）。
- 修复品质维度全局串味：改为按 `SkillDefName` 分技能归集（`QualityBySkill`）+ 全局回退。
- 新增禁用技能（`SkillRecord.TotallyDisabled`）处理：等级/热情/加成一律按 0 计。

### Compatibility
