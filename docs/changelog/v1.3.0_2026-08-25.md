# Personal Chronicle · v1.3.0 更新日志
> 2026-08-25 · 档案总览大更新：工坊管理 + 死亡档案自动归档 + 原版房间名覆盖 + CE 性能修复

---

## 🆕 新功能

### 档案总览 · 死亡档案筛选与自动归档
- **档案总览页面新增人物筛选栏**：「全部 / 在世 / 已死亡 / 已归档」四个标签，快速过滤人物列表
- **低价值死亡档案自动归档**：已死亡的殖民者/囚犯档案会按价值自动评估——有故事的人（勋章、职称、社交关系丰富）永久保留；路人级档案标记归档，**默认 30 天后自动销毁**释放存档空间
- **Mod 设置新增「自动归档」配置区**：
  - 开关：启用/禁用自动归档
  - 价值阈值滑块（银币单位，默认 200）：低于此值的死亡档案进入归档倒计时
  - 保留天数滑块（默认 30 天）：归档后保留多久再销毁

## 🔧 工坊房间管理（大幅增强）

### 工坊弹窗重做（方案 B · 双列图标网格）
- **全新双列布局**：左侧信息区（房间名 + 当前✓标记 + Top3 设备）+ 右侧图标按钮列（改名 ✎ / 定位 ⊕ / 设为当前 ✓）
- **Top3 设备展示**：副行显示该房间使用最频繁的前 3 台设备及其次数（如「锻造台 12 · 炉灶 5 · 屠宰台 2」）
- **改名改的是房间名**：✎ 按钮现在修改工作房间的自定义名称（如「中央厨房」），而非单台设备名；名称在 mod UI 和原版房间信息面板同步显示

### 原版房间名覆盖（Harmony Patch）
- **住所/工坊改名后，RimWorld 原版房间信息面板也会显示你的自定义名**
- 之前只改了 mod 内部显示，原版右键→房间信息仍显示「厨房」「卧室」等默认名 → 现已修复
- 同时支持建筑别名覆盖到原版 UI（`Thing.Label`）

### 工坊交互优化
- **右键工坊卡 = 镜头跳转**到该工坊坐标（之前误触发了弹窗）
- **左键工坊卡 = 弹出「全部工作房间」列表**
- **同房间去重**：同一房间的多台制作台不再重复列出（之前厨房里有 2 台设备就会显示 2 条「厨房」）

## ⚡ 性能修复

### CE（Combat Extended）袭击刷屏卡顿根治
- **问题**：CE 袭击来袭时大量敌人每 tick 获得 0.0x 经验，导致职业 XP 采集链和日志爆炸，10 波后几乎卡死
- **修复**：
  - 非殖民地人口（袭击者/友军/动物）的经验采集直接跳过
  - 微量经验（< 0.05）不再触发职业 XP 计算
  - DevMode 调试日志块完全移除（发布版不应有任何调试输出）
- **结果**：CE 高并发场景下该调用链彻底静默、零日志 IO，性能问题根治

## 🛠️ 内部改进

- **开发者手册**：新增 `docs/参考清单/开发手册.md`，面向开源/二次开发的完整技术文档（分层架构、数据流、扩展点、贡献指南）
- **发布流程固化**：修正了开发区与游戏加载目录的路径约定，避免"改了代码但游戏跑旧 dll"的陷阱
- **Harmony Patch 可访问性铁律**：所有 `[HarmonyPatch]` 类必须为 `public`（之前 `internal` 的 patch 类被 Harmony 静默跳过且无报错——这是最难排查的一类 bug）
