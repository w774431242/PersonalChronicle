# Personal Chronicle · v1.3.1 更新日志
> 2026-08-30 · 属性面板 tooltip 结构透明化（遵循《开发铁律》第七节）

## 🔧 属性面板 tooltip 透明化

### 浮层结构对齐原版 stat tooltip
- **展示全部结构因子**：悬停属性面板字段（如「全局工作效率」）时，浮层现在列出与原版 stat tooltip 等价的完整结构行——文化 / 光照 / 年龄 / Isekai INT / Isekai Level / mod StatPart 等，不再只显示「基础值 + 主因子 + 最终值」。
- **零贡献因子不再省略**：此前 `ApplyParts` 会跳过贡献接近零的 part（如光照 ×100%、文化），现按《开发铁律》7.1 保留，显示为 **×1.00 / 0%**，作为结构透明的一部分。
- **保留原版层级缩进**：原版 `ExplanationPart` 中 `"  Isekai Level 4"` 是 `"Isekai INT"` 的子项，浮层通过 `BreakdownRow.IndentLevel` 保留缩进层级（铁律 7.3）。
- **顶部展示字段说明**：浮层标题与基础值之间新增 `StatDef.description`（如「做任何类型工作时的速度乘数。」）。

### 标签本地化清洗（铁律 7.2）
- `CleanLabel` 改为**保留括号内关键参数**（光照百分比、技能等级等），仅剥离尾部的「乘数 / multiplier / factor / 系数」等无信息词。
- 例：`光照 (79%) 乘数: x100%` → `光照 (79%)`；`Isekai INT (5): x1.00` → `Isekai INT (5)`；`文化: -4%` → `文化`。
- 清洗失败时回退到 part 类型名，避免空标签。

## 🛠️ 内部改进
- **新增《开发铁律》第七节「属性浮层（Tooltip）透明铁律」**（7.1~7.5）：明确定义浮层必须展示完整结构、数据来源走原版 StatPart 管线、层级缩进、零贡献降噪、代码落地位置。
- **数据模型**：`StatBreakdown.Description` + `BreakdownRow.IndentLevel`。
- **构建器 `StatBreakdownBuilder`**：`ApplyParts` 不再因 `cur≈before` 跳过 part；`Build` 注入 `StatDef.description`；新增 `CountLeadingSpaces` 提取原版缩进。
- **绘制层 `ITab_Pawn_Career.Breakdown`**：新增描述行绘制、明细行叠加 `IndentLevel` 缩进、宽度/高度预算同步纳入缩进与描述。
