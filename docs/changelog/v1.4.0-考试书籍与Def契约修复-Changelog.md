## [v1.4.0] - 2026-09-01

### Fixed
- 修复考试书籍无法当书用的问题：52 个考试书籍 Def 由普通物件改为真正的「书」（`thingClass=Book` 并补齐品质与阅读组件、归入 Books 类别），现在可放入书架、右键阅读，阅读产生的技能经验接入职业成长；论文「引用书籍」也恢复按品质加权。
- 修复资格体系在主方向下整体匹配不到的问题（FIX-005）：补 `majorKey` 后，论文按方向解析与按主方向过滤资格恢复，Senior/Specialist/Master 三档不再锁死。
- 修复实践考试品质门槛恒失败、实践分恒为 0 的问题（FIX-006）：实践考试道具补品质组件后，`MinQuality="Excellent"` 门槛可达，达成设计语义。
- 修复 17 个物品在存储设置中不可见的问题（FIX-007）：归入既有物品分类后，存储区可按类别勾选收纳。

### Compatibility
- 兼容 RimWorld 1.6 + Harmony；本次为纯 XML 修复，不修改游戏机制，不影响既有存档读取。

### Localization
- 中文 `DefInjected/ThingDef/ExamThings.xml` 按 defName 注入，defName 与英文原文均保留，翻译零影响。

### Migration
- 无需 Save 迁移。仅 Def 默认值变化（考试书籍 `stackLimit` 由 10 调整为 1）：旧存档中已堆叠的考试书籍会处于 `stackCount > limit` 状态（一般不崩，行为可能异常），建议用新存档验收，或先消耗 / 丢弃旧书规避。
