## [v1.4.0] - 2026-08-31

**Mod 版本：** v1.4.0  
**RimWorld：** 1.6  
**DLC：** 无硬依赖（原有 Ideology/Biotech StatPart 条件加载不变）  
**Harmony：** 必需（`brrainz.harmony`）  
**Save 兼容：** 兼容 v1.3.x 存档，无需迁移  
**API 契约：** `ApiVersion` 仍为 1.2.0（本次不扩展公共 Provider）

上一稳定版本：v1.3.1（2026-08-30）

### Added
- 职业档案增加「显示称号」选择：殖民者条、地图名牌、档案身份只展示一个称号，不再把职称与勋章叠成两行。
- 12 个一级专业下的二级方向技能与数值效果落地：选定主修后，该方向声明的原版 Stat（采矿速度、研究速度、收获效率等）获得常驻加成。
- 考试 / 论文 / 实践套件等物品与配方补齐中英标签，检视面板不再显示翻译键。
- 开发者模式「全量覆盖灌满」与覆盖自检：一次填满已归档人物的职业技能、主方向、工时/产出账本与亲缘关系，并弹出覆盖率报告。

### Changed
- 常驻职业属性加成只取**当前主修方向**的技能，不再把已练习的全部专业技能叠到「全局工作效率」等无关字段上。
- 数值加成按专业等级成长：`XML value × (等级 / 满级) × (1 + 评级权重)`。手册中的方向数值视为满级上限，低等级不再吃满值。
- 属性面板按原版 Stat 的数量语义格式化（效率类为百分比，搬运为千克，近战 DPS 为绝对数值），卡片过长时自动缩小字号。
- 社会关系网络改为家谱树、只画亲属；重要关系表「在世」与图中人物集合对齐。

### Fixed
- 修复开发者灌满后社交关系覆盖停在约 75% 的问题（图外人物、单人图、非自由殖民者不再被跳过）。
- 修复属性面板「研究速度」空白、「综合健康分 / 估值银币」被裁成省略号。
- 修复主修矿业时「全局工作效率」仍出现职业 +4% 的泄漏。
- 修复主修方向加成为固定 XML 值、不随等级变化。
- 修复顶栏称号与档案身份卡不一致（选定方向 vs 推荐方向 vs 已授职称）。
- 修复健康残值事件把缺译键变成变音乱码，并把饥饿等瞬时 Hediff 误标成永久旧伤（FIX-001）。
- 修复社会关系连线出现菱角/接到第三人，以及归档活人「在世」被涂成死亡色（FIX-002 / FIX-003）。
- 修复防御类翻译占位符残留、考试物品 `MakeThing` 缺材料崩溃、Dev 灌满不写职业等级与账本等测试通路问题。

### Localization
- 新增显示称号、选定/推荐主方向等 Keyed 键（简中 / English）。
- 考试物品与配方改为 Def 英文标签 + `DefInjected`，不再把 Keyed 键写进 `<label>`。
- 健康估值事件：有 Keyed 才翻译，否则回退 `HediffDef.LabelCap`，禁止用「译文是否等于原键」判断。

### Compatibility
- 仅 RimWorld 1.6 + Harmony。未改第三方 Def，未新增硬依赖。
- 职业加成仍通过原版 `StatDef.parts` 注入；目标 Mod 不存在时对应 Stat 不出现，不影响基础档案。

### Migration
- 旧存档直接加载，无需转换。
- 职业加成不写入存档，读档后按当前主修方向与等级即时计算。若曾用开发者灌满把 48 项技能全部升级，面板上只会显示**当前选定方向**对应的字段与满级比例值。
- 显示称号：未选择时行为与 v1.3.1 自动解析一致；选择后只显示该项。

### 回滚
- 触发：主修方向加成范围或数值与设计手册严重不符，且无法用「仅主修 + 按级成长」解释。
- 做法：用 v1.3.1 发布 dll 替换；存档双向可开。回滚后职业加成恢复为「未按方向过滤、未按级缩放」的旧行为。
- 可选兼容：关闭开发者自检开关即可隐藏覆盖报告，不影响游玩。

### 已知问题
- 工坊房间、住所等依赖真实游玩流程的维度，灌满工具不会伪造为「全覆盖」；覆盖报告中的空缺在未真实使用前是预期状态。
- 智力完全禁用的殖民者，「研究速度」显示理论值而非原版隐藏，便于确认字段已接通。
- 第三方 `HugsLibChecker` 缺方法、以及无关 Mod 的 XML 报错，不属于本版本范围。
