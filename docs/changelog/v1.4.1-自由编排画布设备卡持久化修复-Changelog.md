- Mod 版本：v1.4.1（上版 v1.4.0）
- RimWorld 版本范围：1.6
- DLC 范围：无强制要求
- Harmony/框架范围：brrainz.harmony（必需）、PersonalChronicle.RUIFramework（必需，≥1.2.0）
- 硬依赖与软依赖：无新增

## [v1.4.1] - 2026-10-02

用户报告的两个现象：① 非编排（查看）模式无法从设备库把设备放置到画布；② 设备卡「保存不住」。

### Fixed — 现象② 设备卡保存不住（P0）
- **P0-1 空清单删档**：`MirrorDetachedToSave` 原本做「档里有、清单上没有 ⇒ 删档」的差集删除。
  内存清单会被关窗清空且一度无法重读，于是**关窗 / 撤销 / 清空画布**任一动作都会把玩家摆好的设备布局整体抹掉且不可回滚。
  现在差集删除**已移除**，删除只允许由显式用户动作驱动（单卡 ×、「清空画布」）；未成功加载存档时禁止任何删除写入。
- **P0-2 重开窗口不重读**：`MainButtonDef.TabWindow` 是缓存单例，切标签只走 `WindowStack.TryRemove → PreClose`、**不销毁实例**
  （Cecil 取证），而原实现的「每档只读一次」闩锁永不复位 ⇒ 切走标签再回来时设备清单已被 `ClearSession` 清空且不重读 ⇒ 画布空白（存档仍有数据）。
  现在 `ClearSession` 置位 `detachedReloadPending`，并把会话作用域键升级为 **(Game, Map) 复合键**（同局换地图也重读）。
- **P0-3 撤销 = 全量删档**：读档只填已放置列表、撤销快照恒空，而撤销门禁是 `UndoOrder>0 || PlacedOrder>0` ⇒ 点一次撤销即清空全部布局并删档，
  且此后两个门禁同时关闭、无法回滚。现在改为**显式 `UndoValid` 有效位**（只有真正拍过快照才为真），读档后立即建立基线快照，两处门禁统一为 `CanUndo`。
- **P0-4 视图与存档口径分裂**：Save 结构预览只列车间块、`entries` 不数设备卡 ⇒ 玩家放完设备仍看到「entries: 0」，被误读成「根本没存」。
  现在两个持久化容器（`mfgLayout` / `mfgDeviceLayout`）都如实列出；编排条悬停复用同一份明细。

### Fixed — 现象① 画布放置不可用（P1）
- **P1-1 设备卡三态全无拖动命中**：已放置的设备卡放下即固定，且没有单卡收回入口（只能一次清空整块画布）。
  现在设备卡可拖动改位（车间内的卡第一次拖动即转为独立摆放），编排态点卡左上角 × 收回；单次放置也进入撤销快照。
- **P1-2 隐形拖拽热区**：车间块拖拽命中区原本是「不绘制任何视觉」的 200×120 锚点框 ⇒ 空白处点一下就误拖车间。改为该车间**实际设备卡的并集**。
- **P1-3 下标即身份**：`PlacedOrder` 存托盘下标，而托盘来自 `AllWorkshops`（`zoneManager.AllZones` 原始序、**无排序**）⇒ 增删车间后下标位移，
  存档坐标会写到别的车间、并把原车间判为「已收回」删档。现在内存侧与存档侧对齐，统一按 **ZoneId** 承载与读写。
- **P1-4 画布外仍可命中**：卡片只用 `Overlaps` 过滤**绘制**，却把未裁剪的矩形交给悬停/点击/tooltip ⇒ 画布外不可见区域仍可点中并误弹详情。命中矩形改为 `卡 ∩ 视口`。
- **P1-5 同局换地图不清会话**：见 P0-2 的复合作用域键。
- **P1-6 节流时钟可被回拨冻结**：2 秒节流窗口用 `DateTime.UtcNow.Ticks` 做差值 ⇒ 系统时钟回拨 / 夏令时会让 `rescan` 永远为假，设备库与画布设备**永久停更**且无报错。
  改用单调时钟（`Stopwatch`）；并修复「窗口内新增的车间 cache miss ⇒ `Devices = null` ⇒ 该车间整体消失」，改为就地重扫该车间。
- **P1-7 放置零反馈 / 入口不可发现**：设备库是隐藏页签、视口窄时整条轨道静默消失、放置后无任何提示、空态文案教用户做三件当前做不到的事。
  现在补**点选 → 点画布**的等价放置路径（两态可用）、`#lbar` 状态提示行、按模式区分的空态文案、轨道隐藏提示条。
- **P1-9 页签溢出静默截断**：底栏第 7 个页签「编排」是唯一的托盘入口，原实现放不下就 `break` ⇒ 窄窗口下不可达。改为等比压缩 + 行尾「+N」明示。
- **P1-10 编排页签禁用页内滚动**：画布用 `Event.current.mousePosition` 做命中与落点换算，`BeginScrollView` 会平移坐标系 ⇒ 三者不同源。
- **P1-11 宽轨侵入画布**：轨道可拉到 360 而画布让位固定 136 ⇒ 宽轨盖住画布最多 224px，落点判定与轨道行错配。轨道宽上限现与视口联动。
- **P1-12 大列表静默截断**：设备库超容量直接截断（玩家以为只有几台设备）⇒ 现在底部明示「还有 N 台未显示」。
- **P1-8 轨道会话态跨档残留**：左轨页签选中 / 轨道宽 / 拖拽把手此前**无任何清理点** ⇒ 关窗时统一复位。
- 修正坐标系混用：ghost 首帧、缩放行光标读数、设备落点原本分别用两套鼠标坐标（`UI.MousePositionOnUIInverted` 与 `Event.current.mousePosition`）⇒ 统一为 GUI 空间并收敛到单一换算点。

### Fixed — Localization
- `Floor.Lbar.SaveTip` 键含 `{0}` 却走**无参** `Translate` ⇒ 悬停恒显示字面量 `{0}`（该键已删除，改为复用 Save 明细）。
- 空态提示按模式拆为 3 键（原键在所有上下文都指向不可达操作）。
- 删除 4 个零引用孤儿键：`Layout.EmptyHint`、`Layout.CardDevices`、`Layout.CardNoDevice`、`Floor.Lbar.SaveTip`。

### Changed
- `CanvasState.PlacedOrder`（托盘下标）→ `PlacedOrder` 重命名为 `PlacedZoneIds`（ZoneId）；`ClearAll` 现在同时删除存档里的设备条目（显式动作）。
- 轨道宽度上限由固定 360 改为 `min(360, 视口宽 × 0.5)`。

### Migration
- **无 Save 迁移**。`mfgLayout` / `mfgDeviceLayout` 均为加性可选字段，旧档读回 `null` 时回落空列表（SAVE-003 向后兼容），`SchemaVersion` 不需 bump。
- **旧档提示**：若旧档里已有 `mfgDeviceLayout` 条目，在旧版本中因撤销 / 二次关窗被差集删除过的，本版本无法自动找回（数据已不在存档里）；未被删的条目本版本会正常读回并显示。

### 已知限制（如实登记）
- 车间内设备的默认位置仍按**区内序号**推算（设备增删后同区卡片会位移）；只有手动摆放过的设备卡按 `stableId` 稳定定位。
- 设备卡与车间块的 `schemaVersion` 仍为显示用常量 `1`，未与 `ChronicleGameComponent.SchemaVersion` 绑定（字段级版本 gate 属后续批）。
- **未执行实机验证**：本轮为静态修复 + 编译验证（0 错 0 警），沙箱无法启动游戏进程。切标签 / 换地图 / 存读档 / 拖放 / 撤销 五条路径需在游戏内核对。
