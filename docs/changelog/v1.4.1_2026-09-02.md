## Change Summary
- Title: 职业档案总览 RPG 面板「主修方向」明确标注 XP 来源工作与数字加成

## [v1.4.1] - 2026-09-02

**Mod 版本：** v1.4.1
**RimWorld：** 1.6
**DLC：** 无硬依赖
**Harmony：** 必需（brrainz.harmony）
**Save 兼容：** 兼容 v1.4.0 存档，无需迁移
**API 契约：** ApiVersion 仍为 1.2.0（本次不扩展公共 Provider）

上一稳定版本：v1.4.0（2026-09-01）

### Added
- 职业档案-总览 RPG 面板的「主修方向」区块新增两行明确信息：
  - **获取经验：W1 · W2 · W3** —— 明确标注当前主修方向需要做哪些具体工作来累积专业 XP（取该方向技能关联的源技能 / 实践工作类型 / 配方名，最多 3 项）。
  - **主修加成：速度 +X% · 品质 +Y▲** —— 一行显示该主修方向在满级时的数字加成（速度 % 与品质档），缺类字段显示"—"而非误导性的 0%/+0▲。
- 新增 Keyed：`Major.XpWorks`（获取经验）、`Major.Bonus`（主修加成），简中 / English 同步。

### Changed
- 专业成长蓝图（XP 来源 chip 链 + 4 档评级阶梯表）改为只消费 Read Model 快照（GOV-006 单一真源），与运行时 `direction.skillDefNames[0]` 解析路径完全对齐；评级表缺类诚实显示"—"。
- 主修方向身份块（职称 / 专业等级 / 评级名）下沉到 Read Model 快照，窗口内不再下挖 Domain 状态，消除渲染态与数据态漂移。
- 未配置专业技能的方向在蓝图区显示「暂未配置专业技能（数据缺漏）」提示行，不再折叠隐藏或误显 0% 加成。

### Fixed
- 修复 36/48 二级方向（其引用的技能 Def 未在 DefDatabase 中定义）在蓝图区显示空卡 / 误导 0% 加成的问题：现按运行时真实路径解析，并对数据缺漏做可见化降级（提示行 + 诚实缺类），不崩溃、不误导。

### Localization
- 新增主修方向 XP 来源 / 数字加成标签键（简中 / English）。

### Compatibility
- 仅 RimWorld 1.6 + Harmony。未改第三方 Def，未新增硬依赖。
- 职业加成仍通过原版 StatDef.parts 注入；本改动仅影响档案总览 UI 呈现。

### Migration
- 旧存档直接加载，无需转换。职业加成不写入存档，读档后按当前主修方向与等级即时计算。
