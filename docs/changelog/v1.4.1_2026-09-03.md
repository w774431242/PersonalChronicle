## [v1.4.1-docs] - 2026-09-03

### Added
- **第二节「各方向真实 effect 清单」重构为四档表**：列改为 `第1档·熟练 / 第2档·专业 / 第3档·高级 / 第4档·大师`（对应 `effectDefNames` 声明顺序的档位口径），值逐条与 `Defs/ProfessionalSkills.MajorBonuses.xml` 一致。
- **新增第四节「字段加成差异化方案（提案）」**：
  - 为全部 48 个方向补设计**大师档（第 4 条，value=0.10，满级 max=+11%）**；
  - 重心规则：**第 3 档(0.09)+第 4 档(0.10)=方向专属字段，占四档总权重 ≈61%**；通用字段（全局工作/全局劳动/移动/携带，表中标 `(通)`）只作第 1/2 档保底；
  - 大师档=方向主字段，**同专业内 4 个方向主字段互不相同**（如医疗：治疗质量/手术成功率/药物烹饪/免疫速度；研究：冥想专注/研究速度/全局学习/社交影响）；
  - 字段池不足的专业（制造/工程/管理）表头注明降级与专属前移位置；
  - 附落地步骤：新增 48 个 `*_Master` effectDef → 各方向 `effectDefNames` 追加第 4 项 → 回填基线表 → 跑 Resolver 单测（Resolver 无需改动）。

### Changed
- 第一节机制说明澄清：`ProfessionalRatingDef` 四档（熟练/专业/高级/大师）只提供 `ratingWeight`/`qualityBiasWeight` 倍率，**不门控 effect**——Resolver 遍历 `effectDefNames` 全部自 Lv≥1 同时生效；「第 N 项=第 N 档解锁」仅为声明顺序约定（展示口径）。
- 差异化提案中武器系档位值归一为 0.05/0.07/0.09/0.10（取消原 0.06/0.08 特例）。

### Fixed（文档纠错）
- **回滚上一轮对账引入的 10 处 value 误改**：经逐行重读 `MajorBonuses.xml` 核验，军械/装备/工业制造效果2、结构/动力/控制/精密工程效果2、选矿效果2 的 value 实为 **0.07**，实验/应用研究效果3 实为 **0.09**——上一轮将其误判为"漂移"并改成 +5，本次已全部恢复 XML 真值。
- 差异化提案初版误用了 **Thing/Building 黑名单字段**（`WorkTableWorkSpeedFactor` / `WorkTableEfficiencyFactor` / `MedicalPotency`，加在 pawn 上完全无效）及非 pawn 归属字段（`AnimalGatherYield` / `ForagedNutritionPerDay` / `FoodPoisonChance`），已全部替换为 pawn 可读字段，并将 pawn 可读性红线写入设计原则。
