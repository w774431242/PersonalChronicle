## [开发线] 2026-09-18

### Added

#### Def（4 类 + 实例）
- **`MVSCommodityDef : Def`（18 品种）** —— 三轴命中（`thingDefs` / `thingCategories` 含后代 / `stuffCategories`）+ 两重排除（`excludedThingDefs` / `excludedCategories`），**同形原版 `StockGenerator_Category`**。覆盖 261 ThingDef。
  - ⚠ **品种数为 18（非方案的 17）**：因 DLC 归属拆分 —— `Artifacts`（**Core**）与 `InertRelics`（**Ideology**）不可是同一 Def 挂同一 `MayRequire`，否则无 Ideology 玩家会连带丢失 Core 的 `Artifacts`。
- **`MVSIncidentImpactDef : DefModExtension`（挂 `IncidentDef.modExtensions`）** —— 事件→经济冲击白名单。⚠ 必须继承 `DefModExtension`（`GetModExtension<T>` 有此约束，继承 `Def` 编译即 CS0311）；因此**不是独立 Def、无自有 DefInjected 目录**，文案走 Keyed `MVS.Inv.Category.*`。
- **`MVSFlowEdgeDef : Def`** —— 上下游流向边（第三方可加），支撑库存结构图。
- **`FactionEconomyExtension : DefModExtension`（挂 `FactionDef.modExtensions`）** —— 派系画像：`techTierOverride`（可空枚举改 `bool has + enum` 安全写法，因原版 Def 加载器不认 `Nullable<enum>`，XML 写值会**静默不赋值**）、`preferred`/`avoided`、`stockBaseline`、`usePriceChannel`（默认 false）。

#### Domain（纯计算，零库类型依赖）
- `MarketFactor` / `SupplyDemandModel`（环路增益 `G = e·k_d/τ`）/ `FactionArchetype`（`TechLevel` → 画像的**确定性有限映射**，穷尽 switch 禁随机）/ `FlowGraph` / `MvsConstants`（**集中**全部可调常量，GOV-006 硬编码登记）。

#### Data
- **`WorldComponent_Market : WorldComponent`** —— 权威因子表（存**因子**非绝对价）+ 虚拟库存 + schema v1。构造纪律：`public` 非 abstract + `ctor(World)`（`World.FillComponents()` 反射补建）；`FinalizeInit(bool fromLoad)` 带参；**`schemaVersion` 用 0 哨兵**（`Scribe_Values.Look` 跳过 default）。
- **`MVSCommodityRegistry`** —— 三轴惰性索引 + 品类轴子孙递归；O(1) `AffectsDef`/`ForDef`。**命中集是可重建缓存，禁 Scribe**。

#### Application / Compatibility
- `Contracts/IMarketFactorProvider`（依赖倒置契约）· `MarketEventLog`（**有界 ring 200，不落盘**，非 `IExposable`）· `MarketEventSink`（桥守卫：`NoInlining` 分派，补丁体只见 `IncidentDef`/`Faction`/`int`）
- **`StatPart_MarketValue`（priority −1000）** —— 定价通道 A，**零 Harmony**。四道闸门全 null-guard + `[ThreadStatic]` 重入守卫（`try/finally` 成对）+ 未命中**不动 `val``（等价中性，语义比赋 1f 更安全）+ clamp `[0.5,2.5]`。

#### 事件流采集（Harmony，EXC-2026-006）
- 修改既有 `Capture/Patch_IncidentWorker.cs`：在**既有** `IncidentWorker.TryExecute` Postfix 体内追加 MVS 记录，**并列、不嵌套**的第二个 `try/catch`（失败隔离：MVS 侧异常不拖垮战斗记录）。
- **白名单门控（`MVSIncidentImpactDef`）是必需项** —— IL 事实：`TryExecute` 存在 `{ ldc.i4.1; ret; }` 的提前返回路径（`def.requireColonistsPresent` 且无自由殖民者时**未执行 worker 却返回 true**）⇒ `__result==true` **不保证事件真发生**，是「可能误记」而非「宁漏勿误」。
- `parms.faction == null`（灾害/天象）⇒ `EventScope.Global`，**不按 `parms.target` 归因**（target 是 Map/World 非派系）。
