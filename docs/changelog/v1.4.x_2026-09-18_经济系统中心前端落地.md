## 一、本版解决的问题

玩家报告：「**市场经济中心前端没有落地**」—— 在游戏内打开「系统中心 → 经济系统中心」，
只能看到职责边界 / 事件契约 / 依赖与能力（CenterManifest）与两个 KPI，看不到任何市场经济内容。

根因：上一批 MVS 只落了**数据面**（Domain / Data / 契约声明），4 个契约接口
`IMarketFactorProvider` / `IFactionProfileProvider` / `IMarketEventReadModel` / `IFlowGraphReadModel`
**声明的实现数为 0**，且 `BuiltinEconomyProvider` 未把业务视图接进详情快照 ⇒ 详情视图无内容可画。

用户两条裁决决定本次做法：
1. **范围**：市场面板 + 上下游库存结构图 + 派系状态 **全落**（不做分期）。
2. **接线**：**消费 MVS 契约**，不得直接读 `WorldComponent_Market`。

## 二、新增功能

### 2.1 市场面板
- 干净数据表：**品种 | 生产 | 消费 | 净值 | 价格**，17 个品种。
- 价格带水平条 + 语义色：**涨红跌绿**（含 ±1% 中性带）。
- 未就绪 / 无数据时价格一律显示 `—`（**不写 100%**，避免误导为「已读取」）。
- 行数运行时驱动 + 上限 32（`MaxMarketRows`），双层封顶（Provider 32 ∩ 高度容量）。

### 2.2 上下游库存结构图
- 三列节点：**上游原料 / 中游成品 / 下游市场**，节点按边角色自动归列。
- 正交折线连线；**仅高亮与选中节点相关的边**（最多 48 条，避免 48 线噪声）。
- 点击节点切换选中（再次点击取消），选中态为 UI 状态，**不入快照、不持久化**。
- 上限：24 节点 / 48 边；溢出按边数降序确定性裁剪，并**丢弃悬空边**。

### 2.3 派系状态
- 列：**派系 | 技术等级 | 类型 | 库存 | 冲击敏感度**。
- 隐藏 `f.def.hidden` 派系；行数上限 20，截断时**显式告知玩家**（不静默截断）。
- 区分「**市场未就绪**」徽标与「**未接入**」空态 —— 两者含义不同，混为一谈会误导玩家排查不存在的问题。

## 三、缺陷修复

### 3.1 【P1】`MarketEventLog` 跨存档事件泄漏

- **现象**：`MarketEventLog` 是 `internal static class`，其环形缓冲挂在**程序集**上而非 `Game` 上
  ⇒ 上一个存档的市场事件会出现在新存档里。
- **加重情节**：该类**随包发布了一个 `Clear()`，但零调用点** —— 防御代码写了却从未接上。
- **修法**：新增 `ChronicleGameComponent.ResetMarketEventLog()` 并接入 `FinalizeInit()`，
  与既有的 `ResetRaidLordLinks()`（同一缺陷类）并列。
- **约束（GATE-SAVE 要求）**：幂等、无 store 时安全、只清 `ring/index/totalWritten/revision`
  四个 static 字段、**不引入 Scribe 写入、不升 schemaVersion**。

## 四、架构说明（为什么不直接读 WorldComponent）

MVS 4 个契约原为**零实现**。本次按依赖方向铁律落地：

```
UI (Economy/UI/*)  →  Application (Builtin 块 + 快照 DTO)
                          ↓  经契约接口
                       MVS/Application/Adapters/*   →   MVS/Data
```

- 适配器置于 `MVS/Application/Adapters/`，**构造注入**，全部**无状态**
  （唯一例外 `MarketEventReadModelAdapter` 为**实例级**缓存，非静态）。
- `MVS/Data/` 仅一处改动：`WorldComponent_Market.CopyInventorySnapshot` 只读转发器
  （`inventory` 原为 private 无访问器）。**`WorldComponent_Market` 未被改成契约实现者**。
- 快照全部为纯 DTO / 值 / 已本地化字符串，**MVS 内部类型不出现在字段签名中**（GATE-DATA 约束①）。

### 性能约束（GATE-PERF）
- **构建与绘制分离**：三块快照只在 Provider 内重建，`OnGUI` 每帧只读缓存对象做绘制，
  **禁止在 `OnGUI` 内 new / 构建任何块**。
- `Recent(max)` 按 `Revision` 缓存（上限 40 行）；结构图按 **Def 数量指纹**失效缓存，
  避免每帧全 Def 扫描。
- 行数运行时驱动（不硬编码，兼容 DLC 增减），且全部有上限与降级。

## 十、本轮改动

### 10.1 市场面板改为 RUIF 驱动

`EconomyMarketPanel` 现有三条路径：

| 档位 | 条件 | 行为 |
|---|---|---|
| **D0** | RUIF ≥ 1.2 | `StatTable` **10 参重载**：表头 `PanelRaised` 底 + 斑马纹 + 比例列宽 + 逐列对齐 + **价格列由 RUIF 原生阈值着色**（`bandCol` + `bandValues`） |
| **D1** | RUIF < 1.2 | 5 参 `StatTable`（左对齐、无带色，一次性日志） |
| **D2** | RUIF 缺失 / 抛异常 | **同版式自绘回落**（同 shares 列宽 + 同斑马纹，观感不跳变） |

绘制期零分配：表行 / 列宽 / 对齐 / Dim / band 各数组**复用同一批字段**，按需增长。

### 10.2 行高改为取引擎真值

原先硬编码 `RowHeight = 18f`。**这不安全**：

`DataAtoms.StatTable` 的 IL 在行循环前做 `Mathf.Min(rowH, Measure.RowHeight(FontLabel))`
⇒ 传入的 `rowH` **小于**该真值时会被**静默压扁**（行内色带与文字重叠）。
18f 只是"默认字体下恰好等于真值"，玩家改字体后立刻失效。

现改为 `RuifBridge.StatRowHeight()`，读取 `Measure.RowHeight(Tokens.FontLabel)` 并缓存，
回落常量 `FallbackRowHeight = 18f`（默认字体下实测值）。

## 十一、本轮修掉的两个真缺陷

### 11.1 列宽 shares 写错（4:1 → 实为 2.385:1）

预览 CSS 写的是固定 px（品种 `124px` / 指标 `52px×4`），但在
`table-layout:fixed` + `width:100%` 下浏览器会**按比例放大**填满容器。
实测（428px 表宽）：品种 `150.891px` / 指标各 `63.266~63.313px`
⇒ 真实比例 = **2.385 : 1 : 1 : 1 : 1.001**。

初版按 `124/52 ≈ 4` 直觉取整成 `4:1:1:1:1`，导致品种列**宽 68%**、指标列**各窄 8px**。
—— 编译通过、测试全绿、屏幕上只是"看着差不多"。已修正并加断言脚本固化。

### 11.2 测试可见性配置方式错误

csproj 加 `<AssemblyAttribute Include="InternalsVisibleToAttribute">` **完全不生效且不报错**
（`GenerateAssemblyInfo=false` 时该 MSBuild 项属于被禁用的属性生成管线）。
改用显式源文件 `AssemblyInfo.Visibility.cs` 并追加 `Compile Include`。
