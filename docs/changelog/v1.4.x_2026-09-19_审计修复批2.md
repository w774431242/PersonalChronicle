## 本批修了什么（3 项）

### 🟠 §2.1 派系状态面板：**静默丢弃**（三个独立症状）

该面板**没有滚动**（`EconomyPanelChrome.Draw` 只返回 body 矩形、不带滚动；面板是 `static class`、
**无处存放滚动态** —— 且"不引入静态可变状态"是本工程纪律）。⇒ 高度不足时旧实现的处理是：

| # | 旧行为 | 为什么是缺陷 |
|---|---|---|
| a | 因子循环 `if (factor == null \|\| 放不下) break;` | **两件不同的事塞进同一个条件** ⇒ 一条坏数据会让后面**所有**项消失 |
| b | 事件段 `if (Events.Count == 0 \|\| 放不下画段头) return;` | 整个事件段**看起来不存在** ⇒ 玩家会以为该派系没有事件记录 |
| c | 事件行循环同样静默 `break` | 同上，无任何迹象 |

**共同点：静默丢弃与"本来就没有"在界面上长得一模一样** —— 这是**假空态**，与本线反复修的
"有标题、无内容"、"破折号当答案"同族。

⇒ 修法：
- **「空项」与「放不下」分开判**（空项 `continue`、放不下 `break` 并**计数**）
- **段头无条件画**（只要确实有数据）—— 段头是"这一段存在"的声明，不该由空间大小决定要不要承认
- **放不下就说出**：新增溢出提示行（模板走语言管道 `MVS.Economy.FactionDetail.Overflow`，
  UI 只填数字），有溢出时**替代**口径行（空间只够一条时，"有东西没看到"优先于"补充说明"）

> ⚠ **为什么不做滚动**：滚动需要跨帧状态，而该面板是静态类。**为它引入静态可变状态，
> 违反的纪律比这个缺陷本身更重**（且审计 §4.1 刚确认"无跨会话滚动态残留"是优点）。
> ⇒ 取"显式说出"而非"假装没有"。**这是本批唯一一处"修法不如理想方案"的地方，如实登记。**

### 🟠 §2.9 `homeTabLabels` 缓存不随语言失效

```csharp
if (homeTabLabels == null) { homeTabLabels = new[] { "...".Translate(), ... }; }
```
只判 `null` ⇒ 运行中切语言后这两个标签**永久停在旧语言**；且是 `static` 字段 ⇒ **跨会话存活**
（退出重进仍是旧语言，直到重启进程）。

⇒ 补**语言键**（`LanguageDatabase.activeLanguage.folderName`），走**同工程三处既有先例**
（`UIComponents.ThemeSwitch` / `UIComponents.Loc` / `MasterControlTabWindow.Population`）。

📌 **判据：凡是缓存了"翻译结果"的静态字段，都必须带语言键。**
⚠ 这类错误很隐蔽 —— 它**看起来像"翻译文件没生效"**，会把排查引向语言包而不是缓存。

### 🟡 §0.7 `EconomySocietySnapshot.Chips` 死字段

上一轮把四个影响因子搬进 tooltip 后，该字段**已彻底失去消费者**（Provider 不再填充、面板侧的
chips 块已删除）。⇒ **删除**。
📌 不保留"死字段 + 说明注释"：那是最容易腐坏的状态 —— 下一轮读到"它还有用只是暂时空"的注释，
就会去**复活**它。**声明原文已取证**（`grep Chips` + 全工程 `.Chips` 引用扫描**零命中**）后才删。
