## [开发线] 2026-09-19

### 要求一：社会特点进顶栏，`StatRow` 徽章退场

顶栏原先那个方块里写的是 **`StatRow`** —— 它不是 bug，是预览里的 `.ruif` **契约徽章**
（与 `SOCIETY` 同类的不翻译符号），但**它占着标题条最右的视觉位，零信息量**。

⇒ 现在这个位置承载**真实读数**（科技档位 ② · 治理 ② · 贸易接口 ②），并**挂 tooltip**
（顶栏极窄，截断几乎必然 —— LAND：截断必须配补偿）。

📌 **两者是互斥的**：有社会特点时**不再画徽章** —— 装饰与数据抢同一块横向空间，只会把数据挤成省略号。
📌 顺带一个结构性收益：**② 与 ③ 的分组不再依赖数组顺序**（② 在顶栏、③ 在 body，**位置即分组**），
比"同一串 chip 里靠次序区分"更难被后人改乱。`MVS.Economy.Society.Badge` 键保留以便一行恢复。

### 要求二：据点规模 → 结构进度条 + tooltip

原先两行文本（`据点（运行时真值） 10 处` / `估算人数（③ 设计假设） ≈213`）→ **一条进度条**：

- **条上的 caption 仍是原值**（「10 处」）⇒ 不悬停也看得到数量
- **tooltip** 给全部明细（据点、估算人数、占全星球份额）
- ⚠ **新增"分母"**：进度条需要一个可条形的量。「10 处」单独是**绝对量**，没有分母，条没有意义
  ⇒ 新增 `FactionScaleData.SettlementShare01` ＝ 该派系据点数 / **全体派系据点总数**，
  与计数**共用同一次扫描**（PERF-001：不为拿分母再扫一遍全库）
- ⚠ **与 `NormalizedWeight` 是两个不同的分母，不可互换**：那是"相对最强派系"的**权重**归一，
  这是"占全体**据点**总数"（各派系之和 = 1）。用错分母会得到"看起来对但读数没意义"的条
- ⚠ 无主据点**不计入分母**，否则"N 个派系的份额之和 = 100%"会被打破（条系统性偏短）
- ⚠ 份额不可算（全体据点数为 0）⇒ **不画条** —— 画一条 0% 的空条看起来就是"该派系占 0%"，
  那是**把缺失伪装成数据**

📌 **取值与文案一字未改**：`PopulationLabel/Value`、`HeadcountLabel/Value` 两条键**没有废弃**，
它们现在活在 tooltip 里（`BuildScaleTip` 直接拼这两条 ⇒ 条与 tooltip **不可能漂移**）。

### 问题三：图表放在**成员构成**上，不是市场特征上

> 我的建议与原图标注不同，理由如下 —— **饼图的前提是"整体中的份额"**。

| | 市场特征的四个系数 | 成员构成 |
|---|---|---|
| 语义 | **各自独立的乘子**（产能 ×1.3 / 进口 ×1.15 / 奢侈 ×1.2 / 冲击 ×1.1） | **整体中的份额**（合计恒 = 100%） |
| 能画饼吗 | ❌ **不能** —— 它们既不构成一个整体、也不该相加。画成饼会让读者以为彼此有"占比"关系，那是**用视觉撒谎** | ✅ 正是饼图的定义域 |

⇒ **图表落在成员构成**（**环形图 + 图例 + tooltip**）：

- **环形（donut）而非实心饼**：留中心孔 ⇒ 窄列里视觉重量更轻，与本工程"细描边 + 低饱和底"风格一致；
  **信息量完全相同**（角度即占比）
- **图例**：色块 + 名称 + 占比，色块与环上同色 ⇒ **靠颜色对应，不靠顺序猜**
- **tooltip**：列**全部**构成（含被聚合的「其余 N 项」）—— 截断与聚合都必须有补偿
- ⚠ 这也同时兑现了要求二的"**结构列表保持干净**"：5 行列表 → 1 个块

**技术实现**：引擎与 RUIF 都**没有**饼/环图原语（已核实 RUIF 原子清单）⇒ 自烘一张 96×96 纹理：

- **只 new 一次、之后复用**，签名（各段占比）不变直接返回 ——
  每次刷新都 new 会导致**一次会话泄漏上百张 Texture2D**（Unity 纹理不在 GC 管辖内，
  这是"看起来没事、玩久了显存爆"的典型成因）
- `FilterMode.Bilinear`：96px 的环缩到 84px，**没有它边缘是硬锯齿**
- 角度从 **12 点方向起、顺时针**（与读者对饼图的默认预期一致）
- 扇形归属用**前缀和**判定，避免逐像素除法的累积误差

## 实机验证建议（重启后）

| 项 | 怎么看 |
|---|---|
| **顶栏** | 应显示形如「社会特点 科技档位 星际 ② · 治理 领导·贸易大师 ② · 贸易接口 4 条 ②」，**不应再有 `StatRow` 方块**；悬停出完整文本 |
| **据点规模** | 应是一条**进度条**（caption 为「10 处」），**不再有两行文本**；悬停给出据点 / 估算人数 / 占全星球份额 |
| **成员构成** | 应是**环形图 + 图例**，**不再是 5 行列表**；环上或图例悬停给出全部构成 |
| **色块对应** | 图例色块应与环上扇形**同色**（不是仅靠顺序对齐） |
| **降级** | 构成不可用的派系 ⇒ 该段（含段头）整体不出现；份额不可算 ⇒ 不画条（不留空条） |
| **回归** | 市场面板可见品种与供需数值应与本批之前**一致**（本批不动四系数） |
