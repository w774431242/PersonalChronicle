## 一、移除「市场特征」段（用户裁决）

**移除内容**：段头（市场特征）+ 三条 Q/A（供需净值 / 本方仓储 / 市场准入）+ 段头 tooltip 上的**四因子 ③ 系数**（产能/进口/奢侈/冲击 —— 它们的唯一 UI 出口就是该段段头，**有意随之消失**，全工程暂无替代出口；profile 数据本身未动）。

**删除面**（按 2026-09-19 删 `Chips` 的同一判据：UI 读模型死字段**删除**优于留空注释）：
- UI：`BlockSectionTraits`/`BlockQa` 块类型、`DrawQa`、四个 `.qa` 常量、`BlockChips` 死常量（复审补删）
- Provider：`AppendDynamicMarketTraits` 方法 + `FindFactionByDefName` 专属副本 + `FactorText`（复审抓出的死方法）
- 快照：`TraitsSectionTitle`/`TraitsBadge`/`FactorsTip`/`MarketTraits` 字段 + `SocietyQa` 类
- dev fixture 同步停填

**结构收益**：`BuildPlan` 的 `.qa` 列宽派生量消失 ⇒ 回归 `void`；计划中最后的宽度依赖项消失 ⇒ **计划与宽度无关**，滚动分支不再重建计划（净减绘制工作）。
**键保留**：`MVS.Economy.Society.Traits.*` / `Market.*` / `Chip.*` / `FactorsHeading` 全部留在语言包（先例：`NotInvolved`），恢复段时从 git 历史接回。
**接口纪律**：`BuildSociety(Map map, ...)` 的 `map` 参数现无消费者 —— **签名不动**（接口 + 注册表牵连；恢复段时大概率要用），已显式声明。

## 二、优化据点收购项

| # | 问题（用户截图实测） | 根因 | 修复 |
|---|---|---|---|
| 1 | AIPersonaCore / AdrenalHeart / AestheticNose / AestheticShaper 等行**直接显示 defName** | 收购行错用 `KindLabelOf`（**PawnKindDef** 查找，成员构成专用）——动物恰好有同名 PawnKindDef 才显示正常，纯物品查无 ⇒ 兜底把 defName 画上界面 | 新增 `ThingLabelOf`（ThingDef 查找 → `LabelCap` 官方管线 → 兜底 defName），收购行改用；与 `KindLabelOf` 是**两种语义的两个查找**，注释明示勿合并 |
| 2 | 各行**满宽彩虹色条**（逐行变色的色环） | `TierTone(RowIndex)` 色环是为环形图**分类色**设计的；收购行无分类语义 | 改**单一语义色** `UITheme.Alive`（与同面板规模条同为"份额/覆盖"语义）；`RowIndex` 字段保留（聚合行判定仍用） |

**保持不变**：排序（count desc → defName tie，确定性全序）、MetaText「N 个据点」（诚实读数）、聚合行不画条、截断配悬停。
