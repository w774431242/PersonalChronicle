## 本批改了什么（同一 Change：`CHG-20260920-MVS-DEVFIXRAND-001`）

| # | 位置 | 改前（加法增量 / 推导） | 改后（直接随机） |
|---|---|---|---|
| 1 | 市场面板 · 行级净额 | `balance = supply - demand` | `rng.Next(-2400, 2400)` 独立随机 |

## 保留不动（**不是**加法增量，属占位契约 / 值-文本对）
- 快照字段与契约**零改动**；真实 Keyed 文本与真实 Def 取名（同日上一批已改）不动。
- **值-文本对**：`NetText` = 自身 `RawNet` 的格式化 · `PercentText` = 自身 `Share01` 的格式化 · `PriceColumnText` = 自身两段文本拼接。
- **占位覆盖形态**：市场 null 行（i=16）、每品种 1 个无读数成员、链路未计数格（i=3）、KPI 与真实中心同 7 张。
- **社会三档份额**：随机权重后**归一**（Σ=1 是 UI 扇形/条形的契约；归一是约束不是增量推导）——上一轮已实现，本批复核确认。

## ⚠ 已知偏差（有意，勿当 bug）
dev 数据中 **`RawNet ≠ RawSupply − RawDemand`**、**汇总 ≠ Σ 各行**、**`Weight01 ≠ 0.5`** ——
真实 Provider 保持这些关系不变（`Raw*` 仅服务排序，dev 预览下行为不受影响）。

## 📌 附带发现与处置（收尾两区比对揪出，非本批代码改动）
