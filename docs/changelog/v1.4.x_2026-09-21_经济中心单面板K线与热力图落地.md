# v1.4.x · 2026-09-21 · 经济中心：单面板 K 线 + 热力图（统一周期基准）

> 用户向 Changelog（不写行号；精确改动清单见 `docs/设计文档/架构/Change-Annotation-CHG-LCE-003.md`）

## 新增

- **经济中心整页改为单面板视图**：默认显示「品种 K 线」，顶栏按钮可切换「热力图」，两个视图都是整页呈现。
- **库存数量 K 线**：左侧选品种，右侧看该物品的库存走势，支持 **60分 / 日 / 周 / 月 / 季 / 年** 六档周期。
  - 每根蜡烛 = 该周期内的 开 / 高 / 低 / 收（全部来自本模组实测采样，非估算）。
  - 鼠标悬停显示十字线与该周期的 OHLC 读数；图右侧有最新收盘价参考线与数值标签。
- **热力图**：按物品品类分组的树图 —— 面积 = 库存价值，颜色 = 该档窗口的涨跌幅；点击格子即切换选中品种。
- **统一周期基准**：六档周期成为全中心唯一时间口径（月 = 原版一个季度 15 日，季 = 2 月，年 = 4 月 = 原版一年）。

## 说明

- 数据来源：数量 / 价值 / 分类 = 原版真实读数；蜡烛与涨跌幅 = 本模组实测采样（每 250 tick 采一次库存数量）。
- 不影响原版价格、财富与袭击强度 —— 本中心只做观测与记账。

## 兼容

- 新增存档段为「加性可选」：**旧存档可以继续加载**，原有档案数据不丢失；经济中心的 K 线从启用后开始累积，早期会显示为空态（"采样中 · 尚无记录"）。

## 已知

- 刚开始记录时可能只有一根"进行中"的蜡烛：需累积到该周期结束才会封成完整蜡烛（60分档最快）。
- 大量物品时，左列表与热力图按库存价值取前若干项，并在列表底部标注还有多少项未显示。
