# v1.4.x · 2026-10-02 · 文字截断修复 + 设备产出口径改为 5 天

- Change ID：`CHG-SHOP-UIFIX-001`
- 影响范围：车间管理窗口（设备页 / 人员页 / 排班页 / 班次表）
- 依据：用户反馈「有些文字被挤兑」+「将设备栏产出计算周期为 5 day」

## 一、修复：文字不再互相挤兑

界面上的文字一旦超出它所在的那一列，就会**直接压住右边的列**（游戏引擎没有自动裁剪）。之前车间管理里有若干处是「文本写出去了、宽度却没管」，典型的就是设备页那行：

```
炉灶（电力）  ●运行  烹饪简单食物 x4 永远   0 / 0   28.3 小时   (146, 0, 150)
                     └─ 这串会盖住右边的「产出」列
```

本次对以下位置全部加上了「超出即省略号 + 悬停看全文」的处理：

| 页面 | 位置 |
|---|---|
| 设备页 | 设备名称、状态、**当前制作**、产出、累计运行、位置（6 列全部） |
| 人员页 | 姓名、当前活动 |
| 排班页 · 班组卡 | 卡头（班组名 + 在编）、成员行的 姓名 / 技能 / 当前活动 / 工时 / 产量、班次 chip 的时段与计数、未编组提示、"+N" 行 |
| 班次表 | 时段、岗位、**指派班组** |

含义：文本过长时会显示为省略号（而不是压到隔壁），**把鼠标停上去可以看到完整内容**。

## 二、变更：设备产出统计周期改为 5 天

设备页顶部横幅与「产出」列的口径，从**今日**改为**最近 5 天**：

| 位置 | 之前 | 现在 |
|---|---|---|
| 顶部横幅 | 「今日产量 0」 | 「5 天产量 N」 |
| 产出列 | `今日 / 累计` | `近 5 天 / 累计` |

原因：车间产出往往不是每天都发生，单看当日经常恒为 0，看不出设备到底有没有在干活。5 天窗口更能反映实际产能。

- 「累计」列不变（长期累计保留）。
- 内部新增**逐日环形缓冲**记录最近 5 天产出，会自动剔除超出窗口的旧数据。
- 存档兼容：新增字段读旧档时为空白，自动补零，**无需迁移**；旧档照常加载。

## 三、回滚

撤销代码即止写；存档无格式破坏（新增字段会在存盘时一并写入）。
