# v1.4.x · 2026-10-02 · 班次精简为「岗位 + 优先级」

- Change ID：`CHG-SHOP-SHIFTSLIM-001`
- 影响范围：班次设置对话框、班次表页
- 依据：用户实测结论「班次只需要岗位、优先级就行。名额、门槛等等无作用」

## 变化

**班次设置**（点班次行的对话框）现在只有三项：

| 项 | 说明 |
|---|---|
| 时段 | 几点到几点（跨午夜 / 全天照旧） |
| 优先级 | `P0`–`P9`，同时段多个班次冲突时数字大者优先 |
| 岗位 | 生产 / 维护 / 质检 / 待命（决定原版「工作」面板勾选并提到最高档哪些工作） |

**撤下的项**：名额人数、技能门槛、候选池 —— 谁上哪个班改由**班组编制 + 倒班表**决定，不再叠加第二套限制。

**班次表**（列表页）列同步精简为：**时段 · 岗位 · 优先 · 指派班组 · 操作**。
- 撤下「名额 / 技能门槛」两列（字段已不可设，留着只会永远显示「不限 / —」）。
- 撤下「命中」列 —— 它移到了**行悬停提示**里（仍可看到该班次当前分到几人）。

**新建班次 / 预设班次**不再预设名额（旧行为是「1 人」/「池人数 ÷ 班次数」）。这类预设值会形成你在界面上看不见、却确实生效的限制；现在统一为「不限人数」。

## 数据兼容（重要）

- 存档字段**没有删除**：已有班次上**原先设置过的**名额 / 技能门槛 / 候选池**仍然按原样生效**（不迁移、不清空），以免破坏你的旧存档。
- 想让某个旧班次回到「不限名额 / 无门槛」，**删除该班次后重新添加**即可。

## 内部变更

- `Dialog_WorkshopShiftEditor`：移除名额步进、技能门槛选择、候选池区块（及配套的池菜单 / 计数逻辑），窗口高度 460 → 300。
- `WorkshopManageView.Shifts`：表头与列宽改为 5 列；`ShiftColKeysLength` 由命名常量派生，消除平行数组写死上界。
- `WorkshopManageView.Schedule`：`OpenNewShiftEditor` 与 `ApplyPattern` 不再写入名额；排班页 chip 悬停提示移除技能门槛行。
- `WorkshopShift`：`RequiredCount` 字段默认值与 Scribe 缺省值 `1 → 0`（不限）；`RequiredCount` / `RequiredSkill` / `MinSkillLevel` / `Pool` 标注为「UI 已撤下、字段保留以兼容旧档」。
- `WorkshopGatePicker` 与 `WorkshopShiftPatterns.SuggestedRequiredCount` 标注为**当前未接线**（刻意保留：源码目录未纳入版本控制，删除不可恢复；且后者有单测覆盖）。
- 本地化键 `ShiftCountLabel` / `ColGate` 保留（与上述预留组件配套；`ShiftCount` / `ShiftCountUnlimited` / `ShiftPool*` 仍被轮岗编辑器与倒班表使用）。

## 回滚

纯 UI 精简，无存档格式变更；如需恢复这三项设置，重新接线上述保留组件即可。
