# v1.4.x · 2026-10-02 · 班次表页（新增）

- Change ID：`CHG-SHOP-SHIFTTABLE-001`
- 影响范围：车间管理窗口（新增「班次表」页）
- 依赖：本次修复把排班页收敛为「一卡一班次」后新增的全班次管理入口

## 新增

车间管理窗口左侧新增 **「班次表」** 页（位于「排班」与「设置」之间）：以表格集中列出本车间的**全部**班次。

| 列 | 说明 |
|---|---|
| 时段 | `HH:00 – HH:00`；当前正处于该时段的班次左缘显示绿点（正在上班） |
| 岗位 | 生产 / 维护 / 质检 / 待命 |
| 名额 | 该班次需要几人；「不限」表示不设上限 |
| 技能门槛 | 如「制作 ≥ 6」；未设门槛显示 `—` |
| 优先 | `P0`–`P9`，同时段冲突时数字大者优先 |
| 命中 | 当前计划实际分配到的人数 / 名额 |
| 指派班组 | 显式勾选了该班次的班组名；未勾选时显示「按倒班轮转」（参与倒班）或 `—` |

## 操作

- **查看 / 修改**：点击任意一行打开班次编辑器（时段、名额、岗位、技能门槛、优先级、候选池）。
- **删除**：行尾「删除」按钮，二次确认后移除。删除时会**同时解除各班组对该班次的指派**（旧版本会残留一个"幽灵班次"，卡片上仍显示已删班次）。
- **新增**：右上角「添加班次」；或用「预设班次」一键铺两班倒 / 三班倒。
- 悬停任意一行可看到完整参数（含倒班序位与指派班组全名）。

## 内部变更

- 新增 `WorkshopManageView.Shifts.cs`（页面绘制；表头冻结 + 可见行裁剪 + 表头文本按语言缓存）。
- `Page` 枚举新增 `Shifts`；侧栏与内容分发接线。
- `MapComponent_WorkshopManager.RemoveShift` 现在会反向清理班组 `AssignedShifts` 引用（修复悬空引用与读档 null 项）。
- 「正在上班」判定从排班页内联逻辑收敛为 `ShiftIsActiveNow`（底层走工程唯一的 `WorkshopHours.InRange`），排班页 chip 与班次表行共用。
  ⚠ 行为差异：**全天班**（起止时刻相同）现在会正确显示为「正在上班」，此前恒判为否。
- 班次编辑器新增孤儿自愈：若所编辑的班次已在别处（如班次表）被删除，编辑器自动关闭。
- 新增本地化键 12 条（中英同步）。

## 回滚

本页为纯新增 UI，无存档格式变更；隐藏入口不影响既有排班数据。
