# v1.4.x · 2026-10-02 · 班组指派持久化修复 + 班组卡直接指派

- Change ID：`CHG-SHOP-CREWASSIGN-001`
- 类型：**P0 缺陷修复**（存档写入失败）+ **UX 修复**（指派入口不可达）
- 用户反馈：「班组卡每次加载都不会保存班次」

---

## 一、现象与取证

用户报告班组卡上的班次在重新加载后丢失。从 20:31 的存档（`Autosave-3.rws`）读出：

| 项 | 值 | 结论 |
|---|---|---|
| 班次 `<loadId>` | **1 / 2 / 3** ✅ | 班次 ID 补号正常 |
| 班组 `<assignedShiftIds>` | **空**（×2）❌ | **保存时指派列表本身就是空的** |
| `PC_WorkshopDuty` Job | **0 个** ✅ | 值勤链路（上一轮修复）已生效 |
| 保存错误 | **0 条** ✅ | 上一轮的存档修复已生效 |

⇒ 两个独立问题叠加：

1. **指派从未落盘**。旧实现用
   `Scribe_Collections.Look(ref AssignedShifts, "assignedShifts", LookMode.Reference)`
   保存 `WorkshopShift` 引用，而 `WorkshopShift` 只实现 `IExposable`、不是 `ILoadReferenceable`
   ⇒ 列表一旦非空，保存即抛
   `InvalidOperationException: Cannot save reference to ... if it is not ILoadReferenceable`
   ⇒ **整次存档失败**（用户 20:0x 的日志即此）。列表为空时反而不报错 —— 所以此前"有时能存、有时存不了"。
2. **指派入口不可达**。指派班次的按钮只在班组编辑器对话框里；排班页的班组卡是**只读**的，
   多班次未指派时卡片只显示「休」（且刻意不可点击）。玩家在卡片上根本找不到"谁上哪个班"。

## 二、修复

### 2.1 关联方式：对象引用 → 持久化 ID

| 组件 | 改动 |
|---|---|
| `WorkshopShift` | 新增持久化 `LoadId`（`Scribe_Values "loadId"`），由管理器统一分配 |
| `WorkshopCrew` | `AssignedShifts`（引用列表）改为 **`[Unsaved]` 运行时结果**；新增 `AssignedShiftIds`（`List<int>`，`LookMode.Value`）作为存档形式；提供 `IsAssigned` / `AssignShift` / `UnassignShift` 收口双份写入 |
| `MapComponent_WorkshopManager` | 新增 `NextShiftLoadId` / `ShiftById` / `EnsureShiftIdsAndAssignments`；`ExposeData.PostLoadInit` 调用（补号 + 按 ID 还原引用列表）；`RemoveShift` 改走 `UnassignShift` |

**10 处读取点一行未改**（读的仍是 `AssignedShifts` 引用列表），零跨对象引用风险。

### 2.2 指派入口搬到班组卡

- 班次 chip 点击：由「打开班次编辑器」改为「**切换本班组的指派**」（FloatMenu 列出本车间全部班次，当前指派带 ✓；班次本身的编辑仍在「班次表」页）。
- 「休」chip：由刻意不可点击改为**可点击 + 悬停高亮**，文案变为「休 · 指派」，tooltip 说明可点击。
- 新增文案：`ChipClickAssignHint` / `CrewAssignShort` / `CrewNoShiftsToAssign`（中英各 3 条）。

## 三、旧档兼容

- 旧档没有 `loadId` ⇒ `EnsureShiftIdsAndAssignments` 在 `PostLoadInit` 自动补号（1,2,3…）。
- 旧档的 `assignedShifts`（引用列表）不再被读取 —— 但它在旧档里**必然为空**（非空则保存失败），无信息损失。
- 用户已有的指派（若从未成功保存）需重新指派一次；新版在卡片上即可完成。

## 四、回滚

撤销代码即止。存档格式变化：`assignedShifts` → `assignedShiftIds`（旧档该字段为空，无迁移负担）。

## 五、待实机验证

1. 班组卡 chip 点击 → 弹出本车间班次菜单 → 选择后卡片立即显示该班次。
2. **保存 → 退出 → 重新加载 → 指派仍在**（本轮核心验收点）。
3. 白班组指派早班、夜班组指派夜班 → 到点换班、无人 24 小时值勤。
4. 单班次车间行为不变。
