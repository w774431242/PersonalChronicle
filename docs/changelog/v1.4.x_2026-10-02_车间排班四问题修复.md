# v1.4.x · 2026-10-02 · 车间排班四问题修复

- Change ID：`CHG-SHOP-4FIX-001`
- 影响范围：车间管理窗口（排班页 / 班次设置 / 班组卡片）、原版「工作」面板联动
- 例外登记：`EXC-2026-012`（E2）

## 修复

1. **排班页卡顿**：点击「排班」时不再卡顿约 1 秒。
   原因有三处叠加：成员头像缓存过期后一次性重绘、调度计划被每秒强制重建、悬停提示每帧拼接。
   现在头像分帧补齐、调度计划只在真正变化时重建、提示改为悬停时才生成。
2. **班组卡片只显示一个班次**：卡片过去会列出本车间**全部**班次（白班卡上会冒出夜班，多班次时重复多行）。
   现在每张卡固定显示该班组当前应上的**一个**班次：优先显示你为班组指派的班次，其次显示倒班表今日轮值班次；
   今日轮休时显示「休」。全部班次仍可在 chip 悬停提示与班组设置里查看。
3. **排班后成员不再闲置**：此前即便排好班次与班组，车间值勤工作类型在原版「工作」面板里始终是**未勾选**状态，
   导致被排班的人无活可干。现在设置班次/班组时会自动勾选对应的工作类型。
4. **岗位自动联动原版工作面板**：班次设置里的「岗位」现在会驱动原版「工作」面板的勾选 ——
   「生产」按车间类型勾选对应工作（烹饪坊→烹饪、锻造坊→锻造、缝纫坊→缝纫、机械加工坊→锻造、
   制作/制药/石工坊→制作、伐木坊→种植砍伐、雕塑坊→艺术、研究坊→研究），「维护」→ 建造。
   岗位改为下拉菜单，菜单中直接显示该岗位会勾选哪些原版工作；「质检」「待命」原版无对应工作，不联动。

## 行为边界（重要）

- 联动**只做「开启」**：仅把**未勾选（0 档）**的工作类型开为默认档；你已手动设定过优先级（1–4）的一律不改，
  也不会反向关闭或重排任何工作。
- 写入时机仅限：修改班次/班组/成员，或打开车间管理面板时对账一次；不会在每帧/每次心跳里写。
- QC/待命岗位不联动原版工作（原版没有对应工作类型）。

## 内部变更

- 调度计划失效策略：`MapComponentTick` 由「每 60 tick 无条件失效」改为「可观测失配才失效 + 20 秒兜底」（稳态重建次数下降 95% 以上）。
- 新增 `MapComponent_WorkshopManager.WorkEnable.cs`（原版工作面板联动写入层，受 EXC-2026-012 约束）。
- `WorkshopTypeDef` 新增 `productionWorkTypeDefNames` / `maintenanceWorkTypeDefNames` /
  `qualityCheckWorkTypeDefNames` / `standbyWorkTypeDefNames` 四个映射字段（数据在 `Defs/WorkshopTypes.xml`，C# 无硬编码）。
- 新增本地化键：`TaskSyncHint`、`TaskSyncTo`、`CardShiftAll`（中英同步）。
- SDD 同步修订：`Pawn自驱力框架_经济驱动的应用配置.md` §5.4/§7、`原版工作系统性能成本分析_2026-09-10.md` W8
  标明例外适用范围收窄（仅「优先级排序」仍在禁令内）。

## 回滚

撤销代码即止写；无存档格式变更；被自动勾选的工作玩家可随时手动关闭。
