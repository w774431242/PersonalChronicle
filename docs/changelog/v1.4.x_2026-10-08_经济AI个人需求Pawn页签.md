# v1.4.x — 2026-10-08 经济 AI：Pawn 检视窗「个人需求」页签

Change ID：`CHG-20261008-ECON-NEEDS-TAB`。类型：UI 挂载点扩展（非新数据源、非新持久化、无 Def 变更）。

## 变更

- **新增 Pawn 检视窗页签「个人需求」**（与「档案」「职业档案」同级）。实机视觉顺序：档案｜职业档案｜个人需求｜健康。仅对**活着的玩家方 humanlike** 显示；尸体、访客、敌对、动物不显示。
- **抽取宿主无关内容层** `NeedDashboardPanel`（+`NeedPanelState`）：名册（经济窗口，含分页选人）与单人（Pawn 页签）两模式共用同一测量与绘制核心；单人模式隐藏名册与分页。
- **新增单人只读门面**：`GameComponent_PawnEconomy.QueryNeedDashboardSingle(Map, pawnId)` → `NeedDashboardBuilder.BuildSingle(...)`，只读 1 个 Pawn（名册路径为 12+1 次读）。
- **页签注入改为组合根传参**：`ChronicleInspectTabInjector.InjectAll(IReadOnlyList<Type>)`，由 `ChronicleMod` 传入 [档案, 职业档案, 个人需求]；注入器不再引用业务域，消除 Archive↔Economy 循环。
- **修正注入器注释**：实机为**逆序渲染**（原版 `BasePawn.inspectorTabs` 顺序反向铺开），index 1 落在视觉最右端紧邻「健康」——旧注释「前移到左侧、紧邻角色」与实机不符。
- **本地化**：新增 `PC_PEA.Needs.TabTitle`（个人需求 / Personal Needs）。
- **net48 兼容修复**：`NeedDashboardTextFlow` 的 `Split('\n')` / `TrimEnd()` 在 netstandard 2.1 引用面下被解析到 2.1 专有重载，net48 宿主抛 `MissingMethodException`（实测 10 个用例失败）；改为显式 `Split(char[], StringSplitOptions)` 与 `TrimEnd((char[])null)`（语义等同无参版）。
- **工具链修复**：`_scripts/compile_with_sdk.ps1` 补 `System.Xml.dll` / `System.Xml.Linq.dll` 引用（缺失时 csc 对既有 Data 文件报成片 `CS0246/CS1069`，与业务代码无关）。
