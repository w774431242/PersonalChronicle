# 经济 AI：B2.2 实物银币储备原型

Change ID：`CHG-20261008-ECON-SILVER-RESERVE`。

新增独立 ThingOwner 银币容器和移动 journal。每笔单堆存取核对两端实际银币增减、结果物品 ID/所属，不单凭 API 返回值确认完成。禁止合堆、创建银币或从旧账反造储备；重入、版本/命令冲突和不明移动被拒绝或隔离。整堆移出时回调抛错产生的已知无主源物品予以保全并保存，不生成存款额度。毁损及未登记盈余单独报告，不修改净缴存历史。

新增独立 schema=1 原型 Scribe：保存实物和全部命令证据；恢复物品 ID、holdingOwner 与防重历史，未来/损坏 metadata 原文保留，未完成阶段不自动重做。既有游戏保存字段和 legacy 引擎未改。

验证：Release 构建成功；新增 42 项通过；全工程 788 通过、0 失败、1 项既有跳过。测试使用真实 ThingOwner/ThingMaker/SplitOff/Destroy/Scribe，配最小 Silver Def 和离线宿主垫片；当前游戏 DLL 的贸易/搬运发现路径另有静态核验。

本批仍是内部独立原型，尚未挂入整局保存、活动账本、玩家 UI 或游戏支付路由。原版路径隔离的源码/IL 证据不等于实机或第三方 Mod 验收。无部署；下一步 B2.3 对接账户发行、防重消费、阶段恢复与旧权益迁移，随后 B2.4 接入单一制度开关。
