## 玩家能看到的

- **地图办理链（待实机验收）**：产生求职意图 → 寻路到劳务站 → 柜台洽谈 → 签字 → 签领合同纸 → 原版工作 → 收集产物 → 前往工资结算处 → 核验交接 → 工资到账 → 账务归档。
- **实话实说**：洽谈阶段不会提前出现"已签约"；"已选择机会"、"已签约"、"正在工作"、"已交验"、"已到账"是**五个不同的状态**，在个人账户页与合同展开详情里逐级可读，并给出**下一步该做什么**。
- **实体合同纸**：真实物品（不可堆叠、不可交易、无市场价值）。检查它可看到短号、持约人、工种、单价、已完成件数、当前阶段、已付与未付；纸**不是债权** —— 捡到或偷到都领不到钱（付款对象由合同裁定）。丢失可到劳务站补领，补领后**旧纸作废**并明确标注。
- **真实产品交验**：产出的东西必须**本人带到柜台**（按 Def 逐项核对实际件数，少带不给过）；无实物的劳务（如割除、驯服）凭完成证明交验，并明确标注"无需实物产品"；狩猎/宰杀/搬运的可信接收凭据未完成，新实体交付模式仍阻断，已有权利保留。
- **批量与欠薪**：合同可分为多件分别完成、分别交验、分别结算；资金不足时显示"已交付，待发薪"，殖民者可以离开，注资后自动补付，**不会重复交货**。
- **资金不提前释放**：完成一件工作不再等于"这笔钱可以派给别人" —— 承诺只在**真正付清**时才释放，因此不会再出现"同一笔工资被派两次"。
- **双语与检查**：新增文本全部中英双语；合同纸有独立贴图（程序化生成，无外部素材）。
