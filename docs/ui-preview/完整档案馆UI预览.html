v4.10 战役档案（Overview › Battle）· 环世界官方手册绘制原语对照
预览元素对应游戏内绘制原语（RimWorld 1.6 纯代码 UI）手册要点
战役卡 · 显著性着色UIComponents.Card + 左 accent 边框 / 顶部 2px 强调条色值走 UITheme 令牌；Decisive=Accent，Skirmish=Muted；禁止窗口内 GUI.color = new Color(...)
「决定性 / 小规模冲突」徽章UIComponents.Pill（GameFont.Tiny 固定）徽章字体须临时固定 Tiny，与 DrawPill 算宽一致，防文字溢出方块
「N 人参战」副标题读 BattleObject.ParticipantIds.Count（开战我方快照）引擎限制：敌方数量开战瞬间未生成，只呈现我方视角，文案诚实标注
展开「我方击杀 / 阵亡」点卡就地展开（类 FactionCodex 内嵌滚动）击杀/阵亡由事件流 subject 反推（OnKillRecorded 已挂 battle 边）
袭击三要素采集（触发/规模/击退）Patch_RaidEnd（3 个 RaidStrategyWorker.Notify_* postfix）+ ArchiveService.OnRaidPawnGone/FinalizeBattle开战快照 RaidCount；Notify_PawnKilled/Died/LeftMap 计数归零 → EndTick 精确闭合（最后袭击者消失）；档案馆定位：流程过后归档，不轮询/不实时
击退时长展示EndTick - StartTick（仅 EndTick != -1）已闭合战役显示「历时 X 时 Y 分」；EndTick == -1（进行中/未归档）显示占位，不造假
来袭规模BattleObject.RaidCount（RaidStrategyWorker.TryExecute postfix 快照）三格指标「来袭规模」格；敌方数量可精确快照（区别于旧「开战点无敌人」认知）
战役条目身份BattleObject.IncidentDefName → IncidentDefLabel标题 + 日期去重，多场同名袭击可区分；StartTick 触发时间（精确）
KPI 汇总条（区块顶）UIComponents.BattleKpiStrip战役总数/决定性/我方击杀/阵亡/参战人次五格；GetBattleSummary() Read Model 聚合，不逐卡计数
战役卡三格指标UIComponents.BattleMetricCell参战（ParticipantIds.Count）/ 击杀 / 阵亡三格；阵亡格用 Dead 令牌强调，中文行高 ≥28f
参战名单 chipsUIComponents.RosterChip（复用 Chip）点击跳转 pawn 详情（NavTarget.Pawn）；人数多时折叠为「N 人参战」，不撑高卡
威胁类型标签UIComponents.ThreatTagIncidentDef.category（ThreatBig=Accent / ThreatSmall=Tag）弱语义分桶；BattleObject 需补存 category 快照（P2）
显著性扩展点IBattleProvider.TryAppraise → IsSignificant/Weight第三方注册高优先级 Provider 可改战役显著性 → 改卡片视觉；UI 零硬编码阈值
v4.12 地图志（Overview › Location）· 环世界官方手册绘制原语对照
预览元素对应游戏内绘制原语（RimWorld 1.6 纯代码 UI）手册要点
地图志卡 · 类型着色UIComponents.Card + 顶部 2px 强调条本家=Accent / 派系城市=Info / 已荒废=Muted+Dead 角标；禁止窗口内 GUI.color = new Color(...)
「本家 / 城市 / 任务地点」徽章UIComponents.Pill（GameFont.Tiny 固定）类型由 MapParent.def（WorldObjectDef）+ mapGenerator + ParentFaction 三件套判别，零硬编码
地形标签 chipsUIComponents.Chip / 新增 TerrainTagbiome/丘陵/临海/污染/积雪/年均温 全部快照自 Map.Tile → WorldGrid.GetTile，温度用 GenTemperature.GetAvgAnnualTemperature（年均非瞬时，防失真）
生命周期三格UIComponents.StatCell（落成 / 状态 / 驻留）EstablishedTick 首建快照 / DeinitTick 地图销毁闭合 / 驻留由 per-pawn PlaceHistory 聚合
展开「此地编年史」点卡就地展开（类 FactionCodex 内嵌滚动）+ TimelineNode 时间轴事件流 subject 反推（ObjectRef.ForLocation 幂等挂 map 边）；编年史升序排列由 Read Model 聚合，窗口零排序
地图销毁钩子订阅 Map.Deinited 事件（优于 Harmony patch）零签名漂移风险；定居点被摧毁走 Settlement.Destroyed / DestroyedSettlement，标 DeinitReason=Destroyed
「可交易」标记UIComponents.Chip / 新增 TradeChip由派系 FactionDef.baseTraderKinds 非空判别（纯 Def 判别，非交易事件）；可交易=Alive / 不可交易=Muted
「主要售卖类型」chips复用 TerrainTag（TradeCategory）从 TraderKindDef.stockGenerators 归一的 8 大类（资源/布料/食物/药品/武器/护甲/植入物/科技），CategoryKey 走 UITheme 着色 / 文案已本地化
「需贸易许可」标注UIComponents.Pill 虚线框TraderKindDef.permitRequiredForTrading（如帝国 TradeSettlement），null=无需；随地图快照保存防 Def 漂移

地图志定位：编年史「领地/地志」档案，只读不造机制。地图身份（类型/归属/地理）在地图首次落成时快照；编年史由发生于此的事件流反推；销毁/荒废由地图销毁与定居点摧毁钩子归档，不实时轮询。档案绑定稳定 MapId，不绑定易消失的 settlement 实体。商贸（可交易 + 售卖类型）是纯只读 Def 判别，无需 TradeDeal patch / 不记交易历史。开发文档：docs/ui-preview/地点地图志开发文档.md

社会关系网络（Social tab）· 环世界官方手册绘制原语对照
预览元素对应游戏内绘制原语（RimWorld 1.6 纯代码 UI）手册要点
关系网络图（中心 + 节点环）DrawSocialNetwork（ArchiveMainTabWindow）中心节点卡（DrawCard Accent）+ 关系节点卡（活跃=Info / 结束=Muted）；节点上限 12
分层定位（统一尺寸）GridSlotsFor(nodes) 返回 (col, row) 整数对 → 节点中心 = (cx + col×colSpacing, cy + row×rowSpacing)关系分类只决定位置，不改变尺寸——所有关系卡统一宽度高度：夫妻对称左右（(-1,0)/(1,0) 延展核心）、父母辈往上（row -1）、子女辈往下（row +1）、平辈左右（(-2,0)/(2,0)）、朋友/宿敌/其他外圈；槽位耗尽螺旋兜底不重叠。间距随 zoom 等比缩放：colSpacing = nodeW + max(nodeW×0.3, 22×zoom) / rowSpacing = nodeH + max(nodeH×0.3, 22×zoom)（gapRatio=30%、minGap=22f 容纳两行文本+padding），卡片放大时间隙同比例增长；节点字号/内边距也随 zoom 缩放（CSS font-size: calc(11px×var(--zoom))）保证视觉协调；panel 高度自适应 max(246, 246×zoom, (maxAbsRow×2+1)×rowSpacing + nodeH + 32)
Z 形中点连线 + 平滑拐角每关系调用五次 Widgets.DrawLine：垂直段1 + 斜角1 + 水平段 + 斜角2 + 垂直段2从卡片 A 中心出发、到卡片 B 中心收尾（非卡片边缘）；两条垂直轴分别对齐卡片 A 的 X 中点（center.x）与卡片 B 的 X 中点（nodeCenter.x），水平段在 midY = (cy+ny)/2 高度横跨；两处 90° 转弯各加 10×zoom 斜角过渡成圆角——圆角半径随卡片缩放联动，放大时圆角弧度按比例增大避免尖刺感；活跃线 Accent 2.5px、结束线 Border 1px
初次自动 fit首次进入（socialNetworkZoomTouched==false）按网格包围盒计算 fit 缩放仅约束水平方向：fit = clamp(可用宽/fitW, 0.2, 1)（fitW 按 maxAbsCol 估算）——垂直方向由 panelHeight 自适应增高容纳，勿用固定 246 高度约束 fitY（会致密集图 clamp 到下限挤成一团）；0.2 下限让窄面板（≤250px）多节点也能完整显示不越界；用户滚轮缩放后（touched=true）停止自动 fit，交还手动控制
滚轮缩放面板内 Event.current ScrollWheel → socialNetworkZoomclamp [0.6, 2.4]，围绕面板中心缩放；panelHeight = max(246, 246×zoom, 网格高度)；消费滚轮事件避免外层 ScrollView 同滚
左键拖拽平移空白背景 Event.current MouseDrag（button=0）→ socialNetworkPan按住左键在节点/中心卡以外拖动即可平移图；不覆盖节点点击（Widgets.ButtonInvisible 优先）
初始关系 + 合成朋友/宿敌PawnArchiveSnapshots.CaptureInitialRelations + SocialRelationPolicyDef直接/推导/好感度三来源去重；朋友=PC_Opinion_Friend，宿敌=PC_Opinion_Rival（好感度阈值 Def 驱动）

社会关系网络图消费 BuildRelations 快照（ArchiveUiDataProvider），窗口只做绘制与交互（NavigateTarget），排序/null-guard 归属 Read Model。缩放/平移是窗口内绘制态交互状态（socialNetworkZoom / socialNetworkPan），随详情对象切换复位。

战役档案定位：编年史「历史转折点」档案，非战斗战报。不建独立战役详情页（会与 CombatLog 阵营图鉴重复）；Overview 卡即档案条目。信息层组件（KPI 汇总条 / 三格指标 / 参战名单 / 威胁标签）全部消费 ArchiveUiDataProvider.BuildOverview(Battle) 快照，窗口零排序 / 零 null-guard。开发文档：docs/ui-preview/战役档案开发文档.md
