## 二、视觉语言规范（重构的"宪法"）

### 2.1 语义 → 令牌映射（**全窗唯一**）

| 语义 | 令牌 | 用于 |
|---|---|---|
| 可用 / 正常 / 运行中 | `Alive` | 能力 chip、制度色条、状态点 |
| 暂不可用（时段外/待办） | `Warn` | chip、提示 |
| 停业 / 故障 / 危险 | `Dead` | chip、色条、危险按钮 `ButtonTone.Danger` |
| 未配置 / 未挂牌 | `Dim` | chip、占位符、空态文本 |
| 信息 / 过渡态 | `Info` | 退出中等 |
| 主操作 / 选中 | `Accent` + `AccentSoft` | 主按钮、选中底 |
| 文字三层 | `Text` / `Muted` / `Dim` | 正文 / 次要 / 最弱 |
| 容器三层 | `Window` → `Panel` → `Card`(`CardHover`) + `BorderSoft`(`Border`) | 窗口 / 分区 / 卡片 |
| 强调描边 | `Border` | 悬停、选中 |

> 约束：**同一语义只允许一种颜色**；新增语义必须先进本表，禁止就地取色。

### 2.2 卡片规格（唯一实现）

```
CardFrame(rect, hovered, accent):
  Box(rect, hovered ? CardHover : Card) + Border(rect, hovered ? Border : BorderSoft)
  accent != null → Box(rect.x, rect.y, 3f, rect.height, accent)
  return Layout.Inset(rect, CardPadX, CardPadY)

StatusChip(rect, label, color):      // 宽 = Measure.Width(label, Tiny) + SpaceSm
  Box(WithAlpha(color, .14)) + Border(WithAlpha(color, .5)) + Label(Tiny, color, Center)
  // 悬停 → TooltipHandler.TipRegion(完整原因)

RowHead(inner, label, buttonLabel):  // 按钮宽 = max(Measure.Width(buttonLabel, Small) + SpaceMd*2, SpaceLg*4)
  标题可用宽 = inner.width − 按钮宽 − SpaceXs   // 先测后算，不用固定值
```

### 2.3 布局纪律（强制）

1. **高度/宽度**：一律 `RUIF.Measure.RowHeight/ControlHeight/Width` 与 `Tokens.*` 派生；**唯一允许的字面量是装饰值**（色条宽 3f、hairline 1f）。
2. **行高体系**：卡片 = `RowHeight(bodyFont) + RowHeight(labelFont) + CardPadY×2 + SpaceXs`；不得出现第三套行高。
3. **按钮高**：统一 `Measure.ControlHeight(font)`（废除 28/30/两套常量的并存）。
4. **滚动**：`BeginScroll` 与 `EndScroll` **必须** `try/finally` 成对（既有样板 `NeedsCyclePanel.cs:141-149`）。
5. **绘制路径零分配**：文本入测量缓存（键 = 数据版本 + 宽度）；绘制只读缓存字段（样板 `NeedsCyclePanel`，反例 `Policy.cs:101`）。
6. **降级阶梯**：D1 省略号（`EllipsisLabel`+悬停全文）→ D2 减少条目（放不下即止）→ D3 收窄内边距（有下限）→ D4 换档（宽/窄卡）。
7. **不折行页必须改**：概览页固定 46f 不折行是**溢出风险**，重构时并入统一测量缓存。

## 四、验收标准（每阶段逐项过，不抽样）

| 维度 | 判定 |
|---|---|
| 层次 | 主区域 ≥3 层（容器/分区/内容/叠加），差异全部来自令牌 |
| 反馈 | 交互件六态齐全；列表行有 hover；chip 有 tooltip |
| 对齐 | 基线 / 右边界 / 中心逐项验；数字等宽 |
| 呼吸 | 内边距 ≥ 令牌值；间距成体系；不贴边；行高不压缩 |
| 准确 | 配色来自映射表；数值语义与数据同源；**自画内容与实现一致** |
| 纪律 | 绘制期零 `StringBuilder`/LINQ/`Measure.Width`；魔数仅装饰值；滚动 `try/finally` |
| 降级 | 窄/宽两档各构造一次；D1–D4 各触发一次，无重叠、无硬切 |
| 本地化 | 缺键回落生效；无硬编码用户可见文本 |
