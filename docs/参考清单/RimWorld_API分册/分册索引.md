## 使用建议

- 编码/补 Def/写 XML 时优先查 `Def系统与XML注入.md`、`XML_Patch操作与XPath.md`、`本地化与翻译.md`。
- 给现有对象加行为优先查 `组件化架构_Comp与Component.md`；存数据查 `存档系统_Scribe序列化.md`。
- 改原版逻辑查 `Harmony运行时补丁.md`；读角色/属性查 `Pawn与Stat核心API.md`。
- `未使用_底层架构与游戏规则.md` 汇集战斗/事件/任务/世界/集群/UI 节点/资源/底层抽取规范等本工程暂不直接用到的内容，仅供偶尔核对，不进入日常引用。

> 注意：原文反复强调——RimWorld **没有** 由 Ludeon 维护的正式 Mod SDK；所有 API 最终权威是**目标 Build 的实际程序集 + Core/DLC Def 实例**。分册仅重新组织公开资料，不改变此事实。
