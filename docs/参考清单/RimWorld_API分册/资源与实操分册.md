## A. Sounds（声音）

来源：<https://rimworldwiki.com/wiki/Modding_Tutorials/Sounds>（oldid=135606，⚠️ 官方标注「需重写、内容过时」，架构描述仍有效，现代字段以程序集为准）

### A.1 三要素架构

```text
Sound Event（游戏代码硬编码的播放信号，事件名不可自造）
→ SoundDef（XML 定义播放行为）
→ Sound File（wav / ogg / mp3）
```

### A.2 SoundDef 结构

```xml
<SoundDef>
  <defName>...</defName>        <!-- 必须匹配代码查找的事件名，不匹配=静默无声（最常见失败原因） -->
  <eventNames>                  <!-- 可选：多个事件名复用同一 SoundDef -->
  <subSounds>
    <li>
      <grains>
        <li Class="AudioGrain_Clip">
          <clipPath>Sounds/Guns/Gunshot1</clipPath>  <!-- 相对 Mod 根目录，不带扩展名 -->
        </li>
      </grains>
      <!-- 现代字段：volumeRange / pitchRange / paramMappings 等，本页未覆盖，以原版 Core Sounds XML 为准 -->
    </li>
  </subSounds>
</SoundDef>
```

### A.3 关键规则与坑

- **路径**：grain 的 path 相对 Mod 根目录、**不带扩展名**；写绝对路径或带 `.wav` 后缀都会失效。
- 播放时游戏**遍历所有已加载 Mod** 找名称匹配的 SoundDef——后加载 Mod 可覆盖同名声音。
- 参数（如 `FireSize`、`ImpactSpeed`）分 oneshot/sustainer，且有「每次采样一次」与「每帧持续更新」两种模式，误用后者会导致音调抖动。
- ⚠️ 官方教程中的 **Package 编辑器已被移除**，该操作流程不可照做。

## B. Textures（贴图）

来源：<https://rimworldwiki.com/wiki/Modding_Tutorials/Textures>（oldid=171447，Under Review）

### B.1 格式与尺寸规范

- 支持格式：**透明 PNG（最常用）** / JPG / PSD / DDS。
- 像素密度：原版多为 **64 px/tile**，新 DLC 与多数 mod 以 **128 ppt** 为基准，256+ 易与风格冲突且耗 VRAM（耗尽直接崩溃）。
- 尺寸为 **4 的倍数，最好是 2 的幂**。
- 描边：可交互物体（物品/建筑）需**粗黑描边，约每 64px 对应 2px**；植物用**绿色描边**。

### B.2 遮罩（Texture Mask）

| 遮罩色 | 含义 |
|---|---|
| 黑色 | 不被染色区域 |
| 纯红 `#FF0000` | 应用主颜色（深红=强度减弱，`#BB0000`=75%） |
| 绿色 | 第二颜色（如床的分配色），红绿可混合 |

### B.3 白边问题（透明像素）

贴图压缩时部分绘图软件丢弃全透明像素的颜色数据 → 游戏内白色描边。解法：①透明像素保留颜色数据（最好黑色）；②原描边外再加一圈 **1% 不透明度黑色描边**。（AssetBundle 可关闭内存压缩绕开此 bug，见 E 节。）

### B.4 路径与引用

- 文件放 `Textures/`；**所有 mod 的贴图在同一加载空间，路径冲突后者覆盖前者** → 文件/文件夹加独特前缀（故意复用原版路径 = re-texture mod）。
- XML 引用以 `Textures/` 为根、**不含扩展名**：`Textures/MyMod/MyTexture.png` → `MyMod/MyTexture`。

### B.5 各对象贴图要求

| 对象 | 要求 |
|---|---|
| 近战武器 | 尖头朝右（西向自动镜像）；原版 `equippedAngleOffset` 多为 **-65°** |
| 远程武器 | 枪管/发射点**垂直居中**对齐弹丸生成位置 |
| 弹丸 | **朝上绘制**，贴图中心=游戏内坐标；**西向不镜像** |
| 头饰 | 最少 3 张（南/北/东，西镜像东）+1 地面图；用遮罩 6+2 张 |
| 身体服装 | 5 体型（male/female/thin/hulk/fat）×3 向 = **15+1 张**；用遮罩 30+2 张 |
| 建筑 | 画布按 `drawSize` 精确设置并居中：`size(2,2)` + `drawSize(3,3)` + 128ppt → **384×384** |
| 墙壁/管线 | **linked atlas**：16 子贴图精灵表，红色区域被裁剪 |
| 地形 | 单张覆盖 16×16 格，必须**四方可平铺** |

## C. Plant Rendering（植物渲染）

来源：<https://rimworldwiki.com/wiki/Modding_Tutorials/Plant_Rendering>（oldid=169989，Under Review）

### C.1 贴图与变体

- **`texPath` 指向包含贴图的文件夹名，不是文件**；`Graphic_Random` 时每副本随机选变体（`Dandelion.png`/`DandelionA.png`/`DandelionB.png`）。
- 1.6 状态变体字段（均沿用默认贴图的 graphicClass/shaderType/drawSize/color，数量不必与默认匹配）：

| 状态 | 字段 | 触发条件 |
|---|---|---|
| 未成熟 | `immatureGraphicPath` | 生长 % ≤ `harvestAfterGrowth`（1.0=100%） |
| 无叶 | `leaflessGraphicPath` | 不可播种/收获季节 |
| 污染 | `pollutedGraphicPath`（Biotech） | 格被污染 |
| 雪覆盖（1.6 新增） | `snowOverlayGraphic` / `immatureSnowOverlayGraphic` / `leaflessSnowOverlayGraphic` | 积雪 >80% |

### C.2 布局与缩放

- `<plant><maxMeshCount>`：**仅允许 ≤25 的完全平方数**（1/4/9/16/25），否则启动报错。
- 实际覆盖 = `visualSizeRange` × `drawSize`，与生长% 成正比。
- 定位基准：`maxMeshCount=1`（树）相对格**底部**；>1（草）网格相对格**中心**。
- 风吹：`<topWindExposure>` 默认 0.25（范围 0–1）；随机偏移**无法用 XML 控制**。
- 阴影：`graphicData` 下 `shadowData`（`volume`/`offset`），省略则无阴影。
- 秋季变色：仅落叶树，且 **shaderType 必须为 CutoutPlant**（TransparentPlant 不支持），参数 `_FallColorSource/_FallColorDestination/_FallTransitionRange/_FallBehaviorEnabled`。

## D. Research Projects（研究项目）

来源：<https://rimworldwiki.com/wiki/Modding_Tutorials/Research_Projects>（2025-10-06 更新，对应 1.6，Under Review）

### D.1 核心字段

- `<baseCost>` 与 `<knowledgeCost>`（Anomaly）**互斥**。
- ⚠️ **原版字段拼写就是 `preqrequisites`（缺 i）**——不要"纠正"成 prerequisites，会导致字段无效。
- `<hiddenPreqrequisites>`：逻辑同前置但不绘制连线（减少视觉杂乱）。
- `<techLevel>` 枚举：Undefined/Animal/Neolithic/Medieval/Industrial/Spacer/Ultra/Archotech（枚举非 Def，不可自定义）。
- `<requiredResearchBuilding>`：**研究台之间无进阶关系**，指定简单研究台则高科技台也不能研究；官方推荐用 `<requiredResearchFacilities>`（如 MultiAnalyzer）做门槛而非自定义研究台。
- 布局：`<tab>`（ResearchTabDef）+ `<researchViewX>`（**以 1 递增**）+ `<researchViewY>`（**以 0.7 递增**）；多 mod 抢格会错位，项目多时用自定义标签页。
- 完成信件：`discoveredLetterTitle/Text` + `discoveredLetterDisabledWhen`；隐藏：`hideWhen`（选项：bigThreatsDisabled/trapsDisabled/turretsDisabled/mortarsDisabled/extremeWeatherIncidentsDisabled）。
- DLC 专属：Royalty `<techprintCount/Commonality/MarketValue>` + `heldByFactionCategoryTags`；Biotech `<requiresMechanitor>`；Anomaly `<knowledgeCategory>`；Odyssey `<requireGravEngineInspected>`。
- 其他：`requiredAnalyzed`（CompAnalyzable 物品）、`recalculatePower`、`teachConcept`、`customUnlockTexts`、`generalRules`（未提供则**永不生成原理图**）。
- 遗留无用字段：`requiredByThis`、`researchMods`（旧 alpha 钩子，勿用）。

### D.2 依赖研究的 Def 字段速查

| Def | 字段 |
|---|---|
| RecipeDef | `researchPrerequisite`（单）/ `researchPrerequisites`（列表） |
| BuildableDef（含 ThingDef） | `researchPrerequisites`（仅列表） |
| PlantProperties | `sowResearchPrerequisites` |
| RecipeMakerProperties | `researchPrerequisite` / 列表 |
| TerrainTemplateDef / DesignationCategoryDef / PsychicRitualDef | `researchPrerequisites` |

### D.3 C# 检查

`ResearchProjectDef.IsFinished` 属性；频繁检查用 **DefOf 模式**取静态引用。

## E. Asset Bundles（1.6 重大简化）

来源：<https://rimworldwiki.com/wiki/Modding_Tutorials/Asset_Bundles>（oldid=181292，Under Review）

- **Unity 版本必须精确匹配 1.6 的 2022.3.35f1**（版本不匹配=加载静默失败返回 null，头号原因）。
- Unity 项目内 `Assets/` 路径必须**镜像 mod 内结构**（`Assets/Textures/Things/Item/MyThing.png` ↔ `Textures/Things/Item/MyThing`）。
- 贴图导入设置：`textureType=GUI`（避免生成 sprite 子资产）；**`_mask`/`_normal` 必须关 sRGB**（存数据非颜色）；`/Terrain/` 路径 wrapMode=Repeat + aniso=8；BC7 + maxSize 4096；mipmap 开。
- 构建：`BuildPipeline.BuildAssetBundles(out, ChunkBasedCompression /*LZ4*/, BuildTarget.*)`；只发布无扩展名的 bundle 文件（.manifest 不发布）。
- **1.6 无需任何加载 C#**：启动自动扫描全部 mod 的 `AssetBundles/`；`ContentFinder` 查找顺序 = 松散文件 → 本体内置 → bundle；松散切 bundle 零代码改动。
- ⚠️ **bundle 优先级最低，不能覆盖/替换本体贴图与声音**（re-texture 仍需松散文件）。
- **着色器例外**：只能在 bundle 中（按名称 `ContentFinder<Shader>.Get`）；编译后着色器平台相关，**三平台分别构建**并后缀命名 `*_win / *_mac / *_linux`（游戏自动选择）；推荐着色器单独一个小 bundle，其余资产放无后缀通用 bundle。
- **字体和网格只能通过 bundle 提供**（无松散路径）。
- 三方式对比（~960 贴图实测）：松散 PNG ~40MB/每次加载转换；DDS ~230MB 最差；Bundle ~28MB 最优（构建后不可编辑）。

## F. Workshop 发布硬性要求

来源：Modding Tutorials hub 上传说明（2026-09-05 抓取）。

- 上传走**开发模式** + Steam 版本。
- `About/Preview.png`：**640×360 或 1280×720 PNG，必须 < 1MB**。
- Workshop 描述使用 **BBCode（不是 Markdown）**。
- 常见报错：`OnItemSubmitted Fail`、`Error : Limit Exceeded`（超 1MB 或尺寸不符时优先排查）。
