# PersonalChronicle 勋章提示词组（按 AI 生图规范填充）

> 配套规范：`docs/参考清单/勋章AI生图规范.md`
> 本文件把全部 31 枚勋章（11 系列：10 系列各 3 档 + Craft_MajorProject 仅金质）逐一填入 Master Prompt 的 【】 占位，可直接交给生图 Agent。
> 通用负面提示词（每个勋章共用，见文末）不重复展开。 全局硬约束：① 背景强制透明（RGBA Alpha，移除背景）；② 全部勋章朝向/姿势一致统一（正面正交、人物正面直立居中）。
> 材质按档位：Bronze=bronze（深铜/青铜）· Silver=silver（明亮银色）· Gold=gold（高亮黄金）。
> 已按家族切为三批分文件，便于分批生图：`批次1_劳动系`(9) / `批次2_战斗供应系`(12) / `批次3_传承成就系`(10)。
