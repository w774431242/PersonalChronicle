> 取证基准：**游戏版本 1.6.4871 rev590**（`E:\SteamLibrary\steamapps\common\RimWorld\Version.txt`）。
> 代码事实来自本机 `Assembly-CSharp.dll` 的 **Mono.Cecil 静态取证**（skill `rimworld-assembly-api-verify`，离线，不加载程序集、不触发沙箱反射拦截）；游戏内容来自官方 Wiki / 灰机中文 Wiki / Ludeon 论坛。
> 标注：`[Cecil]` = 代码实证；`[Wiki]` = 公开资料（未做游戏内验证）；`[IL]` = 已读 IL 体确认常量。
> 适用：支撑「殖民地综合管理系统」的 **派系经济建模（MVS 派系扩展）** 设计。

---

## 0. 结论速览

- 原版派系由 **`FactionDef`（数据）** + **`Faction`（运行时实例）** 两层构成；`FactionDef` 是唯一配置源，`Faction` 是带好感/关系/领袖/意识形态的运行实例。
- 原版 **没有「经济」字段**：`Faction`/`FactionDef` 均无财富、贸易量、人口、生产率等经济属性。经济完全由交易 / 任务 / 袭击掉落等系统**涌现**，无原生经济面——这正是本 mod 派系经济建模要补的层。
- 派系间唯一标量关系是 **好感度（goodwill，整数）**，经阈值映射为 `Hostile / Neutral / Ally` 三态，带迟滞（hysteresis）。
- 外交/经济交互面集中在：`FactionDef` 的 **交易员种类（TraderKindDef）**、**帝国爵位与许可（RoyalTitleDef / RoyalTitlePermitDef）**、以及 **任务系统（QuestPart_FactionGoodwillChange 等）**。

## 1. 游戏内容：原版有哪些派系

### 1.1 原版 `FactionDef` 全清单（来自 `FactionDefOf`，`[Cecil]`）
代码中硬编码引用的 24 个 `FactionDef`：

| 分类 | defName | 说明 |
|------|---------|------|
| 玩家 | `PlayerColony` / `PlayerTribe` | 你的殖民地 / 部落开局 |
| 外来者 | `OutlanderCivil` / `OutlanderRough` | 文明外来者（中立）/ 粗野外来者（默认敌对） |
| 部落 | `TribeCivil` / `TribeRough` | 温和部落（中立）/ 彪悍部落（敌对） |
| 海盗 | `Pirate` / `PirateWaster` | 海盗团 / 废土海盗（DLC Biotech 异种） |
| 帝国 | `Empire` | 皇权 DLC 派系（爵位/灵能/许可） |
| 吸血鬼 | `Sanguophages` | 血族派系（Ideology 相关） |
| 临时/事件 | `OutlanderRefugee` / `Beggars` / `Pilgrims` | 难民 / 乞讨者 / 朝圣者（任务临时派系） |
| 商人工会/打捞 | `TradersGuild` / `Salvagers` | 交易行会 / 打捞者（Odyssey 相关） |
| 非人形/隐藏 | `Mechanoid` / `Insect` | 机械族巢 / 虫巢（永久敌对） |
| 古代 | `Ancients` / `AncientsHostile` | 中立古代人 / 敌对古代人（冷冻舱） |
| 异常 | `HoraxCult` / `Entities` | 霍拉克斯邪教 / 实体（Anomaly DLC，永久敌对） |

### 1.2 基础派系与 DLC 扩展（`[Wiki]`）
- **本体 3 类基础**：外来者、部落、海盗；皇权 DLC 加第 4 类 **帝国**；另有隐藏的 **古代人 / 虫巢 / 机械族巢**。
- 默认世界（未自定义数量）通常生成 **6–10** 个派系：1 文明外来者、1 粗野外来者、1 温和部落、1 彪悍部落、1 野蛮部落、1–2 海盗团、帝国、机械族巢、虫巢。
- DLC 增量：Ideology（温和部落变体、食人/天体部落、血族）、Biotech（尼人部落、魔族部落、亚基基海盗、废土海盗）、Anomaly（霍拉克斯邪教、实体）。
- **永久敌对**：机械族、虫巢、实体对所有派系永久敌对（除虫巢对实体）；野蛮部落、海盗、粗野外来者对玩家永久敌对，好感不可改善（`permanentEnemy` / `naturalEnemy` 字段，`[Cecil]`）。

### 1.3 各派系的游戏内容（`[Wiki]`，供经济建模参考）
- **定居点（Settlement）**：世界生成时按 `settlementGenerationWeight` 生成多处基地，可商队交易 / 突袭摧毁（摧毁全部基地=派系覆灭，不再袭击/出现于任务）。`[Cecil]` 字段：`settlementGenerationWeight`、`settlementLootMaker`、`settlementTexturePath`。
- **袭击（Raid）**：由 `pawnGroupMakers`（组队模板）+ 袭击策略（`RaidStrategyDef`）+ 点数曲线驱动。机械族= Mech Cluster（休眠阵地），虫巢= 地下爆发，古代= 冷冻舱苏醒。
- **交易（Trader）**：商队 / 轨道交易船 / 访客商人 / 基地商人，由 `caravanTraderKinds`/`orbitalTraderKinds`/`visitorTraderKinds`/`baseTraderKinds` 决定售卖表（`[Cecil]`）。
- **帝国专属**：爵位（自由民→…→总督，共 7 级可获）、灵能（psylink）、**许可（Permit）**（空投部队/轰炸/穿梭机/劳工队等）、皇家好感（RoyalFavor）、荣誉（Honor，独立于好感）。`[Cecil]` 类型：`FactionPermit`、`RoyalTitleDef`、`RoyalImplantRule`。
- **任务系统**：大量 `QuestPart_*` / `QuestNode_*` 以派系为参数（好感变更、贸易请求、借出殖民者、设置派系等），是派系经济交互的主要脚本化入口（`[Cecil]` 见类型清单）。

### 2.2 `FactionDef` 关键字段（`[Cecil]`，对 mod 配置最重要）
- **身份/生成**：`isPlayer`、`fixedName`、`factionNameMaker`/`settlementNameMaker`（命名规则包）、`humanlikeFaction`、`hidden`、`techLevel`、`colorSpectrum`、`listOrderPriority`。

- **敌对性**：`naturalEnemy` / `permanentEnemy` / `permanentEnemyToEveryoneExcept`（帝国对玩家外全敌，自定义玩家派系需 patch `permanentEnemyToEveryoneExcept` 才能交好，`[Wiki]`）/ `hostileToFactionlessHumanlikes` / `mustStartOneEnemy` / `raidsForbidden`。

- **交易**：`caravanTraderKinds` / `orbitalTraderKinds` / `visitorTraderKinds` / `baseTraderKinds`、`canRequestTraders`/`canRequestMilitaryAid`/`canRequestOrbitalTrader`/`canGenerateQuestSites`。
- **成员/文化**：`basicMemberKind`、`fixedLeaderKinds`/`leaderForceGenerateNewPawn`、`backstoryFilters`、`xenotypeSet`、`melaninRange`、`allowedCultures`、`requiredMemes`/`allowedMemes`/`disallowedMemes`、`classicIdeo`/`fixedIdeo`/`ideoName`。
- **帝国**：`royalTitleTags`/`royalTitleInheritanceRelations`/`royalTitleInheritanceWorkerClass`/`royalImplantRules`/`royalFavorLabel`、`HasRoyalTitles`、`RoyalTitlesAwardableInSeniorityOrderForReading`。（`[Cecil]` 属性：`HasRoyalTitles` / `RoyalTitlesAllInSeniorityOrderForReading`）

### 2.3 `Faction` 运行时实例字段（`[Cecil]`）
`def`、`name`、`loadID`、`colorFromSpectrum`、`relations`（List<FactionRelation>）、`leader`、`kidnapped`、`defeated`、`questTags`、`ideos`（FactionIdeosTracker）、`hidden`/`temporary`、`deactivated`、`allowGoodwillRewards`/`allowRoyalFavorRewards`、`factionHostileOnHarmByPlayer`、`naturalGoodwillTimer`、`RoyalThingUseViolationGoodwillImpact`（static）。
- 重要方法：`GoodwillWith(other)` / `BaseGoodwillWith` / `RelationKindWith` / `TryAffectGoodwillWith(...reason)` / `Notify_MemberTookDamage/Died/Captured/Stripped` / `GenerateNewLeader` / `TryMakeInitialRelationsWith` / `CheckReachNaturalGoodwill`。
- 静态快捷访问：`OfPlayer` / `OfMechanoids` / `OfInsects` / `OfEmpire` / `OfPirates` / `OfAncients` / `OfHoraxCult` / `OfEntities` / `OfTradersGuild` / `OfSalvagers`（同时存在于 `Faction` 与 `FactionManager`）。

### 2.4 派系生成数据流（`[IL]` `FactionGenerator.NewGeneratedFaction`）
1. `new Faction()` → 设 `def`、`loadID`（`UniqueIDsManager.GetNextFactionID`）、`colorFromSpectrum`（`NewRandomColorFromSpectrum` 从 `colorSpectrum` 取）。
2. `humanlikeFaction` → `new FactionIdeosTracker` 并按 `ideoGenerationParms` 生成/选用 Ideo。
3. 名称：`fixedName` 优先；否则用 `factionNameMaker` 生成（最多 10 次尝试，长度上限 **20**），避免与现有派系重名。
4. 与所有现有派系 `TryMakeInitialRelationsWith`（初始好感由 `<GetInitialGoodwill>` 内部方法决定）。
5. 非玩家且非隐藏 → `TileFinder.RandomSettlementTileFor` 生成 **Settlement** 世界对象 + `SettlementNameGenerator` 命名。
6. `TryGenerateNewLeader` 生成领袖。
- 世界生成入口：`WorldGenStep_Factions.GenerateFresh` → `FactionGenerator.GenerateFactionsIntoWorldLayer`（`[IL]` 已确认仅 1 层转发）。`[注意]` 具体「按计数选哪些 FactionDef」逻辑在 `GenerateFactionsIntoWorldLayer`/`InitializeFactions`（private），本次未展开 IL——如需精确复刻随机性，后续补 `il RimWorld.FactionGenerator GenerateFactionsIntoWorldLayer full`。

## 3. 外交与好感机制（`[IL]` 实证）

### 3.1 关系三态阈值（`FactionRelation.CheckKindThresholds`，`[IL]`）
常量：**-75 / 0 / +75**。
- `goodwill <= -75` → **Hostile**（kind=0）。
- `goodwill >= +75` → **Ally**（kind=2）。
- 介于之间 → **Neutral**；且 **迟滞**：Hostile 仅在 `goodwill >= 0` 才回 Neutral，Ally 仅在 `goodwill <= 0` 才回 Neutral。→ 不会在阈值附近反复横跳。
- `FactionRelationKind` 枚举：`Hostile=0 / Neutral=1 / Ally=2`（`[Cecil]`）。

### 3.2 自然好感回拉（`Faction.CheckReachNaturalGoodwill`，`[IL]`）
- 跳过条件：玩家派系 / 无好感 / `permanentEnemy`。
- 目标区间 = `NaturalGoodwill ± 50`。
- 若当前好感落在区间内 → 重置 `naturalGoodwillTimer`。
- 在区间外 → 累加计时器；每 **3,000,000 ticks（≈50 游戏日）** 触发一次，朝区间边界施加 `Δ = Mathf.Min(10, 距离)`，即**回拉上限 ≈ 0.2 好感/天**（静态取证值）。
- `[Wiki]` 记录部落有「超 50 每日 -0.4、低于 -80 每日 +0.2」的逐日漂移——该逐日速率未在本次 IL 中复现（可能由其它路径/XML 控制），如需精确数值需进一步核对。

### 3.3 好感变动修正（`Faction.CalculateAdjustedGoodwillChange`，`[IL]`）
- 含常量 **`0.25`**（ldc.r4 0.25）：用于「朝自然好感区间靠近时放大、远离时按 0.25 系数衰减」的修正（方向性行为由 IL 比较分支决定，建议后续结合完整 IL 复核非对称细节）。
- 入口：`TryAffectGoodwillWith(other, change, canSendMessage, canSendHostilityLetter, reason, lookTarget)`，`reason` 为 `HistoryEventDef`（如 `ReachNaturalGoodwill`、杀人/俘虏/拆建筑等事件驱动的好感增减）。

### 3.4 好感影响事件（`[Cecil]` `Faction` 的 `Notify_*`）
`Notify_MemberTookDamage` / `Notify_MemberDied` / `Notify_MemberCaptured` / `Notify_MemberStripped` / `Notify_BuildingRemoved/TookDamage` / `Notify_MemberExitedMap`（离场好感，含健康判定 `GetGoodwillGainForExit`）/ `Notify_PlayerTraded`（交易额→好感）/ `Notify_RoyalThingUseViolation`（使用皇室物品违规→好感冲击，`RoyalThingUseViolationGoodwillImpact`）。
- 赠礼换算：`FactionGiftUtility.GetGoodwillChange`（按市场价值换算好感，`[Cecil]`）。

## 4. 经济交互面（对派系经济建模最相关）

1. **交易面**（`FactionDef` 的 4 类 `TraderKindDef` + `canRequest*` 开关）——派系对外经济的「售卖表/可请求性」全在这里。本 mod 经济机构（商店/工资）是**平行体系**，可桥接。
2. **帝国平行体系**：爵位（`RoyalTitleDef`）、许可（`RoyalTitlePermitDef`/`FactionPermit`）、皇家好感（`RoyalFavor`，独立于 goodwill）、荣誉（Honor，独立于 goodwill）。这些是**与好感解耦的独立子系统**，建模派系经济时须区分「好感（外交）」与「皇家好感/爵位（帝国内部）」。
3. **任务面**：`QuestPart_FactionGoodwillChange` / `FactionRelationChange` / `FactionGoodwillLocked` / `InitiateTradeRequest` / `LendColonistsToFaction` 等，是派系经济/外交被脚本化驱动的主入口。
4. **袭击面（经济负向）**：`pawnGroupMakers` + `raidCommonalityFromPointsCurve` + `maxPawnCostPerTotalPointsCurve` 决定来袭规模/战利品（`raidLootMaker`/`raidLootValueFromPointsCurve`）。

> **关键事实**：原版 `Faction`/`FactionDef` **无任何经济字段**（无财富、贸易量、人口、产能）。派系「经济」完全由上述交互系统涌现。本 mod 的 MVS 派系经济建模（见 `docs/设计文档/方案/市场经济框架_派系建模扩展设计方案.md`）正是要补这一层——推荐做法（来自既有设计）：用 `FactionDefFieldDeriver` 只读官方字段、运行时据点计数驱动锚定（`方案A`），不硬编码、不按 `FactionDef` 字符串比较，第三方 mod 派系自动覆盖。

## 5. 给本 mod 派系经济建模的可用事实与扩展点

- **配置层**：新增派系经济字段应走**自定义 `FactionDef` 子类 + 全限定名 XML 根**（避免短名加载失败，见工作区 `MEMORY.md` 的 P0 铁律）；`FactionDef` 已预留 `techLevel`/`xenotypeSet`/`colorSpectrum` 等官方字段可作 `FactionDefFieldDeriver` 反推源。
- **实例层**：`Faction` 可挂 `GameComponent` 或扩展 `relations` 之外的新关系表；好感阈值（-75/0/75）与迟滞逻辑是**公共因子**，建模派系态度时直接复用 `Faction.GoodwillWith`/`RelationKindWith`，不要自造好感标度。
- **帝国**：若经济机构要对接爵位/许可，走 `RoyalTitleDef`/`RoyalTitlePermitDef`/`FactionPermit`，与 goodwill 解耦。
- **生成期**：世界生成用 `FactionGenerator`；若要在生成时注入经济初始状态，挂 `WorldGenStep_Factions` 之后或 `FactionManager` 初始化钩子（注意 `generateNewLeaderFromMapMembersOnly` 等官方开关）。
- **性能/安全**：`FactionManager.AllFactions` 为枚举，热路径用 `AllFactionsListForReading`；`Faction.RelationWith(other, allowNull)` 在缺关系时返回 null，调用方须判空。
