# 总览数据面板 · 属性数值字段清单

> 用途：职业档案-总览（`ITab_Pawn_Career.Overview.cs` 的 `DrawAttributePanel`）下半区
> 「原版属性数据面板」应展示的**具体数值字段**全集。
> 设计约束（用户要求）：展示当前人物的具体派生数值（移动速度、工作效率等），
> 而非原始技能列表。所有字段必须能在 IMGUI 内实时取得（直读 pawn 或快照）。

> ⚠️ **数据来源声明（2026-08-27 校正）**：以下 StatDef 名称**全部来自 RimWorld 1.6 游戏文件
> `Data/Core/Defs/Stats/` 实际解析**，非凭记忆臆造。此前版本文档中的 `SmithingSpeed`/
> `TailoringSpeed`/`ArtSpeed`/`DrugSynthesisSpeed`/`ShootingAccuracy`/`DodgeChance`/
> `DiseaseResistance`/`AnimalTrainSpeed`/`PlantExtractYield`/`PrisonerWarmupRate` 等
> **在 1.6 中根本不存在**，是导致面板显示 `—` 的直接原因，已全部修正。
>
> 🔗 **联网核验（2026-08-27）**：
> - Wiki「Global Work Speed」确认 `WorkSpeedGlobal` 存在，最小值 30%、默认 100%、为所有工作速度的乘数（articles verified for 1.5.4104，机制延续至 1.6）。
> - GitHub 社区 Stat 提取器确认 `shootingaccuracypawn`（`ShootingAccuracyPawn`）、`meleedodgechance`（`MeleeDodgeChance`）为 1.6 真实 defName（原文档 `ShootingAccuracy`/`DodgeChance` 为臆造，已修正）。
> - Wiki 确认 1.6 Mod API 变更（路径寻路多线程、光照多线程、蓝图/计划系统、可变 Tick 速率）与本文档 §124 一致。
> - 当前最新稳定版：**RimWorld 1.6.4850（2026-06-08）**，文档基准 1.6.4633（2025-11-04）仍为有效 1.6 构建。

> 🛠️ **自定义属性面板行为（2026-08-28 字段体检修正）**：玩家可在总览面板勾选想看的字段，偏好持久化。
> 启动期 `OverviewFieldRegistry.ScanExternal()` **自动扫描全部已加载 mod 的 StatDef / NeedDef**，
> 仅注册「适用于 pawn」的真实原生字段，归入「原版属性」组；第三方 mod 按各自 PackageId 成组、可钻取。
>
> ⚠️ **重要修正：pawn 属性判定不能用 `category.defName.StartsWith("Pawn")` 前缀！**
> 全量解析 `Data/*/Defs/Stats`（含 `ParentName` 继承链）后证实：pawn 相关 stat 分布在**多个**分类，
> 除 `Pawn*` 系列外还有 `BasicsPawn`（MoveSpeed/CarryingCapacity/CrawlSpeed/FilthRate…）、
> `Mechanitor`（机械师）、`Mechanoid`（EMPResistance）、`Animals`（Wildness/MinimumHandlingSkill）、
> `Meditation`（MeditationFocusStrength）等。旧前缀判定漏掉 **33 个**真实原生字段。
> 现改为**显式分类白名单**（15 个分类）+ 零散补充集 `ExtraPawnStatDefs`（MaxInstallCount /
> BedHungerRateFactor / ArmorRating_Heat），覆盖数 92 → **125**。
>
> 硬编码精选的 22 个 StatDef + 4 个 NeedDef（`KnownVanillaStatDefs` / `KnownVanillaNeedDefs` 排重集）
> 不会与自动扫描重复。Thing-only stat（市场价值/质量/原料护甲等）因取数无意义已被自动排除。
> 取数均经 `try/catch` 兜底，绝不向 Player.log 抛错。

## 三、数据面板推荐布局（落地指引）

复用 `DrawAttributePanel` 现有模式（直读 pawn + UIComponents.ProgressBar）。

├─ 移动与体能
│  移动速度            4.60 格/s
│  搬运上限            35 kg
│  综合健康分          87 / 100
├─ 战斗生存
│  近战 DPS            12.3
│  射击精度(人)        6.2 格
│  锐器护甲            42 %
│  近战闪避            15 %
├─ 社交心智

> 所有字段均经 IMGUI 原生控件绘制，无 CSS；数值取数符合档案契约（pawn 活事实直读级别）。
