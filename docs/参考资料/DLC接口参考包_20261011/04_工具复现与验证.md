# 工具复现与验证

工具只读取游戏程序集、配置、官方 XML 和本项目源码，写入指定输出目录。不启动游戏、不运行其静态构造器、不修改 activeMods，不创建 Harmony Patch。

## 依赖

- Python 3（仅标准库）；本次使用 Codex 本地 Python。
- PowerShell 7（`pwsh`）。JSON 含大小写不同的类型键；PowerShell 读取 inventory 时使用 `ConvertFrom-Json -AsHashtable`。
- Mono.Cecil 0.11.5；传入本机 DLL 路径，不随资料包复制。
- 可选 ilspycmd。本次阅读使用 8.2.0.7535；复现反编译须先在本机具备此工具及兼容 .NET 运行时。反编译器不同可能使文本不同，程序集哈希与 IL 才是版本依据。

## 重新采集

在解压后的参考包根目录执行。以下路径是本次环境示例，可自行替换；输出建议用新目录保留原始快照。

```powershell
python -X utf8 ./tools/collect-reference.py `
  --game-root 'E:/SteamLibrary/steamapps/common/RimWorld' `
  --repo-root 'E:/SteamLibrary/steamapps/common/RimWorld/11/殖民地综合管理系统' `
  --cecil-path 'C:/Users/Administrator/.nuget/packages/mono.cecil/0.11.5/lib/netstandard2.0/Mono.Cecil.dll' `
  --mods-config 'C:/Users/Administrator/AppData/LocalLow/Ludeon Studios/RimWorld by Ludeon Studios/Config/ModsConfig.xml' `
  --output './snapshot-new'
```

不指定 `--mods-config` 时状态为 Unavailable/Unknown，而非全部未启用。遇到不支持的原版类型、畸形 XML、复制源码不一致或采集期间 DLL 变化，工具直接失败，不输出“完整验证通过”的结论。

未来新增 DLC 需要检查 `PACKS` 列表和本机原版 API 后扩展工具；本包固定遍历本次 Core + 5 个 DLC，不能当作永远自动支持未知扩展的加载器。XML 扫描范围也不含 Languages、纹理、音频或 AssetBundles 的内部对象。

## 查看完整反编译代码

```powershell
pwsh -NoProfile -File ./tools/decompile-local.ps1 `
  -GameRoot 'E:/SteamLibrary/steamapps/common/RimWorld' `
  -OutputDirectory './local-decompiled'
```

本工具输出 16 个关键原版类型的 `.decompiled.cs.txt`。这是对自己的本地程序集生成的阅读结果；不会自动编译/部署，也不包含在本次 ZIP 中。不同版本需要重新阅读分支，不能用旧反编译文本覆盖原版。

快速定位方法：

```powershell
rg -n 'LoadAllActiveMods|ParseAndProcessXML|legacy-xml-deserializer' ./local-decompiled
rg -n 'MayRequire|ValidateMayRequires|XmlInheritance|Register.*CrossRef' ./local-decompiled
rg -n 'GetAllFilesForMod|InitLoadFolders|ShouldLoad|RecacheActiveMods' ./local-decompiled
```

也可直接读 `snapshot/runtime-api-index.md`，再按签名搜索 `runtime-api-and-il.json`。selectedIL 中的 IL 偏移和分支完整保留；calls 包含 call/callvirt/newobj/ldftn/ldvirtftn，不能把所有记录都当作立即执行的调用。

## 验证与打包

```powershell
python -X utf8 ./tools/validate-reference.py `
  --bundle '.' `
  --game-root 'E:/SteamLibrary/steamapps/common/RimWorld' `
  --repo-root 'E:/SteamLibrary/steamapps/common/RimWorld/11/殖民地综合管理系统' `
  --zip '../DLC接口参考包_复核.zip'
```

不提供 game-root/repo-root 时只做包内证据和工具夹具检查；提供时增加原始文件集合、逐 XML 哈希、About/程序集/源码哈希检查。ZIP 校验 CRC 与 manifest 内每个文件的 SHA-256。manifest 不包含自身哈希；ZIP 哈希由工具 stdout 报告。重新验证会更新 validation.json，因此需重新生成 manifest/ZIP。

检查范围包括：原版加载阶段顺序、新/旧解析器入口、全部 DLC 的安装/启用 API、条件过滤方法、原始计数一致性、注释不产生假定义、XML 精确行号、抽象模板与 defName 区分、缺失配置保留未知、坏 XML 报错、源码复制一致性。

通过表示 **MetadataAndToolVerified**。没有运行游戏验证已加载 Def、具体 DLC 行为、第三方补丁效果、未来接口实现或部署。接口示例保持 `.cs.txt`，位于 docs 下，不进入当前生产 csproj 的 Source 显式编译范围。
