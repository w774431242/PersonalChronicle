# 移除独立档案馆，统一由人员系统中心承载

本轮保留版本 0.1 与独立标识 `colony.integratedmanagement`。

## 修改结果

- 移除 `PersonalChronicleArchive` 主按钮定义，底栏仅保留“总控中心”，使用管理系统图标。
- 移除 `ArchiveMainTabWindow` 窗口类型及其 RequestedTabSize、DoWindowContents、独立首页、侧栏和紧凑导航代码。
- 共享档案内容迁入 `Source/PersonalChronicle/MasterControl/Population/PersonnelArchivePanel*.cs`，改为普通面板，不继承 Window。
- 总控中心实例持有面板；新的 PersonnelArchiveHost 只负责绘制矩形、异常隔离与 GUI 状态恢复，不查旧按钮 Def，不创建独立标签页。
- 保留人员中心的档案总览、人物详情，以及物品、战役、地点和事件下钻能力；制造事件面板使用迁移后的公共文本渲染方法。
- 移除独立首页闲置的时间线读取、最近事件和重要档案缓存；人员中心仍使用的档案规模统计继续保留。
- 保留档案服务、记录采集、存档字段、模组标识与第三方业务 API。`Archive` 数据层和公共 UI 工具仍有使用者，未做整目录删除。
- 中文界面标题统一为“殖民地综合管理系统 · 总控中心”，档案面板标题改为“档案总览”；About 与 README 的入口说明同步更新。
