## 7. 命名语义与治理映射（速查）

- **后缀职责**（[TERM-004](设计文档/架构/00-统一术语与定义.md#4-命名语义)）：`*Def`=静态 Def；`*Service`=业务用例；`*Snapshot`=只读投影；`*Accumulator`=累计器；`*Patch`=Harmony 钩子；`*Window`/`*Panel`/`*Dialog`=UI 容器；`*Keys`=翻译/稳定 key 常量。
- **partial 治理**（ARC-013）：`ArchiveService`(7 子文件)、`ChronicleGameComponent`(3 子文件)、`ArchiveMainTabWindow`(主+19 子)、`ArchiveUiDataProvider`(4 子)、`SectionSnapshots`(4 子) 均为物理切片，零契约改动。
- **分层归位**：Domain 纯逻辑 / Application 编排 / Data 持久化 / Capture 钩子 / Archive UI / Api 契约，单向依赖（[MATRIX-001](设计文档/架构/00-规范关系矩阵.md)）。
