第〇章一句话理解

Personal Chronicle 会在你玩游戏的每一刻，静默地记下殖民地里发生的一切——谁加入了、谁死了、谁造了什么、谁打了什么仗、谁住在哪里、谁又成了某某"大师"。

它不替你决定任何事，只是把事实记成档案。但有些档案，会反过来给小人真实的加成：勋章的荣耀、职业的专精、职称的认可。

第一章档案馆是什么

1.1 入口

启用模组后，游戏主界面底部的标签栏会出现一个 「档案馆」 按钮（排在靠后位置，不干扰原版）。点击它，打开一座四层档案库。

1.2 四大类档案

分类记录谁 / 什么你能看到
人物每一个殖民者、奴隶、囚犯工时、战斗、社交、足迹、健康、职业、勋章
物品武器、装备、工坊产物谁造的、谁抢的、谁继承的、它杀过谁
战役每一场袭击与战争参战双方、关键节点、战果
地点每一处被访问、被争夺的角落谁长期驻留、谁远征过、谁在此建造/销毁

1.3 核心概念：事实 ≠ 评价

模组有一条铁律：

事实记录只记"发生了什么"，不记"这人有多好"。

例如，它记"张三在 5510 tick 制造了一件优秀机械部件"（事实），不直接记"张三是优秀工匠"（评价）。评价，是由职业系统、资格系统、勋章系统在事实之上慢慢推算出来的。

这就是为什么：旧档补不回历史——因为事实必须在事件发生的那一刻才被捕捉。

1.4 实时记录 vs 历史快照（双轨）

档案馆首页区分两种数据：

活读 Live

游戏此刻的真实事实，如当前在场的殖民者。

档案 Archive

历史累计的快照记录，如已归档的全部事件。

这样能避免把冷冻舱里的人算进"当前人口"，也不会因为临时增援而乱建档。

第二章人物档案详解

点开任意一个小人，你会看到一张"六宫格"主面板，以及多个子视图。

2.1 六宫格主面板

每一格遵循统一基准：大数字 + 同行动态指标 + 两行 KPI + 三条固定进度条（数据为空时显示 --，布局不会抖动）。

宫格记录内容
工时生涯累计工时、日均工时
产出周产出 / 净值、产值构成
击杀猎物种类、参战战役数、生涯伤害、击杀构成
损耗累计折银（进食/用药折算）、周/日均、构成 Top3
足迹主驻地 / 远征、停留地点 Top3
传承锻造者是谁、传承链上的击杀占比

2.2 子视图一览

概览

生命阶段、健康残值三维评分、职业快照。

编年史

事件时间轴，点一行可展开描述。

生涯

累计工时、劳动强度档位、工作场所与住所。

战斗履历

击杀边 + 参战名册。

社会关系

恋爱/婚姻/亲缘的结成与结束（网络图）。

足迹

地点进出履历。

健康残值

肢体/精神/未衰老三维评分 + 银币估值。

职业 / 勋章

见第三、第四章。

2.3 劳动强度五档

模组会评估每个人的"牛马程度"（纯函数，阈值由数据驱动）：

档位累计工时阈值（约）
核动力驴（T0）≥ 12 小时/天
超级牛马（T1）≥ 9 小时/天
常规牛马（T2）≥ 6 小时/天
劣质牛马（T3）≥ 3 小时/天
社会懒汉（T4）< 3 小时/天

中途加入的存档，以"模组接入后的天数"为分母计算，绝不崩。

2.4 健康残值估值

模组给每具身体估个价（数据驱动，可被其他 Mod 调整）：

基准

1500 银，每年折旧 2%；下限 50。

阈值

青春 85 / 受损 60。

病症罚金

哮喘10% / 驼背12% / 白内障8% / 衰弱15% / 糖尿病10% / 酗酒10% / 化学损伤20%。

第三章职业系统（制造类先行）

职业系统当前以 制造类 作为第一个完整垂直切片，其余 11 个专业（工程/农业/林业/畜牧/医学/武器/矿业/科研/烹饪/艺术/管理）将随各自垂直切片逐步开放。

3.1 第一原则：职业 ≠ 原版技能

原版 RimWorld 的"技能（Skill）"是证据，不是职业本身。

Crafting 16 Construction 14 Intellectual 12 + 你真实做过的制造工作 + 你造出的成果 + 你的职业履历 ↓ 制造类 专业能力
原版 Skill 是基础能力证据，Professional Skill（专业技能）是模组自己的长期能力模型。

3.2 专业四层结构

一级专业（12 类之一：制造）
└── 二级方向（制造类 = 精密 / 武器 / 装备 / 工业）
　　└── 专业技能（如：精密制造）
　　　　├── 能力维度（加工 / 精度 / 工艺 / 材料 / 质控）
　　　　└── 专业效果（速度 / 品质 / 配方 / 材料 / 特殊工作）

3.3 事实层：CareerEvent（职业履历）

每一次真实制造，都会写入一条 CareerEvent，记录：谁、什么时候、做了什么、用的什么配方、造了什么、什么品质、造了几件。

职业履历是整个职业系统的"长期事实数据库"——后面所有评价（能力、评级、资格、职称、勋章）都从它派生，且评价规则改了，历史事实永远不变。

3.4 专业能力怎么长出来

你每制造一次，系统按 「行为 → 能力映射矩阵」 把经验分给不同能力维度，不是五维等量增长。制造类能力维度：

能力含义典型获取
加工能力基本加工操作大多数制造
精度控制精密操作精密机械、电子件
工艺理解工艺/流程理解复杂配方、研究关联
材料应用材料选择与利用高级材料制作
质量控制品质把控高品质产出/检视

3.5 经验公式（XP）

单次实践 XP = 基础实践值（默认 10）
× 配方相关度（匹配 1.0 / 仅工作类型 0.5 / 无匹配 0）
× 品质系数（普通 1 / 良好 1.2 / 优秀 1.5 / 大师 3 / 传奇 5）
× 难度系数（首版 1.0）
× 数量系数（批量累加，上限 4）

等级提升采用边际递减曲线：前期升级快，后期越来越慢，防止数值失控。

3.6 二级方向推荐（推荐 ≠ 强制）

方向分 = 技能相关度 ×0.35 + 实践适配 ×0.25 + 实践质量 ×0.15 + 成果贡献 ×0.15 + 专业能力 ×0.10

推荐只是建议，你最终想走哪条路，自己选。

3.7 专业评级（4 档，由等级派生）

评级不是等级，也不是职称。它只是能力水平的一个标签，无考试门槛，由专业等级经软上限曲线自动派生：

评级触发等级说明
熟练≥ 10入门档，最低加成
专业≥ 25中段主力
高级≥ 38高段
大师≥ 45顶档，封顶不再增（递减设计）

3.8 专业效果：从"数据面板"走进"游戏机制"

专业能力真实改变你下一次工作的结果：

制造速度

通过原版 StatPart 注入配方工作速度统计。拥有技能（等级≥1）且正在制造对应配方时，制造更快。

品质倾向

制造完成后，按专业效果把产物品质整档偏移（+1 档起）。

效果全部数据驱动，且经三层隔离（Effect → Resolver → Adapter），不直接乱 patch 游戏，安全可关。

验收标准只有一句话：玩家看到的不是"制造类 72/100"这个数字，而是"这个人因为真实做过这些工作，所以形成了某种专业能力；专业能力又真实改变了他下一次工作的结果"。

第四章资格、职称与勋章

4.1 资格状态机

专业等级绝不直接等于职称。要走完一条资格认证流水线：

Locked（锁定） → Eligible（具备资格） → Preparing（准备中） → PracticalExam（实践考试） → TheoryExam（理论考试） → Thesis（论文） → Defense（答辩） → Qualified（通过） → Granted（授予职称）

失败会回到 Preparing，而不是删除进度。

4.2 五档职称（现实职称体系）

职称挂载在二级方向上，分 5 档（由低到高）：

员级 → 助理级 → 中级 → 副高级 → 正高级

以精密制造（技能人才通道，技工序列）为例，已落地的 5 档：

职称门槛等级生涯时长（tick）特殊要求
初级技工560,000—
中级技工15200,000前置：初级技工
高级技工25600,000前置：中级 + 考试/论文/答辩（最低 60/70/80 分）
技师381,200,000前置：高级技工
高级技师451,800,000前置：技师 + 至少 1 次传奇制造

4.3 考试与论文：在"玩游戏"中完成

模组刻意不做假的"考试按钮"。

实践考试

真实制造行为证据。报名后限时制造指定物品×N、达最低品质，你真实去制造，系统捕获 CareerEvent 评分。

理论考试

阅读书籍+研究项目+专业能力+理论活动，加权合成（暂无选择题 UI）。

论文

书籍+研究+成果+履历+专家参与共同形成质量，不是"+1 Thesis"。

答辩

同阵营高专业等级小人自动列为委员，玩家确认/指定，委员会评分。

4.4 勋章体系

勋章是成就的表彰，分两条路径授予：

阈值勋章

达到累计指标自动授予（工时、击杀、产出银、传承代数）。

成就勋章

由 CareerEvent 聚合出的成就键（传奇制造次数、大型项目数、已获职称数）触发。

勋章材质与增益阶梯（数据驱动）：

材质增益（通道 A 规划 / 通道 B 展示先行）
铜质+3%
银质+5%
金质+10% + 殖民地公告（Letter）+ 专属「·金质」后缀

勋章分系：劳动系战斗系后勤系传承/装备系团体系排名/荣耀系

（劳动模范/先进工作者/战斗英雄/一等功/模范供应员/传承功勋/镇库之锋/先进集体/劳模标兵 等。）

授权闭环：职业行为 → 能力 → 成果 → 资格 → 职称 → 贡献 → 勋章，最终回写 CareerEvent，形成完整事实闭环。

第五章物品、战役与地点档案

5.1 物品 / 装备档案

概览 · 编年史 · 战斗履历 · 流转记录 · 传承链（谁造的 / 谁抢的 / 谁继承的）。武器始终捕捉；服装按护甲阈值 ≥ 0.20 判定为战斗服装（数据驱动）。

5.2 战役档案

战役生命周期（开始 / 突袭次数 / 结束三 Hook）、参战双方、关键节点与战果；击杀按派系聚合去重。

5.3 地点档案与别名系统

实时地点/持有者/访问聚合（地点地图志）、远征与主驻地。建筑别名三级解析：全局别名 > 个人自定义名 > 原版标签；房间角色别名同样支持。通用改名对话框工坊/房间共用，DLC 感知。

直接关系

第八章安装与兼容

8.1 安装

① 把整个 PersonalChronicle 文件夹放进游戏 Mods 目录 → ② 启用 Personal Chronicle - Archive → ③ 确保 Harmony 在其之前加载 → ④ 主界面底部出现「档案馆」即成功。

8.2 依赖与兼容

版本

RimWorld 1.6。

依赖

仅 Harmony（唯一外部依赖）。

语言

内置简体中文与 English。

平台

Windows / macOS / Linux 均可。

与 Character Editor 等 Mod 共存；纯只读记录，不修改游戏核心机制。

8.3 存档说明（重要）

想要 100% 完整档案，请新开档。模组是"实时事件采集"，启用前发生的事补不回来。

中途加装也可用：当前在场人口会自动建档，只是缺"加装前的历史"。早期存档会自动迁移到最新对象模型（无损升级）。

第九章常见问题

中途加装老档，老成员认得出吗？

会。加载时自动为当前全部人口建档，只是其"加入事件/历史时间线"为空。

会拖慢游戏吗？

不会明显变慢。120-tick 节流刷新，后台仅做轻量补漏建档。

职业加成破坏平衡吗？

所有加成 ≤10%，且有软上限封顶（大师后不再增长）。能力须经真实工作积累，无法速成。

金质公告会刷屏吗？

不会。金质勋章公告只弹一次（去重）。

第十章概念速查表

概念一句话
CareerEvent职业系统的"事实数据库"，只记发生了什么

Medal 勋章成就表彰，铜/银/金三材质，可给真实加成
双轨统计活读（当前事实）+ 档案（历史快照），防冷冻舱虚高
