## 1. 授勋嘉奖机制（Award Mechanism）

授勋嘉奖 = 对殖民者/工坊/装备在生涯中达成某项成就的**正式褒奖行为**。机制分三层语义：

### 1.1 嘉奖类型（AwardKind）
| 类型 | 定义 | 对应现实 | 本 mod 载体 | 是否带材质 |
|---|---|---|---|---|
| **表彰**（Citation） | 轻量褒奖，通报表扬/月度表扬，不与勋章等价 | 表彰奖励（如"最美奋斗者"类） | PawnObject 标记 | 否（仅文本/勋表） |
| **奖章**（Medal） | 成就达成授予，分材质等级（铜/银/金） | 国家荣誉称号奖章 | PawnObject/ThingObject/Workplace | 是（铜/银/金） |
| **荣誉称号**（HonoraryTitle） | 最高嘉奖，金质专属，常附专属称号+公告 | 国家荣誉称号 / 勋章 | PawnObject | 金质专属 |

> 梯度：**表彰（无材质）→ 奖章（铜/银/金）→ 荣誉称号（金质专属）**。构成完整嘉奖阶梯。

### 1.2 授勋流程（Award Pipeline）
```
[累计数据] → [判定引擎] → [达阈值/达排名] → [生成授勋事件]
   PawnObject       BuildMedals          MedalDef.tier          AwardRecord
                                                          ↓
                              [写入 GrantedMedals] → [金质? → 公告Letter + 专属称号]
                                                          ↓
                              [Buff 生效] 通道A(Stat注入,阶段三) / 通道B(展示增益)
```
- **判定触发**：每 `ReconcileIntervalTicks=600` tick（挂载 `GameComponentTick`），对标现有 `LocationAtlasCapture.Reconcile`。
- **去重**：同一 `MedalDef.defName` 仅授予一次（取已达最高档），金质公告仅弹一次。
- **追溯授予**：旧档读档时按已有累计数据回溯判定（不丢历史成就）。

### 1.3 等级分类体系（Tier System）
材质三档 = **铜质 / 银质 / 金质**，语义：
| 档 | 语义 | 增益（通道A） | 视觉精致度 | 额外权益 |
|---|---|---|---|---|
| 铜质 Bronze | 初阶成就 | +3% | 低（单环/素珐琅/底3星） | — |
| 银质 Silver | 中阶成就 | +5% | 中（双线环/珠点环/底5星） | — |
| 金质 Gold | 高阶成就 | +10% | 高（三层环/叶纹/顶3星/底7星） | 公告Letter + 专属称号「·金质」 |

> 金质 = 奖章顶档，亦作为**荣誉称号**的视觉/权益载体（荣誉称号不另设独立材质，复用金质 + 额外称号后缀）。

## 2. 元件组成（Component Composition）

参考勋章学（Phaleristics）通用元件 + 中国现实章体工艺（冷压成型、花丝镶嵌、珐琅、织物绶带）。一枚勋章由以下**可复用元件**组成，批量生成时风格统一。

### 2.1 视觉元件清单（SVG/C# 几何绘制共用规格）
| 元件 | 英文 | 定义 | 规格要点 | 是否分级变化 |
|---|---|---|---|---|
| **章体** | Body/Medal | 主圆牌，承载所有图形 | 直径基准 256px，r=104 外缘 | 材质色板变化 |
| **外环** | Outer Ring | 环绕章体的金属圈 | 宽 16px，含浮雕渐变+描边 | 铜/银/金渐变不同 |
| **珐琅盘** | Enamel Field | 中心色面，承载主符号 | 深红/蓝灰等哑光珐琅渐变 | 系别色板变化 |
| **中心符号** | Central Emblem | 表达勋章主题的主图形 | 星/齿轮/剑/盾/工坊/星冠 | 系别变化（核心区分） |
| **麦穗环** | Wheat Wreath | 环绕盘面象征丰收/劳作 | 沿弧对称麦粒 | 全系通用 |
| **铭文环** | Legend Ring | 边缘刻线/文字带 | 双线刻环（银/金档） | 中高精致档出现 |
| **珠点环** | Beading Ring | 连续圆点装饰环 | 24/28 颗均布 | 中高精致档出现 |
| **叶纹环** | Laurel/Foliate Ring | 叶形装饰环 | 8 叶对称 | 仅金质 |
| **绶带** | Ribbon/Sash | 章体后的悬挂带 | 交叉结+垂带，暗红/蓝灰 | 材质色板变化 |
| **星徽** | Stars | 五角星，含底部弧排小星 | 顶部专属星（金）/底部弧排小星（铜3/银5/金7） | 数量/位置随档递增 |
| **勋表** | Ribbon Bar | 章体缩小条（列表/汇总显示） | 简化为色条（材质色+系别色） | 列表态复用 |

### 2.2 元件分级规则（渐进精致化契约）
| 元件 | 铜质 | 银质 | 金质 |
|---|---|---|---|
| 外环层数 | 1（单环） | 2（双线刻环） | 3（三层+描金边） |
| 珠点环 | ✗ | ✓（24 珠） | ✓（28 珠） |
| 叶纹环 | ✗ | ✗ | ✓（8 叶） |
| 中心符号射线 | ✗ | ✓（淡射线） | ✓（强射线+描金） |
| 顶部星 | ✗ | ✗ | ✓（3 星专属） |
| 底部弧排小星 | 3 颗 | 5 颗 | 7 颗 |
| 整体浮雕/高光 | 基础 | 中 | 强（亮金高光） |

> 此表为**资产生成唯一标准**：后续所有勋章 SVG 必须按此表套用，保证全套统一且等级可辨。

### 2.3 系别中心符号映射（Central Emblem by Series）
| 系 | 中心符号 | SVG 形状 |
|---|---|---|
| 劳动系 | 齿轮 | 八齿齿轮 |
| 战斗系 | 交叉剑/星 | 双剑交叉+星 |
| 生产损耗 | 麦束/天平 | 麦束 |
| 传承装备 | 盾+剑 | 纹章盾 |
| 团体系 | 工坊/建筑 | 厂房轮廓 |
| 排名系 | 星冠 | 多星冠冕 |

> 珐琅色板按系：劳动=红/战斗=钢蓝/生产=赭黄/传承=青灰/团体=青铜绿/排名=紫红。

## 3. Def 数据结构（落地契约，详见架构方案 §6）

```csharp
// 勋章定义（Def 驱动，AI-003）
public sealed class MedalDef : Def {
    public AwardKind awardKind;      // Citation / Medal / HonoraryTitle
    public MedalSeries series;       // Labor / Combat / Support / Legacy / Workshop / Rank
    public MedalTier tier;           // Bronze / Silver / Gold（Citation 无）
    public OwnerType ownerType;      // Pawn / Thing / Workplace
    public string metricKey;         // 绑定累计字段
    public float threshold;          // 阈值（排名类用 streakPeriods）
    public int rankTopN, streakPeriods;
    public string buffDefName;       // → MedalBuffDef
    public int order;
}
```
