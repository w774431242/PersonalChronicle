# 经济体系（功能模块）

> 本文件夹是「经济系统中心」深化的主工作区。
> 定位：**殖民地产能 → 库存 → 财富的观测与记账层**，而非「模拟市场」。
> 立项红线：**账本纯观测，绝不反写 `MarketValue` / `wealthWatcher` / 任何影响财富的值**。
>
> ⚠ **红线范围限定**（2026-09-19 补，依据 `EXC-MVS-001` §8）：本红线**只约束「经济体系」账本线**。
> 项目内另有两条**独立**的线，各有自己的约束，**互不覆盖**：
>
> | 线 | 能否反写 `MarketValue` | 依据 |
> |---|---|---|
> | **经济体系（本线 · 账本）** | ❌ **不可** | 本红线 |
> | MarketFramework（**独立 MOD**，不进主 mod） | ❌ **不可**（动态价走 Harmony 价格出口） | `市场经济框架/EXC_动态价格登记.md` §3 |
> | **MVS 定价通道 A**（主 mod 内，`Source/PersonalChronicle/MVS/`） | ⛔ **已删除**（2026-09-20 `CHG-LCE-001`：MVS 市场体系整体移除、`EXC-MVS-001` 作废 ⇒ 红线恢复零例外） | `市场经济框架/EXC_MVS定价通道A.md`（Obsolete） |
>
> **为什么要补这条限定**：三条线的红线原本就只约束各自子系统，但文档里**没写边界** ⇒
> 字面上 MVS 成了"违反红线却没人管"的一方，**红线因此失去约束力**（一条被违反却无处置的红线
> 等于没有红线）。写明边界后，本红线恢复**精确的适用范围**。
>
> 创建日期：2026-09-15

## 二、立项前必须先拍板的三个问题（来自原版调研 8.3）

1. **要不要做「市场动态价格」？**
   - 做 = 与 `TradeUtility` 固定 1.4/0.6 公式冲突，需 Patch 且影响原版难度平衡；
   - 不做 = 经济中心退化为「只读观测 + 记账」，风险低、与原版零冲突。**默认推荐不做**。
2. **财富口径用哪个？** 建议 UI 统一 `WealthTotal`，SDD 明确禁止把 `PlayerWealthForStoryteller` 用于展示。
3. **记账粒度？** 日/候/月归档（对齐 PC 既有 ArchiveService 快照双轨）vs 连续流水；涉及存档 schema 变更，需过 GATE-DATA / GATE-SAVE。

## 三、深化路线（建议执行顺序）

1. 拍板「三问」→ 冻结 SDD 定位（见 `经济系统中心_SDD路线图与子系统切分.md`）。
2. 子系统切分：产能与获取途径 / 库存与物流 / 财富与账本 / 趋势与曲线 / 贸易与金融（金融为可选不立项项）。

5. UI 落地：`系统中心蓝图/经济系统中心预览_*.html` → 游戏内分块（过 GATE-UI）。
