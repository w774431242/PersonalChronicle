# 自主经济社会与玩家角色：总体设计 v0.5

> 当前制度以[公有机构与外贸循环 v0.7](公有机构与外贸循环_优化方案_v0.7.md)为准：机构全部公有、由玩家经营，公共自然资源保持合法可用，加工产品与已适配服务收费，外贸实资投入支撑工资循环。本文涉及私有/多元经营、自主经营者的设想不进入当前范围；机构自主运行只执行玩家授权的日常规则。

2026-10-08。状态：设计讨论，不修改运行代码。目标依据用户提出的玩家角色变化：从逐人劳动安排和共同物资分配，逐步转向建设机构、制定制度、组织公共服务，让 Pawn 自主处理个人与家庭的生活、就业、消费和储蓄。

本册确定产品方向；个体需求与资金逻辑沿用[需求缺口 v0.3](原版需求缺口驱动经济AI_设计方案_v0.3.md)，并发与原版控制权沿用[仲裁 v0.4](多需求并发仲裁_设计补充_v0.4.md)。以下新机构、角色、政策与个性参数均为拟议机制，不冒称原版已有或当前代码已经实现。

历史玩法审计见[完整度评估与设计准入 v0.6](玩法完整度评估与设计准入_v0.6.md)，最新规则补齐与设计准入复核见 v0.7 §9；游戏验收状态独立维护。

## 1. 玩家经营什么，Pawn 决定什么

| 层级 | 玩家主要决策 | 系统自主运行 |
|---|---|---|
| 殖民地治理 | 公私供给范围、公共预算、保障资格、劳动与服务规则、发展方向 | 有限预算分配、政策执行、供需和未满足需求报告 |
| 机构经营 | 建设场所、设施许可、服务范围、运营边界、治理委任 | 合法岗位发布、招工、排班、库存与容量维护、按规则结算 |
| 个人与家庭 | 查看、允许有限政策例外、可选干预 | 生活风格、目标、求职、消费、储蓄、照护与服务预约 |

政府和机构的决策能力也必须实际实现，否则个人自主会停在“没人发布岗位、没医生接单”的断点。MVP 可先由玩家设定机构运营政策、系统据此运行；自主经营者和自主公共规划作为后续扩展。

玩家仍保留原版征召、强制任务和灾时干预权，但正常生活流程不依赖这些操作。是否扩展到自动规划、建设医院和住宅是单独的治理能力，不以 Pawn 已经会求职就宣称实现。

## 2. 以制度能力逐步开启，不把阶段当作历史定律

| 游戏制度模式 | 个人自主表现 | 玩家操作重心 | 开启条件 |
|---|---|---|---|
| 共同供给 | 直接使用合法公共资源，自主生活与协作 | 食物、床位和基本生产保障 | 原版供给、需求读取与安全调度 |
| 有偿劳动 | 个人账户、有限储蓄、契约就业、可选商品 | 有效岗位、预算与真实商品 | 合同/工资/产权/账本闭环 |
| 专业服务 | 自主餐饮、医疗、居住、照护、教学安排 | 服务容量、人员培养、保障范围 | 服务双边调度与结果证据 |
| 家庭与多元经营 | 家庭分担、职业成长、受许可的经营活动 | 公共设施、竞争与保障、持续发展 | 家庭预算、机构经营、成本与供给可验证 |

这些模式允许并存：公共急救、家庭照护和市场餐饮可以同时存在。技术研究或建筑等级不会自动把全部公共资源变成收费资产。每次开启新制度先验证供给、人员、预算和退出路径，不追溯收取旧生活费用或无条件私有化原版库存。

## 3. 丰富 Pawn 的八个决策维度

| 维度 | 需要表达的差异 | 可观察的行为 |
|---|---|---|
| 生活标准 | 食品/居住/娱乐的有限满意目标 | 选择价格与品质不同的合法方案 |
| 劳动意愿 | 目标工时、通勤接受度、工作稳定偏好 | 申请、续约、换岗、拒绝不适合的班次 |
| 储蓄意识 | 保障期、应急储备、有限消费预算 | 生活尚稳定时提前补储，不无止境赚钱 |
| 时间价值 | 愿意花时间自己做，还是购买服务 | 自炊/就餐、亲自照护/购买服务之间选择 |
| 家庭责任 | 抚养、照护、共同生活的明确责任 | 留出时间、分担开销、协调班次 |
| 职业发展 | 实际技能、能力、合法培训机会 | 选择可达到的职业路径与培训投入 |
| 经验与预期 | 记住真实欠薪、服务失败、排队和使用效果 | 调整可靠性估计，选择替代供应方 |
| 社会与自主生活 | 原版关系、娱乐与可选共同活动 | 不只劳动和消费，也保留社交与闲暇 |

原版 traits、技能、健康、关系和实际经历可以作为参数输入；具体映射是 Mod 设计，必须可解释、有限幅度且允许政策配置。不能仅凭一个特质永久判定某人贫穷、爱消费或必须承担全部家庭劳动。

不将“勤劳型、享受型、顾家型”做成只能选其一的职业身份。生活风格由多个连续参数共同形成，并随健康、家庭、年龄阶段、保障和真实经历慢速调整；一次饥饿或一次消费不改变整个人格。

## 4. 长期风格怎样落地

拟议 `LifePolicy` 包含：食品接受标准与溢价上限、住房/舒适目标、计划劳动时段、娱乐/家庭保留时间、储蓄保障期、应急额度、风险与通勤接受范围、职业目标和服务使用偏好。

长期循环结合原版事实、环境和可承受资源输出一份可持续计划，不直接填工作表强制 Pawn 一整天执行。短期循环在原版许可和 P0–P3 仲裁下，逐步推进下一行动。

食品价格由实际报价方确定，Pawn 决定是否接受；工资是合同承诺，不是个人意愿直接生成。储蓄比例宜作用于满足必要承诺后的可分配结余，有限目标水位决定是否还需要新增筹资。每日可用时间扣除睡眠、进食、移动、照护和服务后，才能分配劳动与可选活动。

必须核验计划可持续：预计到账、必要支出、可用工时与服务容量一致。持续无法兑现时，改变工时/可选消费/服务/储蓄计划或报告结构性缺口，不能只让 Pawn 多跑任务。

## 5. 保留一个总循环与四个个体业务循环

总循环：观察 → 当前/未来缺口 → 长短期目标 → 仲裁 → 一个前台意图 → 原版 Job/行为 → 真实结果 → 更新。

四个业务循环继续为：即时满足、储蓄保障、劳动收入、消费与服务。家庭责任、职业成长和社会事件是目标及约束来源，不再各建一个抢控制权的调度器。

在个体模型之外新增两类组织反馈：

- **机构运行反馈**：未覆盖服务与真实订单 → 合法容量/岗位 → 人员与物资 → 生产/服务 → 交付 → 结算 → 调整。需求只是经营信息，不自动等于无限有支付能力的订单。
- **治理反馈**：未满足生活需求、财政和服务能力 → 玩家政策/授权规则 → 有限公共预算与建设安排 → 实际供给变化 → 再评估。

两类反馈必须与个体循环通过有版本的请求、合同、订单和结果连接，不用全局直接给每人写目标来制造“看起来自主”。

## 6. Pawn 可以承担多个经济角色

同一个成人可同时是劳动者、消费者、监护人、服务提供者、学习者；后期再增加经营者。角色代表许可与责任，不是互斥标签。

| 角色 | 自主决策 | 必须具备的运行条件 |
|---|---|---|
| 劳动者 | 比较岗位、申请、履约、续约/退出 | 原版工作合法，真实工单/材料，合同与有限支付来源 |
| 消费者 | 预算、比较报价、采购、使用 | 公共替代可见，产权和服务权明确 |
| 监护人 | 照护分配、时间和开销分担 | 明确责任、孩子缺口去重、合法替代照护 |
| 服务提供者 | 接受合法服务、安排时段、完成交付 | 有能力与设施，原版许可和自身需求受保护 |
| 学习者 | 原版儿童学习、后续成人培训规划 | 不混同儿童 Learning 与成人职业技能；培训须单独适配 |
| 经营者（后续） | 在许可范围选择供给、库存、招聘与报价 | 企业账户/资产与成本真值，实际生产和现金能力 |

同一角色的两份合同也可能冲突。角色之间共享一个时间/能力/预算账本，不能让一个医生同时完整履行工坊班次、诊疗预约和孩子照护。

## 7. 让分工和服务有价值

优先补齐食品、休息场所、健康照护、婴幼儿照护和学习机会。服务价值来自实际效果、可靠性、等待时间、便利性与节约的时间；不因服务收费就自动给出更高效用。

原版免费资源仍按玩家制度和实际权利参与候选。付费设施要有明确服务权与收费边界，不能只改原版全局食物/床搜索，让所有人突然看不到公共资源。私人物品、公共物品、售货库存、已经预付的服务权分别处理。

零资金开局要有可执行的启动路径：实际存在的公共保障、雇主包餐/明确代付或足以及时支付的合同。保障必须有物资、人员和预算，不能在市场缺货时凭空生成食品或医生。

现有体检是资格工具，不是治疗；已有工坊按公共材料和产品规则运行，后续经营者不能无偿将公共投入变成私人货物。物料归属、加工服务费、产物归属和销售款必须由合法合同明确。

## 8. 家庭与生活事件增加深度

已有伴侣/婚约、原版生育规划、怀孕、出生、成长、伤病、关系变化等事件可以改变生活计划：准备床具、重新分担照护、调整班次、增加有限储备、减少可选消费、选择服务。

关系事件和经济行动分开：付款不生成爱情或婚姻，家庭不自动共享全部账户，未婚不被统一判为失败。儿童先作为需求主体和服务受益者；成人就业逻辑不直接套在孩子身上。

家庭事件应产生真实取舍。例如某成人减少劳动而亲自照护，另一成人增加有限收入；或家庭选择付费托育换取可持续的工作时间。每种方案都要检查实际照护者、收入到账、孩子需求与时间冲突，不能只比较名义工资和服务报价。

## 9. 经验、预期与选择变化

可保存有界的观察摘要：合同已付/欠薪、服务真实成功/取消、通勤耗时区间、排队时长和需求改善。预测区分观测事实与估计置信度；未知供应方不自动当骗子，也不自动当可靠。

只有可观察的服务结果才更新对应估计；不给 Pawn 全图即时价格和未来事件知识。MVP 先按已知机构报价和最近实际消费建立信息，再逐步增加公告、询价和有限信息共享。

换岗/换服务设置切换收益门槛、冷却和履约退出规则，不因报价微小变化每日跳槽。严重欠薪、机构关闭、健康失能等事实可以触发提前重评。

## 10. 制度与经济循环必须闭合

基础循环：实际劳动/服务 → 工资或服务收入 → 个人/家庭预算 → 真实消费 → 机构收入 → 合法经营支出与下一轮支付能力。

公共收入、支出、补贴和可能的制度性发行单独记录来源与规则。不能因“现代经济”就每 tick 给钱包加钱；也不能承诺无上限工资、治疗或失业保障。资金守恒不等于经济一定稳定，还要观察真实产出、库存、供给、就业与支付时效。

未来可讨论税收、保障、租赁、经营许可和有限保险；借贷、利息、投资、继承及复杂金融应放后期，在产权、合同、违约与生命周期有实际支持后再设计。暂不将这些拟议功能列作实装能力。

机构价格如要动态调整，使用本 Mod 自己的有限报价规则与真实成本/库存/容量，不恢复或修改已移除的全局 MarketValue 动态系统；初期固定报价已足以验证自主分工。

## 11. 玩家应看到社会结果与原因

RUIF 页面优先展示：基本生活覆盖、缺口与阻塞、有效岗位与空缺、收入到账、服务排队、家庭照护缺口、机构预算和公共财政。玩家据此增加医生容量、改善供给、调整制度，而不是不断右键修复每个 Pawn。

个人解释应能回答：为什么找这份工作、为什么这次选择便宜食品、为什么暂停补储、为什么购买托育、为什么换岗。不能只显示人格标签或一个不可解释总分。

复杂度通过逐步解锁机构、折叠解释和政策模板管理。UI 不创建需求、不直接改余额，依旧只读 Application 快照并发出已定义命令；所有通用业务组件使用 RUIF。

## 12. 实施顺序与零强制操作验收

| 批次 | 实际推进内容 | 必须证明的自主链 |
|---|---|---|
| A | 多需求事实、长短期计划、仲裁与有限储蓄 | 不看商店也能发现未来生活缺口；正常需求无需逐人强制 |
| B | 岗位自运行、合同生命周期、消费/服务双方调度 | 发布有效岗位后，申请、上岗、到账、采购与使用自然完成 |
| C | 餐饮、居住与医疗等服务逐项适配 | 有真实供给和人员时自主预约、交付、结算、失败恢复 |
| D | 家庭责任、照护、学习与职业规划 | 家庭事件能改变时间/预算，孩子需求不会被重复或遗漏 |
| E | 经营者、公共治理反馈与更多制度 | 机构在许可与预算内自行维护供给和岗位，玩家转向制度决策 |

每批在具备明确初始设施、政策、人员与物资的场景中验证“零逐 Pawn 强制 Job”。再独立验证启动路径、无岗位/无供给/无资金、伤病和家庭冲突。基础场景成功不等于整个社会已能无玩家建设自启动。

丰富程度以可观察的决策差异、相互作用和闭环稳定性衡量，不以需求枚举、角色或机构数量衡量。技术上保持单一执行出口、有界目标/候选、事件合并和可恢复事务，先让少数真实角色产生取舍，再扩充新制度。

本次为总体设计整理，尚未新增运行行为，也未进行上述游戏场景验收。
