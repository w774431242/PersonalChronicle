# B1.3 RUIF 只读需求页：实施记录

Change ID：`CHG-20261008-ECON-NEEDS-UI`。授权：用户“批准继续”，沿实装计划完成 B1.3。

## 1. Intake / ADR（编码前）

目标：从现有经济中心/机构窗口进入 RUIF 需求页，分页观察地图内所有感知主体，选择个人查看事实、目标、缺口、来源、年龄与采集状态。与旧可执行成人列表分离。非目标：配置生活目标、经济制度设置、预算/订单/派工、收费、资金迁移、部署。

边界：Domain 仅给上下文增加可选的姓名事实；姓名由既有快组采集。Application 新增只读目录/详情契约与分页构建器，使用感知查询端口。Economy 中独立 presenter 格式化不可变快照，游戏文本适配器解析 Def 标签和 Key；Window 只绘制、选择、分页和缓存。查询不触发采集，不调用旧 Query/Account/Person/Execute。无新 Def、Save、Asset、Harmony、DLC 分支或第三方引用；RUIF 使用既有硬依赖。

UI：StatTable、StatRow、AlertBanner、EmptyState、Layout 滚动和独立详情按钮。正常窗口用七列表，窄区域使用逐项统计卡，文本高度按实际翻译度量。12 人分页；60 游戏 Tick 刷新，主体选择/页码/宿主/地图/会话/语言变化立即失效。暂停不推进采样；不伪造最新年龄。不保存页面状态。

架构审查：新增 Provider/read model/UI，遵守 GOV/MATRIX/ARC、DL-1/2、UI-001–012、LOC-001–004、SAVE-001/007、AI-001–010。采用 Contract/Provider + 原有 GameComponent + RUIF 原子；无需补丁或例外。年龄默认上限为快组 300、身体 500、关系 1200 Tick，限展示用途，不能作为行动授权。当前目标系统未接入，默认 Unknown，不给 80% 目标；缺口不能解释为订单或餐数。

验证计划：构建；分页/生命周期/原版量纲/未知及错误传播/不可变读模型的离线测试；双语 XML、Key 与占位符扫描；编译 IL 检查 RUIF 依赖及只读调用边界；全工程回归。真实游戏中/英文、窄屏、抱持、暂停/切档/读档与点击仍需实机，未执行不标通过。以下为编码后证据。

| 个人详情 | 需求名、当前比例和原始量/上限、目标、百分点缺口、来源、数据年龄和事实/新鲜度状态；心情为结果摘要，不是消费目标 |

| 状态 | 已知 0、未知、不适用、未适配、错误分别显示；未知集合不显示为确认 0 项；陈旧/离图保留历史值与明确状态，缺失/失败只影响相应成员。初始化失败显示错误，不无限等待 |
| 生命周期 | UI 按宿主、会话、地图可用性、语言、选择、页码或时间回退失效；60 游戏 Tick 更新一次读模型。窗口固定绑定打开时的地图；旧地图不属于当前游戏时返回离开范围，不用相同 mapId 读取新档。暂停时不补采，也不推进游戏年龄 |
| 绘制 | RUIF 表格/统计行/横幅/空态/按钮/滚动；宽度 ≥760 为七列表，较窄为统计卡。按 RUIF 实测文字宽度预先插入换行（其 Draw.Label 关闭自动换行），缓存文本、行高和单元格高度；滚动 begin/end 用 finally 配对。选择成员后滚到详情 |
| 本地化 | 两种语言各 77 个新 Key，UTF-8 无 BOM、XML 合法、命名空间无冲突、占位符一致；Need 标签使用当前已加载 Def 本地化，姓名来自快组标量事实 |

数据仍是观察，不等于生活目标、风险、餐数、价格、订单或行动权限。覆盖人数是已观察目录；部分/截断目录不能解释为地图完整人口，未检查项也不是缺失主体唯一人数。年龄为页面读模型构建时的游戏 Tick 差，页面最多有 60 Tick 刷新延迟。身体/瞬时条件保留自身时间，不用新需求时间覆盖。
