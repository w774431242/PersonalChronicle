# B3.1：只读规划验收清单

本轮是只读规划接入。**自动应聘、自动勾选工种、劳动领薪、收费购买仍不可用，不要把手动操作后的结果记录为自主经济闭环通过。** B2.4.3 的存档/制度能力验收另行保留。

退出并重启 RimWorld 以载入新 DLL；进入原测试档，打开任意经济机构的经济界面，进入“需求观察”，选择成员并滚动到需求表后的规划信息。首次目录/采样可能需要数秒游戏时间；暂停时不会推进采样。

| ID | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |
| SH-01 | 选择普通成人，推进游戏时间 | Food/Rest/Joy 的存在项显示目标与真实缺口；不适用或不存在的需要不伪造 | 未测 |
| SH-02 | 查看规划信息 | 明确显示“只读拟选”，有规划年龄、生活倾向、来源和拟选原因 | 未测 |
| SH-03 | 仍将所有原版工作优先级设为 0 | 不显示“因为没勾选所以能力禁用”；当前费用/岗位未接入时显示真实等待原因，不签约、不改优先级 | 未测 |
| SH-04 | 查看没有实资账户的成员 | 现金未知；不采用旧余额，不赠币；未发布费用时储备和收入未知 | 未测 |
| SH-05 | 开启或关闭制度设置 | 需求与只读规划仍更新；本轮不能将制度推进为 Active | 未测 |
| SH-06 | Food 低于约 55% 或 Rest 低于约 45%，尚非急迫区间 | 显示先满足基本进食/休息；原版实际寻食/休息行为不被规划阻止 | 未测 |
| SH-07 | Food 低于约 35% 或 Rest 低于约 25% | 显示原版控制与安全先行；这些是 Mod 保守让路样例，不是原版危险分类 | 未测 |
| SH-08 | 多项需要同时低 | 保留各项，基本生活在普通娱乐和补储之前；没有凭规划直接加 Need 值 | 未测 |
| SH-09 | 征召、指定强制任务、切换睡眠/娱乐/用餐时间 | 规划说明让路；现有命令不会被规划打断；不得出现新经济 Job | 未测 |
| SH-10 | 选择婴儿/儿童 | 保留真实需求观察；普通就业工时不适用，不拟派成人劳动 | 未测 |
| SH-11 | 关闭窗口，推进游戏，再打开 | 规划年龄仍正常更新，后台工作不依赖窗口打开；暂停开关窗口不会重复叠加特质修正 | 未测 |
| SH-12 | 保存/读档、切地图或成员离图 | 缓存重新采样，不混旧会话/地图；无自动开户、扣款、工资或合同新增 | 未测 |
| SH-13 | 中文/英文、较窄窗口，滚动到规划末尾 | 长原因换行、可滚动，无缺 Key、文字重叠和固定行高截断 | 未测 |
| SH-14 | 有勤劳/苦行/美食/夜猫特质的不同成人 | 来源可见；差异是软偏好，时间表、食物营养和实际技能不会被直接改写 | 未测 |

报告问题请记录用例 ID、当前成员、游戏 Tick、页面显示的拟选行动/原因，以及是否暂停、征召或强制任务。本清单仍全部未测，离线测试不能代填。
