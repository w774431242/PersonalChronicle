# Pawn 经济 AI 闭环流程图

建议先看简明版：`Pawn经济AI_简明闭环_高清.png`（6000 × 4700 像素，300 DPI）与 `Pawn经济AI_简明闭环_矢量.svg`。它以 5 个主步骤、3 条行动路径表达闭环，共 9 个节点、13 条连接；等待统一返回，具体异常集中为旁注。简明版同样使用中文矢量轮廓，生成入口为 `build_simple.py` 与 `render_simple.ps1`。原详细版保留供查阅。

- `Pawn经济AI_闭环流程图_高清.png`：6600 × 6680 像素，300 DPI，适合查看、展示与打印。
- `Pawn经济AI_闭环流程图_矢量.svg`：可无损放大；中文已转为矢量轮廓，不依赖查看设备安装字体。
- `预览.png`：缩略预览，查看细字请使用高清 PNG 或 SVG。

流程对应当前实现：原版 ThinkTree 调度 → 经济参与条件 → 待办订单或新决策 → 自有衣物穿戴 / 购物 / 就业与体检 → 原版 Job 执行 → 事实与收支反馈 → 下一次自然决策。覆盖等待、未完成、欠薪、中断、读档恢复等返回路径。RUIF 为界面层，本图聚焦 Pawn 行为闭环。

同字母连接点相连：A 为购买入口，B 为就业收入入口，C 为穿戴入口，R 为统一反馈。全局恢复规则作用于全部机构 Job。

`逻辑校验.json` 记录 46 个流程节点、69 条连接的静态可达性检查：所有节点可从起点到达，并可返回事实更新节点。这项检查不等于游戏内验收；完整游戏闭环仍待实机验证。

维护时修改 `build_flow.py`，先运行它生成 `flow_model.json` 并检查连接，再用 PowerShell 运行 `render_flow.ps1` 生成高清 PNG 和 SVG。绘制使用 Microsoft YaHei 的字形轮廓。
