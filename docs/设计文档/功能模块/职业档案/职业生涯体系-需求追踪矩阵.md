## 1. Change Intent 摘要

- **目标用户行为**：玩家殖民者通过真实游戏行为（制造/建造/研究/著书）形成职业事实档案 → 专业技能成长 → 评级与效果加成 → 资格评定 → 职称授予 → 勋章荣誉，全程数据驱动、事实与评价分离。
- **非目标**：不替代原版技能系统（V2.0 §2 第一原则）；不横向铺开 12 专业（V2.0 §22 垂直切片，先做制造类精密制造闭环）。
- **兼容承诺**：Save append-only 不 bump schema；CareerEvent 白名单受控扩展（DISCLOSE 已批准）；旧档 null 兼容。
