# 自动化设备 开发架构样例 · 生命周期管线 v1.0

> 文档定位：以**自动农机**（`Building_AutoFarm` + `CompAutoAgriculture` + `CompItemStorage` +
> `MapComponent_AutoFarmTerrain`）为已验证样板，固化自动化设备的标准架构与完整生命周期管线。
> 后续任何新设备（加工机、传送带、管道口、泵……）按本样例扩展，不再从零摸索。
> PM 契约文档：`自动化农业设备_开发设计指导_v2.md`（本文档是它的架构落地版）。

## 1. 分层架构（职责边界）

```
┌─ Def 层 (XML) ────────────────────────────────────────────────┐
│ ThingDef 抽象基类（PC_AutoFarmBase）→ 档位子类（S/M/L）继承      │
│ comps 声明能力：PowerTrader/Refuelable/Flickable/Glower/       │
│ CompProperties_AutoAgriculture/CompProperties_ItemStorage      │
├─ 建筑薄壳层 ─────────────────────────────────────────────────┤
│ Building_AutoFarm : Building, IWorkshopDevice                  │
│ 只做：互动键 GetGizmos / 范围可视化 / IWorkshopDevice 标记      │
│ 【零游戏逻辑】——逻辑全在 comp 里                                │
├─ Comp 能力层 ────────────────────────────────────────────────┤
│ CompAutoAgriculture  状态机（播种/收获/生长驱动/地形改造）       │
│ CompItemStorage      内置缓冲仓（IItemStorage 实现）             │
├─ Map 协调层 ─────────────────────────────────────────────────┤
│ MapComponent_AutoFarmTerrain  全图地格归属登记（多机防冲突）     │
├─ 接缝层（对外契约）──────────────────────────────────────────┤
│ IWorkshopDevice  设备识别（车间统计/管理面板自动纳入，零注册）    │
│ IItemStorage     物流对接（未来管道运输唯一入口，见管线草案）     │
└──────────────────────────────────────────────────────────────┘
```

**四条分层铁律**：
1. 建筑类只做壳（UI/可视化/接口标记），游戏逻辑进 comp；
2. 能力做成 `CompProperties_xxx`（Def 级参数）+ `CompXxx`（行为），不同档位用不同参数组合，不写三个类；
3. 跨设备协调（多机竞争同一资源）进 MapComponent，不在单机 comp 内私了；
4. 对外识别/对接**只暴露接口**（`IWorkshopDevice`/`IItemStorage`），禁 defName 前缀匹配——第三方 mod 扩展不需改我们的代码。

## 2. 生命周期管线（五阶段）

### 阶段 0 · Def 加载期

| 环节 | 规则 | 已踩坑 |
|---|---|---|
| XML 解析 | `Class="..."` 指向的类型必须在目标程序集**字节级核实**存在 | 类型不存在 → 整 Def **静默丢弃** + Player.log 异常 + 建造菜单缺建筑（`audit_automation.ps1` B2 已固化） |
| 继承语义 | 抽象基类 `ParentName` 继承是**追加非覆盖**；comps 同理 | |
| 必填字段 | 不继承原版 `BuildingBase` 时须显式补 `selectable`、`altitudeLayer` | `selectable` 缺失（默认 false）= 建筑无法选中/交互（实机 bug）；altitudeLayer 缺失掉到 Item 层被地面装饰压住 |
| 1.6 特例 | 太阳能等被删属性类改用通用 `CompProperties_Power` + `compClass=CompPowerPlantSolar` + `transmitsPower` | 属性类写错 = Def 加载即抛异常被丢弃 |

### 阶段 1 · 建造与生成期（Spawn）

```
SpawnSetup(map, respawningAfterLoad)
  └─ PostSpawnSetup(respawningAfterLoad)
       ① 缓存同体 comp 引用（powerTrader/refuelable/flickable/itemStorage
          —— parent 上的 comp 在 Spawn 后固定不变，可安全缓存）
       ② Def 依赖解析：DefDatabase<TerrainDef>.GetNamed("SoilRich", false)
          （走 DefDatabase 而非 DefOf 字段，避免强耦合；返回可能为 null 须兜底）
       ③ respawningAfterLoad == true 时执行旧存档迁移（MigrateClaimRegistry）
       ④ RebuildCoverage()：覆盖 cell 缓存重建
          —— 覆盖缓存【不持久化】，每次 Spawn 重建（Scribe 纪律）
          —— 正方形（切比雪夫距离）不用 GenRadial（那画出来是菱形）
          —— 排除设备自身占格；同时算 maxRing（圈层推进用，不持久化）
```

### 阶段 2 · 运行期（Tick 管线）★核心

**统一口径**：`CompTickInterval(int interval)` 累加配额，**禁硬编码 `progress += 250`**
（1.6 自适应 tick，interval 不保证 1/250）。每条节拍通道一个独立配额计数器。

```
CompTickInterval(interval)
  ├─ 门控 IsRunning()：通电 ∧ 有燃料 ∧ 开关未关 —— 不满足【零扫描】直接 return
  │
  ├─ 通道 A · 工作片（WorkIntervalTicks = 120）
  │    配额累加 ≥ 120 → DoWorkSlice()
  │    轮转游标 cursor 每次处理 CellsPerWork = 12 格，全周期覆盖一遍
  │    单格 ProcessCell 优先级：成熟作物 → 收获；空格∧种植区∧允许播种 → 播种；
  │    其余 → 灌溉水花（纯视觉，Rand.Chance 门控）
  │
  ├─ 通道 B · 生长驱动（GrowDriveIntervalTicks = 250，对齐原版 Long ticker）
  │    全量扫描覆盖区，快照对比自愈：
  │    成长度在涨 → 原版正常，让位不干预（防双倍加速）
  │    纹丝不动 → 农机接管，速率 = 光照 × 肥力 × 温度（不含夜间休眠因子
  │    → 生长灯下夜间也长）；病害/成熟/无植物跳过
  │
  └─ 通道 C · 改造推进（RenovationRingIntervalTicks = 90）
       圈层前沿 renovationRing 逐拍 +1（欧氏距离分层）
       只改「已抵达圈层 ∧ 属于种植区」的格子；前沿推进与实际改造解耦
       （后补种植区落在已抵达圈层内下次驱动即被改造，不卡死）
       改完（ring ≥ maxRing）前沿停止，扫描仍跑以承接新增格
```

**产出管线（收获 D4）**：
```
HarvestPlant：先按 YieldNow 落产出 → PlantCollected 收尾
  产物去向：itemStorage.Push(def, yield) 先进内置仓
           溢出部分 GenPlace.TryPlaceThing(Near) 落地；失败 Destroy 兜底
  ⚠️ 1.6 的 Plant.PlantCollected 不生成产物（产物由原版 JobDriver 收割 Toil 负责）
     ——只调它 = 植株凭空消失零产出
```

**多实例协调（MapComponent 登记表）**：
- 地格归属**先到先得**：`registry.IsClaimed` 拒绝 → 让位（防两机交替覆写污染还原链）；
- 撤机时 `registry.Release` 释放，其它机可接管；
- 原始地形以登记表为准（不读本机平行表），避免交叠区读到别机铺的地形当原值。

### 阶段 3 · 数据期（Scribe 持久化）

`PostExposeData()` 纪律：

| 判定 | 处理 | 本例 |
|---|---|---|
| 状态缓存可由世界重建 | **不持久化**，Spawn 重建 | coverage / growthSnapshot / renovated |
| 必须跨存档的外部世界影响 | 持久化 | fertilizedOriginal（否则读档后撤机无法还原） |
| 值类型列表 | `LookMode.Value` | IntVec3 / int |
| Def 引用 | `LookMode.Reference`（绝不存对象实例） | TerrainDef / ThingDef |
| 平行表 | ⚠️ **不能 readonly**（`Scribe_Collections.Look(ref ...)` 需可写引用）；PostLoadInit 校验等长、截断/回填对齐 | fertilizedCells↔Original↔Applied 三表 |
| 旧档字段缺失 | PostLoadInit 回填默认值 | applied 列旧档按沃土回填 |
| 玩家可选状态 | 存"默认值时存 null"减少冗余 | targetTerrain == 沃土 → 存 null |

### 阶段 4 · 撤除/销毁期（DeSpawn / Destroy）

```
PostDeSpawn(Map map, DestroyMode mode)
  ① 还原外部世界状态：RestoreTerrain(map)
     —— map 参数必须用（此时 parent.Map 已为 null！）
     —— 只还原「当前地形 == 本机最后所铺(applied)」的格子
        （玩家事后自己铺的其它地砖原样保留）
     —— 原值以全图登记表为准，还原后 Release 认领
  ② 清运行缓存（coverage/growthSnapshot/renovated/游标/圈层）
  ③ base.PostDeSpawn(map, mode)
```

撤机/被毁/搬迁（minified）**三态同路**，无特殊分支。

## 3. UI / 互动管线

| 入口 | 规则 | 本例 |
|---|---|---|
| `GetGizmos()` | 先 yield base（原版 comp 键：开关/维修/加燃料），再补本机键；**实例级缓存**（每帧调用，每次 new = 持续 GC 掉帧，实测 160→60 FPS） | 改造地形键（条件显示）/ 配置农场键 |

| 弹窗 | Def 选择统一走 `Dialog_DefPicker<T>` 骨架（搜索框+图标网格+右侧详情），薄子类只提供数据源与详情行 | Dialog_ChooseCrop / Dialog_ChooseTerrain |

## 4. 新设备扩展 Checklist（照此七步）

1. **XML**：抽象基类（补齐 `selectable`/`altitudeLayer` 等 BuildingBase 字段）→ 档位子类；能力用 comps 参数化；测试期 0 成本注释里写明正式发布要恢复什么。
2. **建筑薄壳**：`XxxBuilding : Building, IWorkshopDevice`（一行 `DeviceLabel` 即自动进车间统计/管理面板）。
3. **能力 comp**：`CompProperties_Xxx`（Def 参数）+ `CompXxx`（`CompTickInterval` 累加配额 + `IsRunning` 门控 + 零扫描）。
4. **跨设备协调**（如需）：MapComponent 登记/释放，先到先得。
5. **产出缓冲**（如需）：挂 `CompProperties_ItemStorage` 或自实现 `IItemStorage`（缓冲只存 ThingDef+count，见管线草案 §1）。
6. **翻译键**：Keyed 简中/英双份；改名/归并前 grep 全部 `T("...")` / `.Translate()`。
7. **收尾**：`C:\dotnet8\dotnet.exe build ... 0错0警` → 单测 → dll 同步发布区（备份+哈希）→ `audit_automation.ps1`。

## 5. 铁律速查卡

- Tick 一律 `TickInterval(int)` 累加配额；工作量与 tick 率无关（固定时间片）。
- 自定义存储一律继承 `RimWorld.Building_Storage`（白送 slotGroup/IHaulDestination/ITab_Storage）；**不自研物品容器**。
- 缓冲只存 `ThingDef + count`，绝不存 Thing 引用。
- Scribe：缓存不存、外部影响必存、Def 走 Reference、平行表可写+PostLoadInit 对齐。
- 撤除还原以"当前地形==本机所铺"核对 + 全图登记表仲裁，防多机交叠污染。
- 运行门控不满足 → 零扫描零分配。
- 每帧入口（GetGizmos/检视/FillTab）禁每次 new。
- 机器收成不走 GenRecipe（不触发职业捕获，PM 契约：机器无人力）。
