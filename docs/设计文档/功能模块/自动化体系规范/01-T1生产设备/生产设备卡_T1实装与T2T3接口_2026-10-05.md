# 生产设备卡：T1 实装与 T2/T3 接口

所属：殖民地综合管理系统 0.1，2026-10-05。

## 本次修订

十台 T1 设备原先能进入制造系统中心，但设备卡没有读取设备图或等级信息，统一显示通用容器和状态灯。本次在真实设备定义中加入卡片声明，并接入制造中心的自由画布、固定俯视图和设备详情身份行。

- 自由画布及固定俯视卡展示该设备的北向图和真实 T1 等级徽标；状态灯、工单、功率、人员、配方和进度继续从原有读数取得。
- 新增当前设备速度系数，读取实际 `WorkTableWorkSpeedFactor`，包含当时的设施与环境修正。该系数不是相对原型倍数：制作台基础 2.0，相对其 0.5 原型为四倍；其他九台基础 4.0。
- 用户改名后的标题保留；悬停提示同时显示真实设备类型、等级和速度。匹配依靠 ThingDef 的声明，不靠中文名、别名或 defName 前缀猜测。
- 卡片缩小时优先保留名称与状态；空间不足的图像、徽标和信息行省略，完整文本保留于悬停。没有卡片声明的设备仍使用原有通用卡。
- 图像资源按路径缓存；快照只传路径和格式化文本，不在绘制期访问建筑或读取生产属性。

## T2/T3 接入契约

未来真实的 T2/T3 ThingDef 在自己的 `modExtensions` 中添加以下声明即可复用设备卡。此例是接入说明，不是当前可建造设备。

```xml
<li Class="PersonalChronicle.Automation.ProductionDeviceCardExtension">
  <tier>T2</tier>
  <texturePath>Things/Building/T2Production/YourDevice_north</texturePath>
</li>
```

`tier` 接受 T1、T2、T3；`texturePath` 是单张图的完整资源路径，不带 `.png`，可使用北向图或专用设备卡图。T3 将 tier 改为 T3。等级未声明、非法或路径为空时回到通用卡。合法声明的图片缺失时保留等级及文本，不显示其他设备图。本次没有注册虚构 T2/T3 建筑，也不冻结其速度、成本和配方。

卡片接口独立于 `SmartBenchExtension`，后续自动化生产设备可以采用不同建筑类和生产机制；只需提供真实设备定义、有效卡片声明，以及自身实际速度属性。原有设备稳定 ID、保存布局与重命名机制保持有效。
