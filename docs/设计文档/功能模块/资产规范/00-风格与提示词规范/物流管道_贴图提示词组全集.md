# 物流管道 · 贴图资产提示词组全集（独立版）

> 用途：为「物流管道」生成**整套贴图资产**的提示词，一条一条可直接复制使用。
> 与 `自动化设备贴图风格规范与提示词组.md` §12 同源，但本文件**自成一体**，
> 不依赖其它文档即可完整生成全部素材。
>
> 规格：64×64 PNG-32（带 alpha）、**严格正交俯视贴地**、原版 RimWorld 工业配色。
> 素材命名与游戏代码一一对应（`PC_Pipe_BodyM0..15` / `PC_PipeH_M0..15` / In / Out）。

---

## 0. 方向约定（先读这个）

管道是**贴地/埋地层**元素，视角为**垂直俯视**（无侧面、无厚度、无透视）。

```
        N = 画布上边缘 (top edge)
             │
  W 左边缘 ──┼── E 右边缘
             │
        S = 画布下边缘 (bottom edge)
```

- **掩码制**：每个格子按「四邻是否有管道」选图，`bit0=N bit1=E bit2=S bit3=W`，共 16 种。
- **方向已画在图里**：掩码图本身包含方向，生成后**不需要再旋转**。
- 只有 **In/Out 端口**需要 4 个朝向（口朝哪边）。

**三条铁律（违反就拼不上）**：

1. 管路在连接方向必须**延伸到画布正边缘且居中**，不留白、不内缩。
2. 多臂在中心 24×24 区域**交汇成整块**，不能留十字缺口。
3. 每条臂只占**半格**（N=上半 / S=下半 / W=左半 / E=右半），画满整格会退化成直管。

## 3. 端口 8 张（In 蓝口 / Out 橙口 × 四朝向）

> 命名：`PC_Pipe_In.png`（口朝东，无后缀）、`_south` / `_west` / `_north`；
> `PC_Pipe_Out.*` 同规则。

| `PC_Pipe_In_west` | 口朝**西** |

## 5. 推荐生成方式：一次出「4×4 形态总表」

分开生成 16 次容易风格漂移。**推荐一次生成整张总表再裁切**：

```
a single reference sheet: a 4 by 4 grid of the SAME pipe-shaped overlay
element showing all 16 connection states in reading order (row 1: isolated
stub, N dead end, E dead end, N+E elbow; row 2: S dead end, vertical straight,
E+S elbow, N+E+S tee; row 3: W dead end, N+W elbow, horizontal straight,
N+E+W tee; row 4: S+W elbow, N+S+W tee, E+S+W tee, four-way cross), every
element identical in style, colour and line weight, each element drawn as the
pipe/trench shape only with fully transparent surroundings — NO square
backdrops, NO tile frames, NO filled rectangles behind any element,
[STYLE CORE 可见款]
```

> ⚠️ 若总表仍出现背景框（AI 对网格图容易画底板），**放弃总表、改用逐张生成**
> （§2 的 16 条逐条提示词已内置防背景约束，单张可控性最强）。

生成 1024px → 按 4×4 等分裁成 16 张（每张 256 → 缩 64）。
隐藏款把 Style Core 换成 §1.2 再生成一张。

## 6. 生成后必做的两道验证

```powershell
# ① 像素采样：有臂方向边缘中点 alpha>0，无臂方向 alpha=0
#    采样点：N(32,2) E(62,32) S(32,62) W(2,32)

# ② 文件名对账：代码请求路径 vs 入库文件（必须 0 缺失）
#    PC_Pipe_BodyM0..15  +  PC_PipeH_M0..15
```

> ⚠️ 这两步曾各漏一次，导致两次"假修复"（素材画错 / 路径多拼一个字母）。
> **生成完必须验产物本身，不能只验代码或只验同步。**
