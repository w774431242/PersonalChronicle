## 1. 风格基调

**一句话定位：深色工业自动化风——炭灰机体 + 功能色点缀 + 机械细节密度略高于原版同尺度建筑。**

与原版（vanilla）的关系：

| 维度 | 原版 | 本项目设备 | 边界 |
|---|---|---|---|
| 主题感 | 手工/作坊混合 | 现代工业化、流水线感 | 不做科幻（无发光全息、无纯白面板） |
| 色彩 | 低饱和为主 | 同样低饱和 + 语义功能色 | 功能色只做点缀，不超总面积 15% |
| 细节密度 | 建筑有管线/铆钉 | 增加指示灯、警示条、接口面板 | 密度上限：以基准件 `PC_AutoFarm_M` 为准，不再加密 |
| 尺度 | pawn 约 1.5 格高 | 设备以俯视 2.5D 表现 | 不画 pawn 级别的面部/皮肤细节 |

**风格基准件（benchmark）**：`Textures/Things/Building/AutoFarm/PC_AutoFarm_M.png`。
新设备拿它并排对比：明度关系、做旧程度、细节密度三项目测一致才可提交。

## 2. 色彩规范（实测色板）

### 2.1 机体基色（占 70–85% 面积）

| 角色 | 色值区间 | 说明 |
|---|---|---|
| 机体主灰 | `#303030` ~ `#404040` | 炭灰金属，占大面积 |
| 深灰/阴影 | `#101010` ~ `#202020` | 暗面、底盘、开口内部 |
| 亮灰/高光 | `#505050` ~ `#707070` | 顶面高光、金属亮边，克制使用 |
| 做旧/锈迹 | `#543000` ~ `#84480c` | 边角锈蚀、黄铜旧件，少量 |

### 2.2 功能色语义系统（点缀，每设备只取 1 个主功能色 + 黄色警示）

| 语义 | 色值 | 已落地的锚点设备 |
|---|---|---|
| **能源 / 水** | `#24486c` `#183c6c` | PC_PowerModule（太阳能板）、PC_IrrigationModule（水路） |
| **生化 / 生长** | `#60a800` `#54b400` | PC_FertilizerModule |
| **运动 / 作业机构** | `#f07800` `#b4600c` | PC_SowerModule、PC_HarvesterModule、自动机械臂 |
| **警示 / 导向** | `#fca824` `#c08418` | 传送带黄色箭头、警示条纹（所有设备通用辅助色） |

**硬规则：**

1. 蓝只用于能源/水路，绿只用于生化/生长，橙只用于运动机构——同一色值不跨语义复用，玩家凭色猜功能。
2. 黄色警示元素（条纹/箭头）是全设备通用件，不算入主功能色。
3. 面积配比约 70/20/10：灰机体 70%、深灰暗面 20%、功能色+警示 ≤10%。
4. 不引入色板之外的新颜色；确需新增语义色（如红色=危险/热处理），先在本表登记再使用。

## 3. 尺寸与像素密度

**基准密度：64px / 格。**

| 资产类型 | 画布 | 依据（存量实测） |
|---|---|---|
| 道具/模块（Item，1 格视觉） | 64×64 | 全部 6 个模块、FarmFrame 均 64×64 |
| 建筑 S（2×2） | 128×128 | AutoFarm_M 128px（drawSize 2×2，64px/格） |
| 建筑 L（3×3） | 256×256 | AutoFarm_L 256px（drawSize 4×4，64px/格，悬挑合法） |
| 传送带等 1 格建筑 | 64×64 | Conveyor 系列均 64×64 |

规则：

1. 画布一律**正方形**，边长 = 视觉主尺寸格数 × 64px。
2. `drawSize` 控制实际绘制大小，可与占地不同（大设备悬挑压到邻格是原版常规做法，如 AutoFarm_L）；
   贴图像素 : drawSize 恒等于 **64px/格**，禁止放大模糊贴图凑尺寸。
3. 禁止对参考图/生成图做超分（upscale）后使用——点采样下超分边缘必脏；按目标分辨率 1:1 绘制。
4. 小道具在 64px 下的最小细节单位约 2px；小于 1px 的细节不要画（游戏内不可见、还会闪烁）。

## 4. 视角、透视与光影

> 核心约束：**环世界原版建筑贴图即 2D 俯视正交（orthographic）**——设备美术必须复刻此观感，禁止透视/等距/立体盒。出图提示词组已在本约束下强化（见 `资产图集提示词/00` §3.5）。

| 项 | 规范 |
|---|---|
| 视角 | **2D 俯视正交（orthographic）**：相机正上方俯视，无透视、无灭点、无近大远小；物体以"平面俯视轮廓 + 极薄上沿亮边"表现体积，**不做 3D 拉伸盒** |
| 朝向 | **北朝上（north-up）**；传送带/进出料口方向按四向后缀（`_north/_east/_south/_west`）定义，出图以 `east` 为基准向（进左出右） |
| 主光源 | 正上方偏前；顶面最亮，极薄上沿次之，开口/暗格最暗（flat shading，无体积光） |
| 地平线/地面 | **禁止**：贴图不含地面块、无接触投影、无地平线——RimWorld 叠加地图光照，自带投影会双重变黑 |
| 着色 | 平涂（flat shading）为主；避免球面高光、渐变天光、环境光遮蔽渲；保留硬边机械细节 |
| 明度关系 | 整体压暗（画面 70% 像素明度 < #505050），高光只给机械核心 |
| 描边 | 不用外描边轮廓；靠明度差区分体块（同原版） |

## 5. 结构语汇（每台设备的必备元素）

批量生产时每台设备应包含以下 4 类元素（允许合理取舍，缺 2 项以上需说明理由）：

1. **机体**：炭灰金属外壳 + 做旧痕迹（边角锈、划痕），是"用过的工业设备"不是"全新商品包装"。
2. **接口面板**：至少一处管线口/电缆口/传送口，暗示它接在产线里（车间体系的叙事核心）。
3. **状态指示**：指示灯或屏幕（用设备主功能色），关停态靠它可辨识。
4. **警示/运动暗示**：黄色条纹、箭头，或可见的运动机构（机械臂、齿轮、传送辊）。

**同族设备的家族感**：同一产线（如 6 个农业模块）共享底盘造型 + 换顶面机构——
已有模块即此模式（统一方形底盘，顶部区分：太阳能板/喷头/收割臂）。新产线沿用此法。

**AutoFarm 底盘语汇强制继承（T3）**：
`PC_FarmFrame` 的深色方框底盘 + 四角螺栓 + 下沿警示条纹 + 顶面标准安装接口，是"统一底盘 + 顶面可换"的已落地实例。
T3 武器设备必须复刻此 DNA：同一 3×3 装甲底盘 + 12 种顶面功能模块，底盘描述一字不动，详见 `资产图集提示词/03_T3_全自动化生产设备.md` §1.5。

## 6. 命名与目录

```
Textures/
├─ Things/
│  ├─ Building/<体系>/<设备名>.png            # 建筑（固定贴图）
│  │  └─ <设备名>_[north|east|south|west].png # Graphic_Multi 四向
│  └─ Item/<体系>/<物品名>.png                # 道具/模块
```

规则：

1. 文件名 `PC_` 前缀 + PascalCase 英文，**只允许 ASCII**（存量 Medals 的中文文件名是历史遗留，不再新增）。
2. 目录按体系分组（现有：`AutoFarm`、`Automation`），新产线开新子目录，不混放。
3. Graphic_Multi 需要 4 个方向后缀文件（north/east/south/west）；对称设备可先只做 2 向（东西同图镜像）。defName 与 texPath 末段保持一致（`PC_SowerModule` → `PC_SowerModule.png`）。
4. 蓝图/幽灵贴图由原版自动生成，除非默认变蓝后不可读，否则不自绘。

## 7. 技术红线（批量验收硬条件）

| # | 条件 | 原因 |
|---|---|---|
| 1 | PNG-32：RGBA 8bit/通道，透明底（alpha 通道保留） | RGB 无透明会被原版当矩形色块渲染 |
| 2 | 禁止索引色/16bit/交错(interlaced) PNG | 原版加载异常或色彩偏移 |
| 3 | 设计分辨率 1:1 交付，禁止缩放交付 | 点采样下缩放即糊 |
| 4 | 贴图 : drawSize = 64px/格 | 全设备视觉密度一致 |
| 5 | 透明区 alpha=0 且 RGB 任意（不填黑晕） | 边缘白边/黑边问题 |
| 6 | 文件 < 200KB（64px 类 < 30KB） | 现有同类资产均远低于此 |

## 8. 存量资产问题清单（批量生产前顺手修）

| 文件 | 问题 | 建议 |
|---|---|---|
| `PC_AutoFarm_S` | Def 中 drawSize (1,1)，与 2×2 占地不符，游戏内视觉密度比 M/L 低一档 | 复核 S 级实际占地，统一为 64px/格 口径 |
| `Textures/UI/epic/*` | RGB 无 alpha、1024×1024（单文件 >1MB），且存在 `epic/epic/` 嵌套重复 | 降为合理尺寸 + RGBA，删重复副本 |
| `Textures/Medals/*`（中文文件名组） | 与英文命名组疑似重复，命名违反 ASCII 规则 | 确认 Def 引用后清理未引用组 |

## 9. 批量生产 SOP（每张贴图走一遍）

1. **画前**：确认设备占地面数、是否需要四向、主功能色（查 §2.2 语义表，没有就先登记）。
2. **画中**：对齐基准件 `PC_AutoFarm_M`（明度/做旧/密度三对照），执行 §5 结构语汇 4 要素。
3. **自检**：过一遍 §7 六条技术红线。
4. **对比验收**：把新贴图与基准件 + 同族已有件拼在一张图上看（同缩放），检查：
   - 整体明度是否一致（新件明显更亮/更暗 = 打回）
   - 细节密度是否超基准
   - 功能色语义是否正确
5. **游戏内验收**：入 Def → 进游戏看三态：正常放置态、变蓝图态（蓝色滤镜下是否可读）、开/关停态（指示灯语义是否成立）；截图存档。
6. **登记**：在本文档 §10 设备清单中勾选完成状态。
