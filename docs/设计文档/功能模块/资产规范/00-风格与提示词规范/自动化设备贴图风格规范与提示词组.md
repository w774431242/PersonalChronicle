# 自动化设备贴图 · 统一风格规范与分层提示词组（主体+组件式组合）

> 适用范围：`PersonalChronicle` 自动化体系全部贴图（农机三档 / 传送带 / 组件物品 / **物流管道**）。
> 目标：与 RimWorld 1.6 原版资产视角、风格一致，杜绝白底与视角跑偏。
> **核心设计**：农机是「主体机架 + 功能组件」的模块化组合体。提示词按五层组织，
> 组件在「物品态」（Layer 2）与「上车态」（Layer 3）之间靠**特征锚点**保持同一
> 识别特征，玩家能从整机贴图上认出每个组件。
> 管线：本文档提示词 → `image_gen` 生成 1024px 白底图 → `_scripts/process_autofarm_textures.ps1` 抠底缩放入库。

---

## 1. 原版视角铁律（为什么之前的图不像）

RimWorld 原版建筑/物品贴图**不是纯俯视，也不是等距轴测**，而是：

- **高角度斜俯视（约 55°~65° 自垂直方向前倾）**：能同时看到 **正面（最主要，占画面 60%+）** 与 **顶面（窄条）**，两侧面几乎不可见（只露出极窄的侧边）。
- **无旋转基准**：建筑默认朝南（`north` = 背面），玩家看到的正面朝向屏幕下方。
- **无透视收缩**：正交投影，近大远小不存在；同一物体所有棱边平行。
- **物品（64px）**：与建筑同视角，只是更小、更简洁，通常一眼能认出"这是个箱子/零件/罐子"。

反面案例（本次返工原因）：之前生成的图是"正面平视 + 轻微俯角"，看起来像盒子正对着镜头，与原版"从斜上方看机器"的感受完全不同；且背景未抠干净留白框。

## 2. 分层提示词架构（层次感来源）

```
Layer 0  Style Core   统一风格后缀 —— 所有提示词末尾必拼，一次定义全局一致
Layer 1  Chassis      规格机架（裸机架）—— 决定 S/M/L 的体型与轮廓，顶部留出组件安装位
Layer 2  Module       组件单体（64px 物品）—— 独立生成，确立每个组件的"特征锚点"
Layer 3  Mounted      组件上车短语 —— 描述组件装上机架后的样子，锚点与 Layer 2 一致
Layer 4  Composed     整机合成 —— Style Core + 机架 + 该档实装组件的 Mounted 短语
```

**三条铁律**：

1. **锚点一致**：同一组件在 Layer 2 与 Layer 3 必须复用相同的关键特征词
   （如生长灯永远是 "pale warm-white lamp tube with metal end caps"），
   禁止换词，否则玩家认不出"这个东西就是背包里那个组件"。
2. **机架先行**：整机提示词 = 机架描述在前（占画面主体）+ 组件短语在后
   （逐条挂接）。组件短语只描述"装在哪、长什么样"，不重复机架内容。
3. **规格即实装**：Layer 4 的整机组件清单必须与游戏内组装链一致
   （v2.1 §15.5：S=播种+收割；M=+灯+水+电；L=+肥+太阳能、组件翻倍）。

## 10. 处理管线（生成后必跑）

```powershell
# 物品（白底图，默认 near-white 抠底）
.\_scripts\process_autofarm_textures.ps1 -InputDir <raw> -OutputDir .\Textures\Things\Item\AutoFarm -Size 64

# 非白底（AI 画了浅橙/灰背景）用边缘泛洪，防止误删浅色机身
.\_scripts\process_autofarm_textures.ps1 -InputDir <raw> -OutputDir <out> -Size 64 -EdgeKey -Tolerance 60

# 传送带四向旋转
.\_scripts\rotate_conveyor_sprites.ps1
```

- **教训**：两段式 near-white 会把浅色机身误删；`-EdgeKey` 只用于非白背景图（纯白背景用默认模式，否则会穿透浅色机体）。
- **单文件单次处理**：脚本会处理 InputDir 内**全部** PNG 且互相覆盖，多规格必须每张单独跑（一次只留一个文件），否则后跑的小尺寸会覆盖先跑的大尺寸（2026-09-05 实测教训）。
- 入库后 `Add-Type System.Drawing` 抽查四角 alpha 应为 0。
- **游戏内仍有白框 = 没重启**（RimWorld 不热加载贴图）。

## 12. 物流管道 PC_Pipe（贴地层 · 连接掩码制）

> 与前面所有条目**视角不同**：管道是贴地/埋地层元素（`altitudeLayer=Conduits`），
> **不是立体物体**，因此不能用 §3 的机器 Style Core（那是斜俯视立体视角），
> 必须用下面的**贴地层专用 Style Core**。
> 当前素材由 `gen_pipe_trench_sprites.ps1` 程序化生成；本章提示词用于
> **改用 AI 生成更美观版本**时保持同一套形态与命名。

### 12.1 形态模型（先理解，再写提示词）

按**四邻连接掩码**出图，`bit0=N bit1=E bit2=S bit3=W`，共 16 种：

| mask | 形态 | mask | 形态 |
|---|---|---|---|
| 0 | 孤段（按竖管） | 8 | W 端头 |
| 1 | N 端头 | 9 | N+W 拐角 |
| 2 | E 端头 | 10 | E+W 横管（主体） |
| 3 | **N+E 拐角** | 11 | N+E+W T 型 |
| 4 | S 端头 | 12 | **S+W 拐角** |
| 5 | N+S 竖管（主体） | 13 | N+S+W T 型 |
| 6 | **E+S 拐角** | 14 | E+S+W T 型 |
| 7 | N+E+S T 型 | 15 | 十字 |

**三条形态铁律**（比美术风格更重要，违反就拼不上）：

1. **边缘贯通**：管路在每个连接方向必须延伸到画布**正边缘**且居中，不得留白、不得内缩。
2. **中心交汇**：多臂在中心 24×24 区域交汇成整块，不能出现"十"字缺口。
3. **只画到中心线**：每条臂占**半格**（N=上半 / S=下半 / W=左半 / E=右半），
   否则会画满整格退化成直管（2026-09-07 实测教训）。

### 12.3 形态提示词组（拼在 Style Core 之前）

> `[ARMS]` 占位处填"臂位描述"，四方向写法固定为
> `top edge`=N、`right edge`=E、`bottom edge`=S、`left edge`=W。

**① 主体直管（mask 5 / 10）**

```
a straight floor trench running vertically through the whole tile, centred,
entering at the top edge and continuing out of the bottom edge, with a
gunmetal pipe laid inside, [STYLE CORE-P]
```
横管把 `vertically / top edge / bottom edge` 换成 `horizontally / left edge / right edge`。

**② 拐角 L（mask 3 / 6 / 9 / 12）—— 你最关心的直角**

```
an L-shaped right-angle elbow floor trench: it enters from the top edge,
turns 90 degrees at the tile centre, and continues out of the right edge,
with a continuous gunmetal pipe following the bend, a small corner junction
plate at the centre, [STYLE CORE-P]
```

四个拐角只换方向组合：

| mask | 入口 → 出口 |
|---|---|
| 3 | `enters from the top edge … continues out of the right edge` |
| 6 | `enters from the bottom edge … continues out of the right edge` |
| 9 | `enters from the top edge … continues out of the left edge` |
| 12 | `enters from the bottom edge … continues out of the left edge` |

**③ T 型（mask 7 / 11 / 13 / 14）**

```
a T-junction floor trench: a straight vertical run from the top edge to the
bottom edge, plus a branch turning 90 degrees at the centre and continuing
out of the right edge, with a junction block at the centre, [STYLE CORE-P]
```

**④ 十字（mask 15）**

```
a four-way cross junction floor trench: one run from the top edge to the
bottom edge crossing another from the left edge to the right edge, with a
square junction plate at the centre, [STYLE CORE-P]
```

**⑤ 端头 / 死头（mask 1/2/4/8）**

```
a dead-end stub floor trench: it enters from the top edge and stops at the
tile centre with a sealed end cap plate, [STYLE CORE-P]
```

**⑥ 端口变体 In / Out（覆盖在直管之上，各 4 向）**


### 12.5 强烈建议：一次生成「形态总表」再裁切

与 §8 传送带的"整条长带三等分"同一思路——**风格统一度最高**的做法：

```
a single reference sheet: a 4 by 4 grid of the SAME floor pipe tile showing
all 16 connection states (isolated stub, four dead ends, four L elbows,
two straight runs, four T junctions, one cross), every tile identical in
style, colour and line weight, arranged in reading order with no gaps between
cells, [STYLE CORE-P]
```

生成 1024px 后按 4×4 等分裁成 16 张（每张 256 → 缩 64）。**同一张图出来的 16 个形态，
风格 100% 一致**，远优于分开生成 16 次。
