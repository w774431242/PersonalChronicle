## 2. 三级设备体系的视觉区分（出图前先背下来）

| 维度 | T1 智能化 | T2 半自动化 | T3 全自动化 |
|---|---|---|---|
| 操作方式 | pawn 站台操作，智能辅助（屏幕/辅助臂） | pawn 上下料，机器封闭加工 | 无人，传送带直进直出 |
| 造型语言 | **开放式工作台**：台面 + 围栏 + 智能屏 | **半封闭箱体机**：料斗 + 观察窗 + 出料槽 | **全封闭生产舱**：装甲外壳 + 传送口 + 机械臂 |
| 占地/画布 | 2×2 / 128px | 2×2~2×3 / 128px | 3×3 / 256px |
| 家族识别 | 有 pawn 站位缺口（台面前沿留空） | 有料斗入口 + 出料口 | 只有传送带接口，无缺口 |
| 细节密度 | 低（基准件的 60%） | 中（基准件的 80%） | 高（= 基准件 PC_AutoFarm_M） |

**同一工序的三级设备必须轮廓可区分**：玩家看剪影就知道等级——T1 有"人位"，T2 有"料口"，T3 是"铁盒子"。

### 3.5 环世界 2D 俯视正交视角强化要点

所有设备出图必须呈现**环世界原版建筑贴图的 2D 俯视正交观感**，逐条自查：

- **正交（orthographic）**：无透视、无灭点、无近大远小；物体尺寸恒定，像瓦片平面拼图。
- **正俯视**：相机在物体正上方，看到的是"顶面平面布局"，不是斜 45° 等距（isometric）。
- **北朝上（north-up）**：贴图顶部 = 地图北；传送带流向 / 料口方向以此为基准（east 为默认基准向）。
- **无地面 / 无投影**：只画物体本体，透明底；不画地面块、不画接触阴影、不画地平线。
- **平涂着色**：以 flat shading 为主，避免球面高光、体积光、渐变天光，保留硬边机械细节。
- **极薄上沿**：允许顶面边缘有一道极薄"立面亮边"暗示厚度（同原版墙体/导管），但不得做成 3D 拉伸盒。

> 自检对照：把出图与 `PC_AutoFarm_M` / 原版 `ElectricSmelter` 等建筑贴图并排——若你的图显得"立体盒子/有灭点/带地面阴影"，即未达成正交俯视，必须重出。

## 7. 出图后技术红线（同美术风格规范 §7，验收时逐条过）

1. PNG-32 RGBA 透明底，无索引色/16bit/交错；
2. 设计分辨率 1:1，只降不升；
3. 贴图 : drawSize = 64px/格；
4. 透明区 alpha=0 干净，无黑晕白边；
5. 64px 类文件 < 30KB，128px < 80KB，256px < 200KB；
6. 同缩放与基准件 `PC_AutoFarm_M` 拼版对比：明度/做旧/密度三项目测一致。

游戏内验收三态（放置态/蓝图态/开关态）见美术风格规范 §9 第 5 步，不重复。
