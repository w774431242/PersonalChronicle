> **四向贴图（已定）**：全部 12 台走 `Graphic_Multi`，**east 为基准向**（进左出右/操作位朝右），与 T2/T3 一致。

> **功能与数值真源**：`../T1_智能化生产设备_功能数值设计.md`（占地/造价/耗电/研究档位/升级机制均查该文档，本文只管「长什么样」）。

## 本级统一备注

1. 所有屏幕统一画成"深灰底 + 功能色细字/细线"，禁止大面积亮屏（会破坏整体明度关系）。
2. 台面材质统一深灰拉丝金属；木工台可加浅色台面但面积 <20%。
3. 每台必须有：智能屏（等级识别标志）+ 台面前沿空缺口（pawn 站位）。
4. 出图后按 00 文件 §4/§7 验收；拼版对比对象为基准件与同工序 T2（确认轮廓可区分）。

## 细节密度 60% 的量化口径

> 补 `自动化设备_美术风格规范_v1.0.md` §1「密度上限以基准件为准」的 T1 细则。
> **口径 = 独立机械细节元素数约为基准件（`PC_AutoFarm_M` = 100%）的六成**，不是把线宽画细 40%（线宽受 2px 最小单位限制，不可再减）。

| 元素类型 | T1 上限 | 基准件对照 |
|---|---|---|
| 独立功能模块（屏 / 表 / 罐 / 架） | ≤ 3 个 | M 为 5 模块 |
| 管线 / 电缆接口 | 1 处 | M 为 2 处 |
| 指示灯珠 | 2~3 个 | M 为 4~5 个 |
| 面板分缝 / 铆钉行 | 台面 2 条 + 机身 1 行 | M 为 3 条 + 2 行 |
| 做旧痕迹（锈斑 / 划痕） | 边角 2 处 | M 为 3~4 处 |

## 三级区分自查（出图后逐项过）

拼版对比时，同工序三台放一起看，必须满足「一眼可辨等级」：

| 检查项 | T1 应有 | T2 应有 | T3 应有 |
|---|---|---|---|
| 台面前沿 pawn 站位缺口 | **有**（T1 独有标志） | 无 | 无 |
| 料斗入口 / 出料槽 | 无 | **有**（T2 独有标志） | 传送口（贴地） |
| 排气管 / 除尘管 | 无 | **有**（12 台全保留） | 无（封闭舱） |
| 封闭程度 | 敞开工作台 | 半封闭 + 观察窗 | 全封闭装甲 |
| 底盘 | 各自成形（无统一底盘） | 各自成形 | **统一 3×3 底盘**（一字不改） |
| 细节密度 | 60% | 80% | 100% |

> **T1 与 T2 最容易混淆的边界**：两者都是 2×2、都是 128px。区分靠「**看不看得见台面缺口**」——
> 能看见 pawn 站位缺口 = T1；能看见料斗 = T2；两者都无 = T3。
