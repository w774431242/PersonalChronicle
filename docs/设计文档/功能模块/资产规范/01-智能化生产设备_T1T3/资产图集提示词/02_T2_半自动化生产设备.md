# 资产图集提示词 · 02 T2 半自动化生产设备 v1.0

> **等级定位**：半自动机级——pawn 只负责上下料，加工过程在半封闭箱体内完成。
> **造型铁律**：必有**料斗入口**（进料侧）与**出料槽/口**（出料侧），加工区半封闭 + 观察窗；无全封闭装甲（那是 T3），也无 pawn 站位缺口。
> **公共段**：`00_公共风格基底与使用说明.md` §3，拼装公式 = STYLE_POS + TIER_T2 + 设备主体段 + 功能色段。
> 规格：占地 2×2~2×3｜画布 128×128｜细节密度 = 基准件的 80%。
> **视角强化**：所有设备必须呈现环世界原版 **2D 俯视正交**观感（见 `00_公共风格基底` §3.5）——料斗/出料槽在俯视平面中左右可见，无透视、无地面、无接触阴影；一致性对照以原版 `ElectricSmelter` 等建筑贴图为准。

## 本级统一备注

1. "进料侧在左、出料侧在右"默认统一（与 T3 传送带流向一致，玩家读图零学习成本）；因四向贴图会旋转，east 向为基准向。
2. 观察窗画"深色玻璃 + 内部微弱工作光"，不透亮；内部机构只露 2~3 处关键件。
3. 排气管/除尘管是本级等级识别标志之一，12 台全部保留。
4. 与 T1 的区分自查：拼版对比同工序 T1，确认本机"看不到台面缺口、能看到料斗"。
