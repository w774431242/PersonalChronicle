# T1 基础设施：美术资产设计与提示词

日期：2026-10-06。状态：拟定稿 v0.1；本批尚未生成 PNG、导入游戏或验证实际贴图。

设计范围为 14 种建筑、56 个方向。`分方向提示词/` 中每份 TXT 可直接复制用于一次生成；文件正文没有 defName、文件名、成本与解释记录。`按设备合并/` 中每份 TXT 收纳四段独立提示词，供查看与选择，不应一次提交要求生成四个方向。

对应 [完整玩法方案](../../自动化体系规范/02-基础设施与电力/AUTO-2026-10-06-T1基础设施补全设计方案.md)。建筑参数与名词映射见 [资产清单](资产清单.json)。清单中的 defName、目标路径、尺寸和数值都是拟定值，尚未注册为运行资源。

交付 ZIP 包含本批设计、提示词、校验文件与已有 T1 风格参考预览。历史四向修订记录的链接用于工作区内查阅，其全部历史对照图不重复打包。

## 1. 视觉锚点与尺寸口径

主视觉参考 [当前 T1 十台设备预览](../02-T1生产设备/T1生产设备_导入预览_2026-10-05.png)，结构方向参考 [现有四向修订](../02-T1生产设备/T1生产设备_四向修订_2026-10-05/修订记录与对照图索引.md)。前者是已有设备贴图预览，不是本批新设施的样张。

- 正交俯视、短侧边、深色轮廓、低饱和钢灰/暖灰/暗灰；采用清楚的色块，不走写实照片、等距模型、像素画或密集机械线条。
- 功能读数屏用少量暗青；能源识别采用暗钢蓝；黄色只用于少量警示。太阳能板本身是暗蓝光伏材料，允许其大面积出现；不把整机涂成蓝色。普通无电仓储只使用机械标签槽，不画常亮屏幕。
- 没有可读文字、数字、logo、库存数量、固定电量、固定温度或灯光投影。真实库存和状态由游戏数据与渲染绘制。
- 新资产归建筑 D 类。拟定运行目录为 `Textures/Things/Building/T1Infrastructure/`；PNG 使用清单中的全 ASCII 名称，以 `PC_T1_` 开头并带 `_north/_east/_south/_west` 后缀。
- 本批继承当前 T1 长方形四向画布路线，**不按旧农机规范强制正方形**。采用拟定 `drawSize=(占地宽+0.5, 占地深+0.5)`，为外壳与透明边留空间；东西向交换宽深。该 drawSize 与占地不是同一个概念，后续需以放置预览检查轮廓和操作格。
- 母图按拟定 drawSize 每格 256 像素；游戏图通常每绘制格 128 像素，3×1 台为 448×192，沿当前已导入 T1 规格。大光伏采用 96 像素/绘制格，导出 432×336，全部目标边长小于 512 像素。绘制密度是本批建议，不把它写成旧规范已经统一采用的标准。
- 图像模型未必支持表中精确尺寸，返回结果也未必有合格 alpha；提示词只表达目标。实际生成后先核对部件、比例、边缘与透明通道，再通过等比缩小和透明画布适配导出；禁止拉伸、超分填细节或把白底图当成透明图。

## 2. 四向与部件坐标

北向是结构母版，前沿在画面下。东向前沿左，南向前沿上，西向前沿右；北→东→南→西按机体俯视结构顺时针转向，相机保持固定。名称中的宽度指北向占地，东西向应变成纵长设备。

每份独立提示词都列出该方向每个固定部件的画面位置；它们比“左边有发动机”这种没有方向语境的描述优先。端挡、标签槽、面板、反应罐、进料托盘、冷凝件的数量与结构在四向之间保持一致，不可以靠镜像生成另一方向。

工业冷却器必须与原版 `South.RotatedBy(rotation)` 冷端与 `North.RotatedBy(rotation)` 热端对应。北冷下热上，东冷左热右，南冷上热下，西冷右热左。

采用“先北向结构样张→用户选择的母版→同物体其余方向”的制作顺序。其余方向生成时把实际北向图作为图像参考，仅靠四段文字独立抽样无法保证部件完全一致。参考图必须是设备本体，不是文档里的多设备带文字总览。

## 4. 各设备的辨识重点

| 设备 | 一眼看出的主结构 | 最容易画错的地方 |
|---|---|---|
| 燃油机 | 发动机＋发电机壳＋燃料箱 | 每方向重排油箱和排气；画成工作台或大烟囱 |
| 光伏 | 两块宽板＋小逆变器盒 | 透视斜立板、高脚架、细碎电池片反光 |
| 电池 | 方形封闭电芯组＋检修条 | 发光科幻电池；在四向复制相同接线盒位置 |
| 配电柜 | 单格低矮顶置箱＋机械拨杆 | 画成高柜，与可站立开关的通行行为矛盾 |
| 通用架 | 三开放浅分区＋层板 | 烘焙满载货物；生成高货架正面透视 |
| 重载架 | 粗加强梁＋两端挡板 | 多加起重机或自动进料口 |
| 物资柜 | 分类顶面＋短门沿＋标签槽 | 用药品图标假装治疗；库存永久画死 |
| 冷藏柜 | 隔热双盖＋压缩机盖＋格栅 | 画成普通货架；大量冰雾、固定温度数字 |
| 备料架 | 两个空浅托盘＋取料缺口 | 画成传送带或自动喂料机 |
| 工具柜 | 固定工具座＋浅工具盘 | 画成另一台可生产的机床 |
| 工作灯 | 宽灯面＋短支座 | 高杆、地面光晕、带背景的灯光效果 |
| 冷却器 | 冷端窄槽＋热端粗格栅 | 冷热端换位；四向与真实温控方向相反 |
| 炼制台 | 进料盘＋矮反应罐＋冷凝件 | 画成金属熔炉或无人舱；改变管路连接 |
| 研究台 | 固定仪器＋开放工作面＋小读数屏 | 全息电脑、文字笔记、把它画成高科技研究机房 |

## 5. PNG 阶段验收

本轮检验范围仅为 TXT 与设计清单，以下是后续实际图片的验收要求：

1. 每种四向齐全，名称与清单一致；真实 PNG RGBA，四角透明，背景没有白/灰边和棋盘格。
2. 四向固定部件逐项核对；检查东西向纵长、冷热方向、前沿和转向轴，而不是只确认文件后缀齐全。
3. 提示词所画的托盘为空；固定仪器与工具可以画入本体，实际仓储货物不能画入本体。
4. 缩小到目标游戏尺度并排比现有 T1；前后沿、格栅和工具轮廓可辨，无噪点或过密细线。
5. 占地、drawSize、选择边界、操作格、相邻通行和渲染库存逐项实机查看；提示词尺寸不能作为已经落地的证据。
6. 冷藏柜即便美术完成，也须待 C 批功能验收通过后才作为可建造建筑发布。

已有 `prepare-t1-textures.py` 从 `Defs/T1_Production.xml` 读取十台生产设备，并固定使用 448×192/192×448；本批不能直接套用该脚本导入全部新设施。后续需按本批清单与实际 Def 扩展导入流程，先保留母图再导出目标图。
