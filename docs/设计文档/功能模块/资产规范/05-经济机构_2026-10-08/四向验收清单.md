# 经济机构四向资产验收

北向为每机构唯一母图；其余三向均直接引用北向生成。检查结果分为文件与图像结构验证、生成图肉眼复核、实际游戏渲染三层，不能互相替代。

本批“健康状态”指完好柜台及完好产品的基础贴图：不烧录损坏、断裂或缺件。游戏受损叠加仍由原版处理。独立重绘允许细小描线和盘内位置差异，不等于逐像素旋转一致；书脊、夹口、卷边、领口、屏幕与器械端点等方向锚点必须随柜台转向。

## 单图与跨方向判据

| 检查 | 通过条件 |
| --- | --- |
| 命名与映射 | 每机构 `_north/_east/_south/_west` 四个真实 PNG，Graphic_Multi 基路径无方向后缀，菜单显式指向 `_north` |
| 参考一致性 | 东/南/西的生成记录均绑定本机构最终北向 SHA-256，不引用其他方向作母图 |
| 背景/画布 | RGBA真透明、边缘Alpha仅0或1（8位编码最低一档残留）、主体不截断、无背景地板或纯白矩形；严格全零边界状态与低Alpha噪点另行报告，保留原始PNG不抠图 |
| 几何 | 北/南主体竖向，东/西横向；中心误差≤画布4%，可见轮廓留边≥3.5%，1×2/2×1占地对应；长/短轴各相对北向偏差≤10%，不得被大量透明留白掩盖 |
| 布局 | 物件整体随朝向变换，物体的局部前后左右关系不改变，不得“转了桌框却没转组件” |
| 物件健康 | 银币圆整、工具完整、衣物领口/折叠分明、医疗管线连接合理，无多余零件、穿插、粘连、断裂或融化 |
| 材质/光照 | 柜台和物件材料一致；世界顶光按方向重新绘制，避免把原图高光/阴影一起死板旋转；不改变功能种类 |
| 本地化 | 无烧录文字/数字，原标签继续由游戏双语Def控制 |

## 游戏中逐项勾选（待玩家执行）

- [ ] 完全重启游戏，五个建造图标不再为同一白色长方块；无对应贴图加载错误。
- [ ] 每类机构在空地分别预览 N/E/S/W，共20个朝向；方向正确，东/西没有被自动镜像替代。
- [ ] 旋转前后桌面比例和中心不跳动，北/南1×2、东/西2×1；无明显多占格、裁切或拉伸。
- [ ] 放置20个样本，近看和正常缩放分别检查工具、衣物、币盘、医疗管线无变形/僵硬错位。
- [ ] 不只看菜单：建筑实际显示、蓝图、框架、选中高亮、受损显示均可识别，无白块/洋红。
- [ ] 旧存档已建柜台保留同一Def身份，重载后换新贴图；账户和储备不变化。
- [ ] 每向柜台旁通行和到场办理正常，25银币缴存/提取无原版寻路或预约回归。
- [ ] 中文/英文、1920×1080常用UI缩放下图标清楚，名称未烧录在PNG中。

反馈请给机构名、方向、缩放、截图及首次日志；若某方向组件不正常，单独修订该方向并再次对照北向，不以整体“看起来像”代替检查。本清单全部游戏项初始为未测。
