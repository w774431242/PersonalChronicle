## 任务与架构审查

用户截图显示五个相同白色长方形建造图标；当前五类机构继承相同原版 Table1x2 图形与 drawSize=(3,4)，没有自身资产或专门 uiIconPath。原版 Table1x2 确有同名路径，因此不将截图直接定性为文件找不到；本次用独立资产与明确路径解除占位外观，并检查当前日志是否存在其他加载错误。

采用 D 类建筑资产：`Textures/Things/Building/PawnEconomy/PC_PEA_<Institution>_<north|east|south|west>.png`。根据用户补充要求，每机构先确定北向母图，再使用同一北向图分别生成东、南、西图；共20张，Graphic_Multi + drawRotated=false。每个方向重新渲染物体在该方向的形态及世界顶光，避免只旋转整张图造成高光/边缘僵硬；不能改变组件数量、局部布局、材质、配色和资产身份。地图占地仍 (1,2)，四向可旋转、可穿行、服务寻路与旁路账目保持；square 画布与 drawSize=(2,2)，主体约占0.8×1.6格（E/W交换），防止占位3×4绘制过大。

每机构 graphicData.texPath 绑定无方向后缀的基路径，uiIconPath 明确绑定 `_north`；不靠缺失方向自动镜像或回退。颜色和物件语汇：劳务站=蓝色档案/合同夹；工坊管理处=橙色图纸/工具；结算处=黄铜/银币盘及账簿；商店=绿色衣物货格；体检中心=白色青绿检查仪器/听诊器。统一简洁描边、低饱和色、无文字、无人、无房屋/地板/环境背景。正常产品形态检查包括：工具无断裂/多余手柄、衣物领口与折叠无融合、银币圆形和分组不变、医疗管线连续且不穿插、柜台边框闭合而不弯曲；不能仅按文件存在宣告健康。

扩展点仅原生 Def 与 PNG，RUIF 前端未改；无 C#、Harmony、存档 schema、DefName、机构种类、支付能力或一般收费开关变化；不新增第三方依赖。规则：GOV-013、AI-001/002/013/014、DATA/ASSET/ART、REL-002。已读总纲、矩阵、术语、AI、表现与美术专项规范。已核对原版 Graphic_Multi 的方向材质映射；此前单图旋转草稿已由用户本条四向要求替代，未部署单图方案。

## 制作与验证计划

使用内置 image_gen 串行独立生成每方向，全部以本机构北向为参考，不链式东转南转西累积漂移；直接保存透明 PNG，不用白底/绿底抠图，不程序旋转/镜像替代方向图，不把模型输出仅留缓存。产出保存到运行 Textures 并保存逐图提示词、北向参考路径/哈希、原始路径和哈希。检查 RGBA、透明边界、主体比例、无裁切、五机构可区分、四向锚点/组件健康，并肉眼审查；必要时由 image_gen 定向修订。验证 XML继承、原版字段、全部20路径存在/一致、PNG完整性、原版方向规则、占地与交互字段保持。仅资源变动不重复编译/全量逻辑测试；跑适用 Def 检查和部署哈希核对。正式全局 gate 缺失仍如实标记。

部署只同步本批 Def 与20个 PNG，备份旧 Def、保护工坊 ID 与其他资源；运行中游戏只部署资源副本并要求完整重启，不能声称热重载。实机须检查：五个建造图标、20个N/E/S/W放置预览、实际占地/穿行/柜台到场、缩放清晰度、旧柜台读档后换图、原请求恢复不受影响。缺少实机画面时仅称已接入待验收。
