## 落位规则（新增资产批次时按此判定）

| 文档 / 产物性质 | 落位 |
|---|---|
| 风格规范、通用提示词组（跨批次长期有效） | `00-风格与提示词规范/` |
| 分级设备设计真源 + 资产图集提示词（T1/T2/T3 设计线） | `01-智能化生产设备_T1T3/` |
| 已实装设备的出图批次（提示词 / 母图 / 四向修订 / 核查） | `02-T1生产设备/` 或新建同级 `0N-<对象>/` |
| 新批次提示词与母图 | 新建 `0N-<对象>_美术提示词_<日期>/`（编号递增，内含 `分方向提示词/` + `资产清单.json`） |
| 未通过验收 / 被取代的批次 | 留在原批次目录并显式标注「未通过验收」或移入该批次的 `废弃*/`（只进不出） |
| 运行贴图（PNG 入库件） | 不放本目录 → `Textures/Things/Building/<Sub>/` |
| 命名 / 尺寸 / 格式铁律 | 不放本目录 → [`../../架构/10-美术资产标准化规范.md`](../../架构/10-美术资产标准化规范.md) |

**批次目录约定**：`分方向提示词/` 每份 TXT = 一次生成；`按设备合并/` 仅供查看，不得一次提交四方向；母图（原始尺寸）与游戏尺寸分目录保存，游戏尺寸目录按 `Textures/Things/Building/` 镜像以便整目录拷入。
