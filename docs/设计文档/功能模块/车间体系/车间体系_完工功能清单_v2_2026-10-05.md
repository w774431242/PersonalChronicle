# 车间体系 · 完工功能清单（v2 基线）

- **基线日期**：2026-10-05（车间模块完工封版）
- **规模**：约 **136 个文件 / 3.5 万行**（含 Domain/Data/UI/Capture 的车间件），另有 4 份车间 Def XML
- **生成方式**：4 路并行代码扫描（排班/设备/UI/岗位餐饮各一路）+ 36 条 CHG 变更史汇总 + 关键条目交叉核实
- **用途**：后续"联动打磨"的索引 —— 改任何一处先查本清单定位责任链与已登记残留
- **与旧文档关系**：本文档**取代** `车间体系_功能模块清单.md`（2026-09-11，已过时两轮迭代；2026-10-05 文档整理时移入 `docs/_归档/`）；设计意图仍见 `车间体系_设计蓝图.md` / `车间体系_排班企业化设计.md`
- **标注约定**：`⚠` = 代码注释明确登记的残留/限制；`★` = 本次扫描**新发现**（此前未登记）；`✅已核实` = 本次逐条查证过事实

## 1. 模块总览

### 1.1 边界

**属于车间体系**：车间区域（Zone）、设备与台账、班次/班组/固定班/倒班、岗位体系、值勤与考勤、作息与三餐联动、车间管理面板 7 页、制造中心俯视图与自由编排画布、设备详情窗、相关 StatPart 与 Harmony 补丁、车间 Def/设置/语言。

**不属于**（同目录但属其它域，勿混入本清单）：农业自动化（`CompAutoAgriculture*` / `Building_AutoFarm` / `Designator_AutoFarmGrowZone` / `MapComponent_AutoFarmTerrain` / `Dialog_AutoFarmSetup` 等）、物流管道与传送带（`CompItemPort` / `CompItemStorage` / `Building_PipeSegment` / `Building_ConveyorSegment` / `MapComponent_PipeNetwork`）、殖民地经济/传承/职业档案等其它模块。

### 1.3 三条主链（速览）

| 链 | 路径 |
|---|---|
| **① 排班链** | 班次/班组/固定班（Zone_Workshop + Manager 存档）→ `RebuildDutyPlan`（三级：固定班 > 班组 > 轮岗）→ `TryGetDutyJob` → `JobDriver_WorkshopDuty`（走到工位·站岗）→ `NotifyDutyEnded` → 考勤/绩效入账 |
| **② 作息链** | 班次窗口 + 摸鱼 + 三餐（∩ 本班次工作时段）→ `WorkshopDutyCoordinator.SyncVanillaTimetables`（**唯一** timetable 写入口）→ 原版管制表 → `MapComponent_MealSchedule` 按表写用餐工作档位 → `WorkGiver_Meal` 发 Ingest |
| **③ 数据链** | 60 tick 设备扫描 → `WorkshopDeviceLedger`（运行/产出/产值/窗口计数）→ UI（设备页表 / 概览 KPI / 俯视图设备卡）+ `Patch_GenRecipe` 产出归账 |
