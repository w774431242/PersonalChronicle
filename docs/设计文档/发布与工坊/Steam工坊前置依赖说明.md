# 创意工坊「前置依赖与重要说明」

可直接放在 Steam Workshop 描述顶部或更新说明里。简体中文优先，英文附后。

---

## 简体中文

```
【前置依赖】
- 游戏版本：RimWorld 1.6（不支持 1.5 及更早版本）。
- 必需依赖：Harmony（创意工坊 ID 2009463077，订阅后自动加载，无需手动排序）。
- 本 mod 仅依赖 Harmony，不依赖任何其它 mod；与绝大多数 mod 兼容。

【重要说明】
- 档案馆定位：本 mod 只读取并记录，不修改任何游戏机制、不干预平衡、不增加性能负担到可感知程度。
- 从安装并开新档后开始记录；中途加入存档只能补全「当前存活殖民者 + 已故墓碑者」两类当前状态，历史事件（过往战役、击杀、生产）引擎不保存，无法回溯补全。
- 数据持续写入存档；读旧存档时按 Save Schema 自动迁移，老存档零配置兼容。
- 第三方 mod 可通过 PersonalChronicleApi 接入（TryGet 获取门面），契约版本与发布版本对齐（v1.0.0）。
- 反馈与 bug 请在工坊讨论区或仓库提交，附 Player.log 片段可大幅加快定位。
```

## English

```
[Prerequisites]
- Game version: RimWorld 1.6 (not compatible with 1.5 and earlier).
- Required dependency: Harmony (Workshop ID 2009463077; auto-loaded after subscribing, no manual load order needed).
- This mod depends only on Harmony and is compatible with virtually all other mods.

[Important Notes]
- Archive philosophy: this mod reads and records only. It never alters game mechanics, balance, or adds noticeable overhead.
- Recording starts from a fresh game after install. For mid-save installs, only current state (living colonists + tombstoned pawns) can be backfilled; past events (battles, kills, production) are not stored by the engine and cannot be retro-filled.
- Data is continuously written to your save; old saves auto-migrate via Save Schema, zero-config compatible.
- Third-party mods can integrate via PersonalChronicleApi (TryGet for the facade); the contract version is aligned with the release version (v1.0.0).
- For feedback and bug reports, please use the Workshop discussion or the repository, ideally with a Player.log snippet to speed up triage.
```
