# 市场经济框架（MVS）· 数值稳定性离线仿真报告

> 补《市场经济框架_v1设计方案》**§9.1 门禁③「数值稳定性」的离线部分**（参数 1–5、9–12、14、15）。
> 参数 6–8、13、16 需游戏内长时观测，本报告只给**可行区间初值**，不代表已定稿。
> 仿真器：`_scripts/mvs_stability_sim.py`；原始结果：`_scripts/_mvs_stability_results.json`。

---

## 1. 建模口径

闭环（每步 = 1 游戏日）：**存量 S → 价格因子 F → 消费 δ → 存量 S'**

| 步骤 | 式 | 参数 |
|---|---|---|
| 目标价 | `F* = (S_eq / S_t) ** k_d` | `k_d`（需求系数，F* 斜率） |
| 平滑 | `F_tgt = F_{t-1} + α·(F* − F_{t-1}) + rev·(1 − F_{t-1})` | `α` 平滑、`rev` 回归 |
| 夹逼 | `F_tgt = clamp(F_tgt, Fmin, Fmax)` | `[Fmin,Fmax]` |
| 冲击 | `F_tgt *= (1 + shock_t)`，再 `F_t = F_{t-1} + clamp(Δ, ±shockCap)` | `shockCap` |
| 消费 | `δ_t = δ0 · F_t^(−e) · (1+noise)` | `e` 价格弹性 |
| 供应 | `σ_t = σ0`（v1 外生，产能） | — |
| 出口 | `export_t = exportRate · max(0, S_t − mult·S_eq)` | `exportRate` |
| 递推 | `S_{t+1} = S_t + σ_t − δ_t − export_t`（硬边界记账） | 库存上下界 |

价格律取**乘法式** `(S_eq/S)^k_d` 而非线性 `1 + k_d(S_eq/S − 1)`：后者在 `S` 偏离时迅速穿过 0（负价），乘法式天然有界且关于 `S=S_eq` 对称。

尺度锚（可任意缩放，结论只依赖无量纲量）：`δ0=σ0=100 件/日`、`τ = S_eq/δ0 = 均衡库存天数`。

---

## 2. 解析结论（仿真验证）

在均衡点 `(S_eq, F=1)` 线性化，雅可比

```
J = [[ 1,            e·δ0      ],
     [ −α·k_d/S_eq,  1−α−rev   ]]
```

令无量纲**环路增益**

```
G = e · k_d · δ0 / S_eq = e · k_d / τ
```

则 `trace = 2−α−rev`，`det = (1−α−rev) + α·G`：

| 条件 | 结论 |
|---|---|
| `G` 小（`det<1` 且判别式>0） | 实特征值 ⇒ **单调收敛** |
| `G > (α+rev)/4` | 复特征值 ⇒ **阻尼振荡**（振幅按 `√det` 衰减） |
| 非线性 + 边界饱和（`G` 较大，实测 `G≳1.3`） | **持续振荡 / 极限环** |

**关键无量纲量是 `G`，不是 `k_d` 本身**：同样的 `k_d`，`τ` 越大越稳（库存缓冲越厚）。故调参口径统一为「先定 `τ`，再按目标 `G` 反推 `k_d`」。

需求阶跃下的新均衡（**解析可闭式**）：

```
δ(F)=σ0  &  F=(S_eq/S)^k_d   ⇒   S* = S_eq · (σ0/δ0)^(1/(e·k_d))
```

`δ0/σ0=1.3、e=k_d=1` ⇒ `S* = 0.769·S_eq` —— 与场景 7 实测 `anchor_dev = −0.2308` **精确吻合**。

## 3. 判定标准（照抄 §9.1）

① 迭代收敛到有界区间；② 无符号反复翻转；③ 库存始终在上下界内；
④ 买卖价不变量 `sell<buy` 恒成立；⑤ 存档往返幂等（**不在本仿真范围**，交实现期单测）。

## 4. 仿真结果

### 4.1 G 扫描（`α=0.15, τ=3, rev=0, 初值 S=1.2·S_eq`）——验证三区制

|---|---|---|---|---|---|---|---|
| 0.05 | 0.017 | 0.4 | 单调收敛 | 1 | 0 | 134 | 0.8% |
| 0.1125 | 0.0375 | 1.0 | 单调收敛 | 1 | 0 | 54 | 1.6% |
| 0.30 | 0.10 | 2.7 | 阻尼振荡 | 11 | 0 | 19 | 3.4% |
| 0.60 | 0.20 | 5.3 | 阻尼振荡 | 18 | 0 | 26 | 5.7% |
| **1.00** | **0.333** | 8.9 | **阻尼振荡** | **27** | **0** | **23** | **8.0%** |
| 1.50 | 0.50 | 13.3 | 阻尼振荡 | 33 | 0 | 25 | 10.3% |
| 2.00 | 0.667 | 17.8 | 阻尼振荡 | 39 | 0 | 26 | 12.1% |
| 3.00 | 1.00 | 26.7 | 阻尼振荡 | 50 | 0 | 25 | 15.0% |
| 4.00 | 1.333 | 35.6 | ⚠ **持续振荡** | 274 | 62 | 27 | 16.9% |
| 6.00 | 2.00 | 53.3 | 阻尼振荡 | 75 | 0 | 32 | 18.6% |
| 9.00 | 3.00 | 80.0 | ⚠ **持续振荡** | 379 | 83 | 42 | 20.0% |

**读法**：`G ≲ (α+rev)/4`（≈0.0375）为单调区；越过即进入阻尼振荡（瞬态振荡次数随 `G` 单调上升）；`G ≳ 1.3` 出现**持续振荡（极限环）**——正是 §9.1 担心的"持续振荡"风险，被复现并定位到 `G` 阈值。

### 4.2 α 敏感性（`G=0.333` 固定）

| `α` | 振荡阈值 `(α)/4` | 分型 | 瞬态振荡 | 超调 |
|---|---|---|---|---|
| 0.05 | 0.0125 | 阻尼振荡 | 46 | 5.4% |
| 0.10 | 0.025 | 阻尼振荡 | 32 | 7.0% |
| **0.15** | **0.0375** | 阻尼振荡 | 27 | 8.0% |
| 0.30 | 0.075 | 阻尼振荡 | 17 | 9.9% |
| 0.50 | 0.125 | 阻尼振荡 | 11 | 11.4% |

**读法**：`α` 越大瞬态越平缓（振荡少）但**超调越大**；`α=0.15` 是「振荡次数 / 超调」的折中点。`α` 属游戏内长时观测量（参数 6），此为离线可行区间。

### 4.3 冲击鲁棒性（蒙特卡洛，推荐参数，60 次，每 600 天一次 ±5%~40% 脉冲）

| 指标 | 值 |
|---|---|
| 有界率 | **100%** |
| 最大后段振荡 | 25 |
| **最大超调** | **7.94%** |
| 最大后段振幅 | 2.89% |

⇒ 推荐参数下**反复冲击不越界、价格峰值 < 8%**，满足 §9.1「迭代收敛到有界区间」。

### 4.4 shockCap 敏感性（参数 9，+300% 灾难冲击）

| `shockCap` | 单次冲击后 F 峰值 | 瞬态振荡 | 安定(天) |
|---|---|---|---|
| 0.005 | 1.059 | 31 | 37 |
| 0.01 | 1.072 | 32 | 25 |
| **0.02** | **1.079** | 32 | **23** |
| 0.05 | 1.080 | 33 | 113 |
| 0.10 | 1.100 | 33 | 124 |
| 0.25 | 1.250 | 34 | 131 |
| 0.50 | 1.500 | 35 | 141 |

**读法**：`shockCap` **线性地**限定单次冲击的价格峰值、**亚线性地**缩短安定时间。取 **0.02** ⇒ 灾难冲击下峰值 ≤ 8%、23 天复位。（0.005 虽更小，但复位反而更慢，边际收益递减。）

### 4.5 S0 归一口径（参数 15）

两派系：A小 `δ0=30`、B大 `δ0=300`；构造「A 超储 1×、B 恰好」。

| 基线口径 | 全球偏离 |
|---|---|
| 平铺基线（`Sb` 常数=3000） | **+50.0%** |
| 需求比例基线（`Sb = τ·δ0`） | +9.1% |
| 需求比例基线 + 需求份额加权 | +9.1% |

**结论**：基线**必须 ∝ 该派系需求**（`Sb = τ·δ0`），否则平铺基线会把小派系的库存偏离按体量错配，令全球因子被单一派系牵引。当 `Sb ∝ δ0` 时，总量法与需求加权法**一致**（+9.1%），故**取总量法即可，无需额外加权**——这简化了实现。

### 4.6 守恒校验（参数 14）

| 场景 | 相对残差 | 容差 1e-6 |
|---|---|---|
| 无界·无出口 | 7.6e-16 | ✅ |
| 软出口 | 7.6e-16 | ✅ |
| 硬上界 + 溢出排水 | 1.6e-13 | ✅ |
| 硬下界 + 应急进口 | 3.8e-16 | ✅ |

⇒ 记账式守恒在四类边界下均成立，**容差 1e-6 充分**（实测残差低 7 个数量级）。

### 4.7 需求阶跃 +30%（`δ0: 100→130`，含/不含回归项）

| `rev` | F 终值 | 库存锚定偏离 | 瞬态振荡 |
|---|---|---|---|
| 0 | **1.300** | **−23.1%** | 31 |
| 0.02 | 1.300 | −25.4% | 28 |

**两条重要结论**：
1. **供应外生时，需求阶跃会永久移动价格均衡**：`F* = (δ0/σ0)^(1/e) = 1.3`，库存锚定在 `0.769·S_eq`（与 §2 闭式解吻合）。这是**市场语义正确行为**，不是缺陷——需求上升 ⇒ 价格上升、库存降至新均衡。
2. **回归项 `rev` 不但无助锚定，反而恶化**（−25.4% vs −23.1%）：因为把 `F` 拉向 1 会**抬高消费**（`δ=δ0·F^{−e}`），进一步抽干库存。⇒ **`rev` 建议取 0**；库存锚定由 `F*=(S_eq/S)^k_d` 自身提供，冲击衰减由阻尼 + `shockCap` 承担。（参数 8 若仍要保留，须游戏内长时观测确认其收益。）

## 5. 推荐参数集（v1 初值，标注来源）

| 参数 | 推荐值 | 来源 | 说明 |
|---|---|---|---|
| `e` 价格弹性 | **1.0** | 离线 | 单位弹性，Cobweb 基准；`G` 随之定标 |
| `k_d` 需求系数 | **1.0** | 离线 | 配 `τ=3` ⇒ `G=0.333` |
| `τ` 均衡库存天数 | **3.0** | 离线 + 游戏内 | `S_eq=τ·δ0`；越大越稳，上限受"库存像作弊"约束 |
| `α` 平滑 | **0.15** | 离线区间，游戏内定稿 | 振荡/超调折中（区间 0.05–0.5） |
| `rev` 回归 | **0.0** | 离线 | 见 §4.7，负收益 |
| `shockCap` | **0.02** | 离线 | 灾难冲击峰值 ≤8% |
| `[Fmin,Fmax]` | **[0.5, 2.5]** | 离线 | §4.1 全部场景未越界；负价不可能 |
| 库存上下界 | **[0, 4·S_eq]** | 离线 | 溢出排水/应急进口均记账守恒 |
| `exportRate` / `mult` | **0.02 / 2.0** | 离线 | 软出口 sink，防单调累积 |
| 守恒容差 | **1e-6** | 离线 | 实测残差低 7 个数量级 |
| S0 归一口径 | **`Sb = τ·δ0`，总量法** | 离线 | 见 §4.5，无需额外加权 |
| 环路增益 `G` | **0.333**（目标 ≤0.5） | 离线 | 唯一需要盯的无量纲量 |

> ⚠ 这些是**离线可行值**，不是"最优"；参数 6–8、13、16 仍须游戏内长时观测（§7）。落地时把它们集中到一处配置（`WorldComponent` 外部参数 / DefModExtension baseline），便于观测期调参。

## 9. 残余风险

1. **模型是 1 商品 × 聚合派系的单闭环**，未含多商品耦合（`CommodityDef.weight` 聚合）与多派系同时冲击的叠加——多商品耦合的稳定性须在实现期为次跑一遍或做离线扩展。
2. **价格律是设计选择**（乘法式 `(S_eq/S)^k_d`）；若实现改用线性式，`G` 结论需重算（线性式有负价风险，**不推荐**）。
3. `τ` 的取值直接决定"库存是否像作弊"与稳定性，属**玩法权衡**，非纯数值问题——须用户拍板 `τ` 的期望量级（3 天？7 天？）。
4. 本仿真**不覆盖**存档往返幂等（§9.1 判定⑤），归实现期单测。
