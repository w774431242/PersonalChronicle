# EXC-2026-014 · RUIF 硬依赖（工程级 UI 框架前置）

- **Change ID**：`CHG-SHOP-AUDIT-001`（2026-10-02 全面审计）追溯登记
- **等级**：E2（受控例外，可回滚、影响面明确）
- **触发规则**：COMP-001（目标 Mod 缺失时正常运行）/ COMP-004
- **状态**：Approved（依据既有 ADR-AMD-1 / ADR-AMD-2 的用户硬指令，本条为其提供审计链编号）

## 例外内容

本 Mod 对 **RUIF（`PersonalChronicle.RUIFramework`）构成硬依赖**：

- `About/About.xml:10-27`：RUIF 声明于 `modDependencies` + `loadAfter`；
- `Archive/UI/RuifBridge.cs:12-15`：源码自陈"缺 RUIF 时编译期即失败，不提供降级路径"；
- 消费面：`Archive/UI/` 与各业务面板（含车间管理 `WorkshopManageView.cs:949` 的 `RuifBridge.StatRowHeight()`）。

## 为什么豁免

1. **这是用户的显式架构决定**（工程铁律「组件方向内容必须引用 RUIF，禁止自研组件」，
   `Source/PersonalChronicle.csproj:34-38`），并有 ADR-AMD-1 / ADR-AMD-2（Status: Accepted）背书。
2. RUIF 是**同作者发布的伴生 Mod**（非任意第三方），版本演进可控。
3. 车间管理侧的**实际降级是完整的**：`RuifBridge.StatRowHeight()` 不可用时回落
   `FallbackRowHeight = 18f`（`RuifBridge.cs:506-517,530`），UI 仍可用 —— 豁免的是"Mod 缺失"，
   不是"运行时 API 缺失"。

## 范围与约束

- **不豁免**任何对其它第三方 Mod 的直连；新增第三方依赖必须另立 EXC。
- RUIF API 消费必须走 `RuifBridge` 单点（禁止业务文件直接 `using RUIF` 散落）。
- 版本过低告警已有节流（`RuifBridge.cs:711-720`，10 分钟一次）。

## 回滚

移除 RUIF 依赖 = 移除 `About.xml` 声明 + 以 `UIComponents` 回退全部 RUIF 调用点 —— 属架构级回退，
不在本例外范围内。

## 复审触发

- RUIF 发生破坏性 API 变更（本 Mod 编译失败）时；
- 用户决定解除硬依赖（转向可选依赖 + 能力探测）时。
