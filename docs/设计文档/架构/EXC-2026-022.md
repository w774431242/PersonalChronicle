# EXC-2026-022 · 在原版时段选择器追加「吃饭」按钮（管制/作息表）

- **状态:** Approved
- **提出:** 2026-10-04（用户反馈「管制作息表没有吃饭管制类型」）
- **关联变更:** CHG-20261004-MEALSCHEDULE-B
- **风险等级:** **E1 中**（纯 UI 追加，不改原版数据结构；失败可回滚）
- **触发 Architecture Review:** 是（Harmony = Yes）

## 背景

玩家口径（2026-10-04）：底部【管制】标签（原版 `MainButtonDef Schedule` → `MainTabWindow_Schedule`，
表格 `PawnTableDefOf.Restrict`）的作息表里**没有吃饭管制类型**，希望能把某几小时划成「吃饭」。

静态取证（Build 1.6.4871，Cecil）确认了三件事：

1. 时段数据模型**可扩展**：`Pawn_TimetableTracker.times : List<TimeAssignmentDef>`，
   `RimWorld.TimeAssignmentDef : Verse.Def`（字段仅 `color` / `allowRest` / `allowJoy`）。
   ⇒ 新增 `PC_Meal` Def 后，**格子涂色、存读档、点击涂格全部自动生效**，原版无任何 defName 硬编码。
2. **按钮网格是硬编码的**：`TimeAssignmentSelector.DrawTimeAssignmentSelectorGrid` 的 IL 逐条确认它只画
   `TimeAssignmentDefOf.Anything / Work / Joy / Sleep [+ Meditate（Royalty 激活）]`，
   **不遍历 `DefDatabase<TimeAssignmentDef>`** ⇒ 光加 Def 不出现按钮。
3. 原版**没有留任何 XML 扩展点**：无 TimetableDef 列表、无 DefModExtension、无 `MainButtonDef` 侧的
   可注入字段（`Work` 侧至少有 `PawnColumnDefGenerator` 这种隐式生成机制，Schedule 侧完全没有）。

## 授权范围（A）

允许两处 Harmony 补丁，均为**只读/追加**语义，不改原版数据结构：

| 补丁 | 目标方法 | 语义 |
|---|---|---|
| `Patch_TimeAssignmentSelector` | `TimeAssignmentSelector.DrawTimeAssignmentSelectorGrid`（**Postfix**） | 按原版布局算法（IL 复刻）追加第 N+1 个「用餐」按钮；点击只写 public static 的 `selectedAssignment`，其余交还原版 |
| `Patch_PawnColumnWorker_Timetable` | `Pawn_TimetableTracker.SetAssignment`（**Postfix**） | 玩家把某小时涂成「用餐」时唤醒一次本图重算（否则逐人 timetable 变化要等下一个餐段） |

## 硬约束

1. **Postfix only**：禁止 Prefix 阻断或重画原版 5 个按钮（必须完整保留其
   `UIHighlighter` 教学高亮、选中框、音效与 Royalty 条件）。
2. **布局必须复刻而非臆造**：`MealButtonRect` 的坐标算法逐行对照
   `DrawTimeAssignmentSelectorGrid` IL（`yMax -= 2` → 取左上四分之一 → 每个按钮后 `x += width`）。
3. **Def 缺失即降级**：`PC_Meal` 解析失败时按钮不画 + 一次性 `Log.Warning`，
   **不得抛异常打断 UI 绘制**（COMP-011）。
4. **不得触碰 `selectedAssignment` 的其余逻辑**：不新增 static 状态、不缓存 pawn 引用。
5. 私有字段读取（`Pawn_TimetableTracker.pawn`）必须用**一次性缓存的 `FieldInfo`**，
   取不到即静默跳过（功能退化为下一餐段生效），不做每帧反射。

## 禁止范围（F）

- ❌ 禁止 `Prefix` 改写 `DrawTimeAssignmentSelectorGrid` 的行为或吞掉原版按钮。
- ❌ 禁止给原版 `TimeAssignmentDef`（Anything/Work/Joy/Sleep/Meditate）改颜色或 `allowRest/allowJoy`。
- ❌ 禁止在 `Pawn_TimetableTracker` 之外新增第二套时段写入路径（写入口唯一性，GOV-005）。
- ❌ 禁止用本 EXC 为其他 UI 追加需求背书。

## 回滚

删除两个 Patch 类 + `Defs/Automation_TimeAssignment.xml` 即可完全回滚：
无存档字段依赖（`PC_Meal` 只在玩家主动涂格后才出现在 `times` 里，
回滚后残留的 `PC_Meal` 引用会因 Def 缺失而退化为「无效时段」，不崩溃）。

## 验证

- 编译 0 错 0 警。
- 静态取证：按钮网格硬编码、布局算法、点击链路（`selectedAssignment` → `DoTimeAssignment`）。
- **实机未验证**（沙箱无法起游戏进程）：需玩家确认按钮出现、点击可涂格、存读档保持。
