## 1. 实现

## 2. 契约与口径

- **RUIF 依赖**：`About/About.xml` 已声明 `PersonalChronicle.RUIFramework` 为硬依赖（编译期引用 `RUIF.dll`）⇒ 可直接调用 RUIF API，无需软探测（GATE-COMP 的"硬依赖"路径）。
- **配色**：窗口取本 Mod 的 `UITheme`（与工程其它界面同处可切换主题之下）；按钮语义色由 RUIF `ButtonAtoms` 提供。**"基于 RUIF"落在组件与度量上**，配色不旁落。
- **LAND-009（内容不编造）**：正文只写**已落地**的玩法事实 —— 主按钮入口 / 划区建车间（`Designator_ZoneAdd_Workshop`）/ 工单配料与原料轨道（含"不足一单标红"）/ 编排画布与存档 / 档案与职业方向（`Dialog_SetPrimaryDirection`）/ 经济 / 主题与「—」的含义；"预留 · 未接入"中心如实说明只登记清单。**不承诺未实现的功能**。
- **截断补偿**：正文行截断走 `UIComponents.TruncateToWidth(text, w, font, rect)`（4 参 = 截断即自动挂原文悬停，LAND-008）。

## 4. 待实机验收

1. 总控中心页头出现「新手教程」按钮；悬停有提示；点击弹出教程窗口。
2. 宽/窄窗口下：按钮**不与主题/返回重叠**（窄到放不下时整件消失而不是叠字）。
3. 教程窗口：标题条「新手教程 · 从哪开始」、7 节齐全、内容可滚动到最后一节、底栏「知道了」可关闭；X 可关闭；点窗外**不**关闭。
4. 语言切换（中/英）后重新打开：文案随语言切换（`UIComponents.Loc` 按语言缓存）。
5. 小分辨率（如 1280×720）：窗口不溢出屏幕；正文行不被硬切（截断处悬停可见全文）。
