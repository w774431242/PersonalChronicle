# 变更标注 · CHG-20261006-T1FLAT

## 背景

PM 2026-10-06：「T1 设备不要集中一个按钮，全部展开」。

原实装（`docs` 两稿的设计决策）把 10 台 T1 智能生产设备用 1.6 原生
`DesignatorDropdownGroupDef`（`PC_T1Production`）合并为建造菜单单一入口
——理由是「10 个平铺项会污染建造菜单」。本次为**该决策的反转**：取消合并，
10 台设备在「自动化」（`PC_Automation`）分类各自独立成建造按钮。

## 一、Def 结构（`Defs/T1_Production.xml`）

| 项 | 处置 |
|---|---|
| `<DesignatorDropdownGroupDef>PC_T1Production</DesignatorDropdownGroupDef>` | **删除**（含原 4 行块）；原位改为决策留痕注释（L4-6） |
| 10 台 ThingDef 的 `<designatorDropdown>PC_T1Production</designatorDropdown>` | **逐台删除**（10 处） |
| `designationCategory` / `uiOrder`(3100-3109) / 数值 / 配方 / modExtensions | **一律不动** ⇒ 平铺顺序 = 原 uiOrder 顺序 |

静态验证：`SelectNodes('//ThingDef/designatorDropdown')` = **0**；
`/Defs/DesignatorDropdownGroupDef` = **0**；`ThingDef` 仍 = **10**。

## 二、本地化（LOC）

- **删除** `Languages/English/DefInjected/DesignatorDropdownGroupDef/T1_Production.xml`
  （唯一键 `PC_T1Production.label`）—— 组 Def 不存在后该键即**孤儿键**，必须同批删除
  （先例：`CHG-20261002-ORPHANKEYS` 孤儿键清理纪律）。
- 该目录删后为空，已清理；中文侧本无此键（`Defs/Automation_Category.xml` 只保留
  `PC_AutoFarm` 组，本次**未动**）。
- **按钮名回归面已预先核实**：展开后每个按钮名取各设备 `def.label`；
  英文 `Languages/English/DefInjected/ThingDef/T1_Production.xml` 对
  10 台 **label 100% 覆盖**（`smart smelter (T1)` 等），不会回落中文；中文 label 在 Def 内直写。
