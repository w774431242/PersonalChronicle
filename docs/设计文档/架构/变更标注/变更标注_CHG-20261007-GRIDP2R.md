## 2. 关键设计裁决（带理由）

1. **为什么必须有 Prefix**：判据是「刚发生显著跌落」，而 Postfix 只有后值 ⇒ 照字面实施算不出判据（本工程第三次遇到「无可计算输入」型缺陷）。Prefix 快照是唯一能取到前值的时点。
2. **为什么用「绝对门 + 相对门」双条件**：只看绝对值 ⇒ 边角小电池被正常用掉也会越门；只看比例 ⇒ 储能极小的网任何波动都是 100%。与速断判据同构。
3. **为什么 overlay 用程序化材质而非贴图**：`SDD` 4.7 已裁决断路器不做 `_Off` 变体；再引入贴图会多一条「缺图 ⇒ BadMat 洋红」失败路径。且 `SimpleSolidColorMaterial` 走不透明 shader（已 IL 实证）⇒ 必须自建 `Transparent` 材质。
4. **为什么不扫 `net.powerComps` 找断路器**：2026-10-07 实机两次证伪（我们的输电体在 `powerComps` 与 `transmitters` 里都捞不到）⇒ 一律走自注册表 `knownBreakers`。
