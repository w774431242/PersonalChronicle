# 变更标注 · CHG-20261007-GRIDP3

## 1. 目标

实装 `SDD-2026-10-06-电网系统.md` v0.5 的 **P3「调度与接管」核心链路**。

## 2. 关键设计裁决

1. **挂点选 `PowerNetsTick` 而非 `PowerNetTick`**：后者每 net 每 tick 调用（10 张网 = 每 tick 10 次组件查找）；`PowerNetsTick` 是纯转发循环（IL 实证）⇒ 接管不丢行为，且安全阀判据本就是 map 级、锁存可与接管粒度一致。代价（第三方挂在 PowerNetTick 上的补丁不执行）靠让位出口② 缓解。
2. **Plan / Apply 分离**：`SDD` §5.3「先算后置位」的落地形态 —— 算的阶段零世界副作用，避免「半个 tick 的世界」。
3. **`ChangeStoredEnergy` 用启动期委托绑定**：它是 `private`（Cecil 实证）；绑定失败 ⇒ **整体让位**（电池冻结比不接管糟得多）。
4. **Critical 档默认不自动切**：只剩 Critical 时切一台通常补不上缺口却造成不可逆伤害（生长舱断电即终止培养）⇒ 显式开关 + 默认关 + 内建反向对照用例锁死。
5. **XML 注释禁连续双短横**：首版注释里的连续短横会让**整份 Def 解析失败**（已本地复现并修复）。

| 2 | UI 四页未实装 | 调度页无入口，P3 观测面缺失 |
