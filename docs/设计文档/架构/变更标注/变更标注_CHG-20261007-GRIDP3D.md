# 变更标注 · CHG-20261007-GRIDP3D

## 1. 目的

为 `SDD` §6.2 的**页集**（分区总览 / 分区详情 / 计量 / 保护 / 调度）**腾出纵向空间**：
把电力中心页从「整页适配一屏、**无页面级滚动**」改为**可滚动纵向分区**。

## 2. 为什么必须改这一条

原实现刻意不套外层滚动：

```
// 整页适配一屏、无页面级滚动 ⇒ 与 app shell / 经济页同规**不套外层滚动视图**
// （表体的固定视口与溢出提示由 `DrawPowerGridTable` 自管）。
```

在「一屏」前提下这是对的；但要追加四个内容分区**必然溢出**，且溢出部分**无法到达**
（表体只在自己内部做固定视口降级，页面级没有滚动条）。

⇒ 改为 `BeginContentScroll` + **计高方法**。`LAND-002` 要求**计高 ≡ 绘制**：
新增 `ComputePowerGridHeight` / `PowerGridTableHeight` 与绘制消费同一组符号
（`KpiBlockHeight` / `SectionTitleHeight` / `HeaderHeight` / `RUIF.Measure.RowHeight` / `PowerGridMaxRows`），
否则会出现「滚到底还有内容」或「底部一大片空白」。

## 3. 顺带修正的一处行为

`DrawPowerGridTable` 原先按**视口高度**算能显示几行（`(rect.yMax - y) / rowHeight`）。
页面可滚动后视口不再是约束 ⇒ 改为上限 `PowerGridMaxRows`（12 行），
保留 `GATE-UI`「大列表须有上限」的要求，且与计高同源。

## 4. 形态裁决记录

`SDD` §6.2 写的是「五页」。本次采用**单页纵向分区**（而非页签），理由：
① 与现有「KPI → 分区表」的连续版式一致；② 不需要新的页签机制；
③ 五节内容都短，纵向分区无切换成本。

⚠ **本条属对 `SDD` 措辞的实现选择，需在 SDD 内补一句说明**（未闭环项）。
