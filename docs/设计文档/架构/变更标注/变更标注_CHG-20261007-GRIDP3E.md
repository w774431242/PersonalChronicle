# 变更标注 · CHG-20261007-GRIDP3E

## 1. 目标

实装 `SDD` §6.2 页集中的**保护分区**（批①-b）。

## 2. 一处必须先说清的粒度事实

`SDD` §6.2 的「保护」页要求**逐分段设备**（额定 / 定值 / 上次动作原因），
而既有 Read Model 的行粒度是**分区**（`GridPartitionRow`，只有聚合的 `TrippedCount`）。

⇒ 二者**粒度不同**，不能靠给分区行加字段实现 ⇒ 新增**第二套行集** `GridBreakerRow`
与第二条注入通道（与 `rowsSource` 同型：`Application` 定契约、`Automation` 启动期注入）。

## 3. 数据链路（四段，逐段可查）

```
MapComponent_PowerGridSim.knownBreakers
  → CollectBreakerRows(buffer)                     [Automation 侧填充]
  → GridSimAccess.CollectBreakers(map, buffer)     [Application 侧受控钩子，降级不抛]
  → SystemCenterDetailSnapshot.PowerGridBreakers    [读模型缓冲，派生态不入档]
  → DrawPowerGridProtectionSection                  [UI 只读快照]
```

## 4. 复用而非重写

`TripReasonKey`（枚举 → Keyed）由 `CompPowerCircuitBreaker` 的 `private static` 改 `internal static`，
Read Model 直接复用**同一份**映射 —— 避免 UI 侧出现第二份实现，日后加跳闸原因时必然漂移。
