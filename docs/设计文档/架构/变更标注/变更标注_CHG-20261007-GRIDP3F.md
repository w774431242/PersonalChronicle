# 变更标注 · CHG-20261007-GRIDP3F

## 1. 目标

实装 `SDD` / `EXC-2026-027` A.6 要求的**次回滚路径**：一个玩家可见的「电网甩负荷接管」总开关。

此前只有**主回滚**（删 `Patch_PowerNetTick.cs`）—— 那要改工程文件，玩家做不到。
A.6 因此声明了一条玩家可用的开关路径，本轮补齐。

## 2. 开关语义（写在语言键里，避免玩家误解）

| 项 | 语义 |
|---|---|
| 默认 | **开** |
| 关闭后 | 甩负荷**完全走原版**（每 20 tick 随机关 5%）；**保护与计量不受影响** |
| 与让位的关系 | 探测到 Power Priority / Power Controller 时**自动让位**，无需手动关 |

⇒ 判据链顺序（`Patch_PowerNetTick.Prefix`）：`sim == null` → 存能面绑定 → **玩家开关** → 第三方让位 → 零配置 → 锁存。

## 3. 一处过程中的自我纠正（记录以免复犯）

首版引用写成了 `ChronicleMod.Settings` —— 该类名**不存在**：文件是 `ChronicleMod.cs`，但类名是
**`PersonalChronicleMod`**（编译报 `CS0103`/`CS0234` 才发现）。已改用正确类名并编译通过。
