# 变更标注 · CHG-20261007-GRIDP3G

## 1. 目标

补 `SDD` §7.1.2 要求的「探测命中 ⇒ 让位 **+ UI 明示**」中的 UI 部分。
此前只有日志明示（可 grep），玩家在界面里看不到"本 Mod 的调度已停用"。

## 2. 依赖边怎么绕开

`SDD` §3.2 的依赖图**没有** `UI → Compatibility` 这条边 ⇒ UI 不能直读兼容层。

⇒ 复用工程既有的**受控静态钩子**范式（同 §3.5 `GridSimAccess`）：
`Application` 定义只读能力位，`Compatibility` 在启动期注入（`Compatibility → Application` 是**允许方向**）。
UI 读的是 `Application` 的属性 ⇒ 全部消费方留声明的依赖图内。

## 3. 放在空态判定之前（有意）

让位是**全局事实**（第三方 Mod 占了挂点），与"本图有没有分区"无关。
若放在 `Ready` 之后，则"尚无分区"的玩家看不到它，会误以为调度正在生效 —— 正是要防的误解。

| 2 | 批③ 计量/调度历史（需先起草历史采样设计） |
| 3 | 批④ 分区详情单线图 |

「不让位 / 无名」，行为与加此功能前一致。
