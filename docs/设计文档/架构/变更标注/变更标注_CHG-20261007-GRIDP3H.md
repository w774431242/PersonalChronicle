# 变更标注 · CHG-20261007-GRIDP3H

## 1. 本批是什么

批③ 的第一步：**历史采样通道的设计草案**（纯文档，无代码）。

`SDD` §6.2 的「计量」页要**分区 W/Wd 曲线与需量峰值**、「调度」页要**甩负荷历史**，
而父 SDD 全文**从未定义**产生与保存它们的通道 —— 与本工程已三次修过的同型缺陷一致
（规格写了需要数据支撑的界面，但没定义那份数据从哪来）。

⇒ 本批把该缺口正式定义：环形缓冲、采样周期/容量、是否入档、降级行为、契约与实装清单、
以及**五条可证伪验收判据**（每条都写明了反例）。

## 2. 顺带闭环的一个入场条件

草案原把「RUIF 是否提供曲线能力」列为**入场条件**。本批已实测核实：**存在** ——
工程自述「环形与面积等图表一律经 `RuifBridge` 走 RUIF（`RUIF.Charts.*`）；本工程不再自绘图表」，
另有 `RUIF.Charts.PlotRectOf` 与 `RUIF.TableFmt.BandColor` 的既有用例。
⇒ 计量分区可直接实装，且不构成「自研组件」违规。已回写进文档 §4 与 §7。
