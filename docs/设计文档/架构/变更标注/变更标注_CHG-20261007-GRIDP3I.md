# 变更标注 · CHG-20261007-GRIDP3I

## 1. 本批是什么

批③（历史采样通道）的 **Domain 层落地**，按 PM 批准的建议值：
**周期 250 tick · 容量 240 点（≈1 天）· 不入档 · 每分区一份**。

设计依据：`docs/设计文档/功能模块/自动化体系规范/03-电网系统/SDD-2026-10-07-增补-历史采样通道.md`
（同批已落地并闭环了其中的 RUIF 曲线能力入场条件）。

## 2. 三条被判据钉死的语义（都有对应用例）

| 语义 | 为什么必须钉死 | 用例 |
|---|---|---|
| **空缓冲不得返回"零值当数据"** | `TryGetAt` 返回 false 而非零值；`TryGetPeakDemand` 无数据时返回 false —— 否则 UI 会把 0 当真峰值画出来 | `Empty_ReportsNoData_...` |
| **全盈余时峰值 = 0 但「有数据」** | 健康电网上显示「历史数据不足」是错的 —— 这是反向对照 | `PeakDemand_AllSurplus_IsZeroButStillHasData` |
| **峰值只算当前窗口** | 若已覆盖的点仍参与峰值，峰值**永不衰减**，与曲线口径矛盾 | `PeakDemand_OnlyConsidersCurrentWindow` |

另：容量 ≤ 0 **抛异常**（不静默 clamp）—— 静默会让"容量为 0"表现为"永远没有历史数据"，
而那极易被误判为"采样没工作"。
