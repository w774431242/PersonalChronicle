# 变更标注 · CHG-20261007-GRIDP3J

## 1. 本批是什么

把上一批落地的 `GridMeterRing`（Domain）**接上消费方**，使其不再是死代码。

| 项 | 值 | 依据 |
|---|---|---|
| 采样周期 | **250 tick** | PM 批准值（增补 SDD §5-A） |
| 相位 | `+15` | 与 A/C 通道错开（避免同拍做两件事） |
| 粒度 | 每分区一份 `GridMeterRing` | PM 批准值（§5-D） |
| 数据来源 | `GridPartition.NetWatts` / `StoredWattDays` | **UI 同源** —— 不新增第二套换算（验收判据 4：曲线末点必须等于面板当前值） |

## 2. 开销（对照 `PERF` 判据 1/2）

- **每 tick 成本** = 一次取模比较（`now % 250`）—— 无扫描、无分配；
- **每 250 tick** = 每分区一次 `Add`（写入定长数组，零分配）；
- 内存 = 分区数 × 240 × 12 B ≈ **2.8 KB / 分区**（有界，不随时间增长）。

## 3. 一处需知的可见性放宽

`MapComponent_PowerGridSim.partitions` 由 `private` 改 **`internal`** —— `GridTickDriver` 是同类协作方
（它已在用 `sim` 的其它内部成员），而分区列表无法通过参数传入（采样要遍历全部）。
⇒ 放宽范围最小（程序集内），未对外暴露。

## 4. 未闭环

| # | 项 |
|---|---|
| 1 | `GridSimAccess` 只读查询口（供 Read Model 取曲线点） |
| 2 | Read Model 缓冲 + 计量分区的曲线 UI（`RUIF.Charts`，经 `RuifBridge`） |
| 3 | 甩负荷历史的**入档**（§5 决策 C，属事件档案，需独立 Scribe 字段与 Migration 评估） |
| 4 | 实机：目前**看不到任何变化**（采样是纯后台行为） |

## 5. 回滚

三文件；回滚即删 `Meter` 字段、`RunMeterChannel` 与调用点（`partitions` 可见性可保留）。
零存档影响（Meter 是派生态）。
