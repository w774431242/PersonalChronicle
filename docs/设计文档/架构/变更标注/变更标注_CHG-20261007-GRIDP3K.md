# 变更标注 · CHG-20261007-GRIDP3K

## 1. 本批是什么

把前两批的采样基础设施**兑现成玩家可见的信息** —— 电力页新增「**计量摘要**」分区：
每个分区一行，显示 **采样点数** 与 **需量峰值**。

## 2. 一个关键简化（省掉整条注入通道）

原设计（增补 SDD §4）计划给 `GridSimAccess` 加一条新的 `CollectMeterSamples` 注入通道。
实装时发现：**`CollectRows` 本来就在遍历分区**，而计量数据挂在 `GridPartition.Meter` 上
⇒ 直接在同一个循环里填两个字段即可，**不需要第二条通道**。

⇒ 少了一条契约、一个 binder 方法与一次快照缓冲分配。

## 3. 数值口径（避免"看起来在工作"）

| 项 | 语义 |
|---|---|
| 点数 ≤ 0 | 显示「暂无历史数据」——**不画 0**（`LAND-009`） |
| 峰值 NaN | 显示「-」；UI 用 `float.IsNaN` 判定，而非 `== 0`（全盈余时峰值**就是** 0，那是真实答案） |
| 点数 ≥ 2 | 才够画曲线（本批只显示数字，曲线留待用 `RUIF.Charts`） |

## 4. 顺带清理

`ComputePowerGridHeight` 里保护分区高度**被重复累加了三次**（上一批插入时的残留）⇒ 本批重写为分区累加式，
并把三处重复的行高计算收敛为 `PowerGridRowHeight()`（`LAND-002`：计高与绘制同源）。

## 5. 未闭环

| # | 项 |
|---|---|
| 1 | 曲线本身（`RUIF.Charts`，经 `RuifBridge`）—— 本批只出数字摘要 |
| 2 | 甩负荷历史**入档**（决策 C，事件档案性质） |
| 3 | 批④ 分区详情单线图 / 批⑥ 真分段 |
| 4 | 实机核对（需等 ≥2 采样周期） |

## 6. 回滚

五文件；删除 2 个字段 + 填充 + 计量分区与 4 键即可。零存档影响（全部派生态）。
