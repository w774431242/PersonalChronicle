# 变更标注 · CHG-20261007-GRIDP3M

## 1. 本批是什么

**曲线本体** —— 计量链路的最后一步：把 `GridMeterRing` 的点画成折线。

至此计量链路闭环：`GridPartition.Meter`（采样）→ `CopyValuesTo`（导出）→ Read Model → UI 折线。

## 2. 两个必须说清的技术决定

### 2.1 尾部填充（防"假崩落"）

`RUIF.Charts.LineChart` 收**整个** `float[]`，没有"只画前 N 个"的参数。
若把未使用的尾部留作 0，曲线右端会**断崖式掉到 0** —— 看起来像"电网突然全黑"，而实际只是点不够。

⇒ `CollectRows` 里把尾部**填成最后一个有效值**（视觉上是平直线）：平直是诚实的中性表达，断崖是假信息。

### 2.2 容量 120 < 环窗口 240

240 个点挤进约 200 px 的 sparkline 密度超过任何屏幕能表达的程度 ⇒ 取最近 120 点（`CopyValuesTo` 的右端对齐语义正好保证"给的是最近的"）。

## 3. 结果

- `GridPartitionRow.Curve` 是**每行一份、构建期分配一次**的复用数组 ⇒ 绘制期**零分配**；
- `CurveCount < 2` 时不画（点不足以成线是**正常**早读档状态，不是故障）。
