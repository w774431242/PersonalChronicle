## 变更范围说明

本单元把「生活缺口 → 收入目标 → 真实岗位 → 合同 → 启用岗位所需工作类型 → 原版真实劳动 → 唯一应付 → 国库结算 → 柜台真实购买」接成一条可复核链路。全部写入都有显式闸门；无报价/无岗位/无资金时如实停在等待态，不以 MarketValue、固定餐数、赠币或要求玩家勾选工种代替证据。
