## 变更范围说明

本增量把「家庭与照护」从一句设计变成可复核代码：四个身份（受益者/监护人/执行者/付款方）各有独立契约；亲属关系本身不授权扣款；服务只有在**七门取证**齐全时才可报价与收费。首个真实的交付链是**治疗**：原版 `TendUtility.DoTend` 的只读上报（EXC-2026-029）作为交付证据，经授权上限闸门与账本内部转账完成一次结算，证据派生命令 id 保证重放不重复扣款。

**已更正**：上一轮把该回调的证据记在「体检」名下属归因错误；`DoTend` 是治疗过程。体检/床位/托育/教育四类**无原版交付过程**（`ChildcareUtility` 只有判定方法、`LearningUtility.LearningTickCheckEnd` 是高频检查而非交付事件），故 `DeliveryEvidence=false`，继续「取证中」且不报价。
