## 核心语义：**回退不得重获已消费额度**

`BeginDay()` 由无参改为 `BeginDay(int day)` —— 这是本批唯一的行为性变更，也是 §6 那句话的落点：

- 日序号**前进** ⇒ 清额度（真的跨日）
- 同日 / 日序号回退 / 负数（时间不可信）⇒ **返回 false 且不清**
- 载入走 `Restore` 而**非** `BeginDay` ⇒ **读档本身不等于新的一天**

少了这条，玩家反复读档即可无限刷学习额度 —— 而"有界"只限制了**单日上限**，挡不住这条路径。

**迁移动机**：`Tests/StyleLedgerTests.cs:44` 原为 `ledger.BeginDay()`，签名变更后必须给日序号；已改为 `BeginDay(1)` 并断言返回 true。**这是设计要求的签名收紧，非回归。**
