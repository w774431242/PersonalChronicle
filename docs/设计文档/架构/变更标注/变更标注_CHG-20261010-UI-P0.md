# P0-3 滚动保护（首批）

**ChangeID**：`CHG-20261010-UI-P0`｜**日期**：2026-10-10
**程序集**：`72A1EE4416E093AEABA16FF7234B3A244AD407D47EA1EE8EEE305BBD2BE1C172`（= 游戏目录）｜**部署**：已部署

## 问题

组件绘制规范铁律 3：**IMGUI 无自动裁剪，出栈动作必须放 `finally`** —— 异常一旦逃出 `DoWindowContents`，
`BeginScroll/EndScroll` 入栈出栈断裂，日志刷 `You are pushing more GUIClips than you are popping`
⇒ **整局 GUI 卡死（玩家无法行动）**。审计发现本域 **5 处** 无保护。

## 本批修复（3 处，覆盖 7 个绘制面）

| 位置 | 覆盖面 | 改法 |
|---|---|---|
| `Dialog_PawnEconomy.cs` `DrawRows` | **岗位/库存/账户/台账/报表（5 个页签共用）** | 整个绘制体包 `try`，`EndScroll` 移入 `finally`；空态分支的提前 `return` 不再自行出栈 |
| `Dialog_PawnEconomy.Overview.cs` `DrawOverview` | 概览页 | 同上 |
| `Window_PawnEconomyDiagnostics.cs` `DoWindowContents` | 诊断窗 | `Label` 包 `try`，`EndScrollView` 入 `finally` |

异常处理一律 `Log.ErrorOnce`（唯一键，不刷屏）。已对齐既有样板 `NeedsCyclePanel.cs:141-149`。
