# 前端设计审计报告（拥挤 / 失效 / 系统性 Bug）
> 2026-09-19 · 范围：经济中心 UI 层 + Archive/UI 组件层 + MasterControl 外壳层
> ⚠️ **方法**：静态代码审计（两个并行探查代理，逐条要求 `文件:行号` 证据）。
> **未实机验证** —— 本报告的全部结论均为**静态可判定**的问题；凡需实机才能确认的，已在条目中标注。
> ⚠️ **立场声明**：本线今日的 UI 改动由 AI 完成，故**先审自己**（§0），再列既有问题。

## 结论一句话

**不是"拥挤"这个层面的问题，是三类结构性问题**：
① **信息可达性缺口** —— 截断 43 处、只有 4 处配了悬停；
② **状态出口缺失** —— 多处"我们不知道"被呈现成"有数据"或干脆消失；
③ **隔离与失效链缺失** —— 外壳层零异常兜底 + RUIF 门控双标准。

拥挤确实存在，但它是**结果**（标题条 5 个元素挤 32px），不是**原因**。

## §0 🔴 自审：本日改动**新引入**的问题（6 条）

> 这一节优先于所有既有问题 —— 它们是**我今天刚写进去的**。

### 0.1 【P1】环形图/图例**档位色 off-by-one**，标准情形下 3 段同色
- **证据**：Provider 写 **0 基**（`BuiltinEconomyProvider.Society.cs:128` `TierIndex = i`），
  而 `TierTone` 按 **1 基**分档（`EconomySocietyPanel.cs:584-592`：`case 1` / `case 2` / `default`）。
- **后果**：实际映射 0→绿、1→紫、2→金、3→绿、4→绿。而 `FactionComposition.DefaultTopN = 4`
  且超限**必然**追加聚合行 ⇒ **标准就是 5 行** ⇒ 第 1/4/5 段同色，环形图上相邻扇区无法区分。
- ⚠ **更糟的是注释在说谎**：类注释声称"三档…最小欧氏距离由 0.13 提升到 0.29 —— **全主题可辨**"（`:581-582`）。
- **性质**：**我本轮把 3 行改成 5 行时没有回头验色** —— 典型"改了下游忘了上游前提"。

### 0.2 【P1】`HasBarShare=false` 时，**影响因子 + 据点 + 人数全部不可读**
- **证据**：`EconomySocietyPanel.cs:207-210` 只在 `HasBarShare` 时 Plan 条；而 `ScaleBarTip`
  的**唯一**消费点是 `:354`，且它同时是 `FactorsTip` 的唯一出口（`Society.cs:346-352`）。
- **后果**：契约未接线 / 全体据点数为 0 时，四条影响因子与规模明细**一并消失**，
  而段头仍无条件 Plan（`:195`）⇒ 正是我自己在 `:184-186` 写下的"有标题、无内容就是假空态"。
- **性质**：**我把多个信息塞进唯一一个 tooltip，却给它加了前置门禁** —— 门禁一关，全丢。

### 0.3 【P1】「供应库存」实为**玩家地图库存**，却挂在选中派系名下
- **证据**：`BuiltinEconomyProvider.MarketPanel.cs:315` `map.resourceCounter`（`map` 来自
  `SystemCenterReadModelProvider.cs:174` `Find.CurrentMap`）→ `:337-345` 累加 → `:356-361`
  作为**选中派系**的"市场特征"一条输出。
- **后果**：同一行里**两个主语** —— 筛选用选中派系的可见集，计数用玩家的库存。
  而我给它写的注释是"三条里**唯一不依赖任何假设**的读数"（`:298-299`）—— 读数是真的，**标签是错的**。
- **性质**：与"市场特征动态化"同一批引入；**这是"标签必须跟着值走"的第 5 次违反，且是我自己犯的**。

### 0.4 【P1】「人口规模」标题下可能显示**据点**（"N 处"）
- **证据**：降级分支 `Society.cs:183-188` 把 caption 换回 `PopulationValue`（"{0} 处"），
  而段标题键 `MVS.Economy.Society.Scale.Title` 实值 = **"人口规模"**。
- **后果**：标题说人口、值说据点 —— 正是我前一轮亲自修掉的类别错配，**换个分支又回来了**。
- ⚠ 且**三方不一致**：源码注释（`Society.cs:34-37`）与快照注释（`EconomySocietySnapshot.cs:37-42`）
  都还写着"已改名为据点规模"，而语言包已改成"人口规模"。

### 0.5 【P2】影响因子被搬进**规模条** tooltip ⇒ 归属段落错位
- **证据**：`Society.cs:344-352` 把 4 个市场系数塞进规模条 tooltip，并用空行自称"分为两组"。
- **后果**：这四个系数描述的是产能/进口/奢侈/冲击，与"据点规模"无关 ——
  **我上一轮刚指出"chip 悬在两段之间没有归属"，这一轮把它搬进了一个更错的归属里。**

### 0.6 【P2】相邻两面板对**同一供需差**用了**相反符号**
- 市场面板"净值" = `供应 − 需求`（`MarketPanel.cs:161-166,268-273`）
- 社会面板"需求总缺口" = `需求 − 供应`（`MarketPanel.cs:349-355`，本轮新增）
- **后果**：两面板同屏相邻，数字互为相反数、格式都是 `+0.#;-0.#`，**无任何一处说明符号关系**。

### 0.7 【P2】其它自审项

## §1 🔴 P0（既有，2 条）

### 1.1 市场面板：「价格」列与「均价」汇总是**两套算法**
- **行价格** = 运行时市场因子（事件冲击累积，`MarketPanel.cs:179-183`，来自 `WorldComponent_Market.globalFactors`）
- **汇总均价** = `总需求 / 总供应`（`MarketPanel.cs:275-286`）
- 表头写「价格」、汇总写「均价」，读者必然认为后者是前者的聚合 —— 极端情形列内全是 `1.00 ±0%` 而均价 `1.60 ▲+60%`。
- ⚠ 唯一能解释口径差异的脚注被**主动清空**（`MarketPanel.cs:57-62`）。
- **这是"同屏自相矛盾"里最贵的一条**：玩家会据此做交易/生产决策。

### 1.2 KpiGrid：`GUI.BeginGroup` / `BeginScrollView` **不在 finally 内**
- **证据**：`Archive/UI/UIComponents.KpiGrid.cs:106`（BeginScrollView）、`:125`（BeginGroup）、
  `:375`/`:377`（End）—— 两者之间**没有任何 try**；唯一的 `finally`（`:379-383`）只恢复颜色与字体。
- **后果**：任一绘制调用抛异常（RUIF 是外部依赖，`RuifBridge` 全方法带 try 正说明它会抛）⇒
  **裁剪栈与 GUI 组永久失衡** ⇒ 此后所有窗口错位、整帧异常。
- 调用点在**被最多玩家打开的** pawn 检视页（`ITab_Pawn_Chronicle.cs:181`）。

## §3 系统性模式（比单条缺陷更重要）

### 3.1 🔴 **"标签与值脱钩"是本工程的头号缺陷族 —— 今日已第 5 次**
累计：`具体人数→据点规模`、`社会结构占比→成员构成`、`SettlementShare→BarShare`、
`MemberText→MemberCount`，**以及本轮我自己新犯的两条（§0.3、§0.4）**。
📌 **判据**：任何"改名/改语义"的动作，必须**同时**检查：字段名 · 键名 · 段标题 · 注释 · **降级分支**。
本日两次违反都发生在**降级分支**上 —— 主路径改了，`else` 分支没改。

### 3.2 🔴 **"能画出来"≠"能到达"**
截断 43 : tooltip 7；`DataRow`/`RuleBox`/`Chips`/`Price01`/`ColumnTitles`/`FlowNode.DataLevel`
等**填充了却无人读**或**定义了却无调用者**。§0.2 的"影响因子随条一起消失"是同一族。
📌 **判据**：新增一个"出口"（tooltip / 面板 / 挂载点）时，要问**它的前置门禁是什么、门禁关掉后这些数据还有没有别的出路**。

### 3.3 🔴 **隔离范式已存在但未推广**
`ArchiveEmbeddedHost.cs:55-92`（try/catch/finally + 状态捕获 + 记录日志）是**正确范例**，
但 `MasterControl/` 与 `ArchiveMainTabWindow.*` 都没采纳 —— 同一工程两套标准。
📌 **判据**：修完一处崩溃后，**把范式抽成可复用入口**，否则它只会留在那一处。

### 3.4 ⚠ **注释会腐烂，且腐烂的注释比没有注释更危险**
本日已发现 3 处注释与代码相反：
`TierTone` 声称"全主题可辨"（§0.1）、`Scale.Title` 注释说"已改为据点规模"而键值是"人口规模"（§0.4）、
市场表注释说"截断必须配悬停"（`:700-703`）而只对 D2 成立。
📌 **判据**：注释里的"已修复 / 已改名 / 全主题可辨"这类**完整性断言**，必须有测试或注释指向的验证命令兜底。
