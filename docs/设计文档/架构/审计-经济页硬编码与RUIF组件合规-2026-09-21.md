## 1. 结论（两句话）

1. **经济页是全仓唯一「整页图表全部自绘」的页面**（`Widgets.*` 17 处、`RUIF.*` 0 处、`RuifBridge.*` 0 处），违反组件铁律；
2. **`SDD-LCE-003` R5 的豁免理由已过期**：它写「自绘蜡烛/树图无 RUIF 原子」，但 RUIF **v1.3.0 已含 `ChartCandAtoms.Ohlc(Rect, OhlcBar[])`**（`RUIF/Source/Components/ChartCandAtoms.cs:389`）⇒ 蜡烛部分**必须改用 RUIF**；仅**树图布局**（squarified）与**十字线**（RUIF 图表按设计不读鼠标，`Charts.cs:96`）仍无对应。

## 6. 例外登记

| ID | 事项 | 理由 | 失效条件 |
|---|---|---|---|
| **EXC-RUIF-001** | 热力图使用**自持 squarified 布局** | RUIF 无 treemap 原子（全源码无 `Treemap/squarif`）；绘制原语已全部走 `RUIF.Draw`/令牌 | RUIF 提供 treemap 原子，或本页改为 `Charts.HeatmapGrid` 规则网格 |
| **EXC-RUIF-002** | 蜡烛**实体填充/D网格/十字线/tag** 自绘 | `ChartCandAtoms.Ohlc` 无实体、图表族不读鼠标 | RUIF 提供 `CandleChart`（实体 + 网格 + 十字线）后改用 |
| **EXC-RUIF-003** | 热力图**双向色阶**自持（`UITheme.Alive/Dead + WithAlpha` + sqrt） | 已取证：`ChartsFmt.HeatColor(t) = Lerp(Tokens.Card, Tokens.Alive, t)`（`Charts.cs:86-87`）是**单色阶**，无法表达"跌红" ⇒ 语义不符，采用会丢失涨跌方向 | RUIF 提供**双向/发散色阶**（如 `HeatColorDiverging(t)`）后改用 |
| （沿用） | 桌面端无虚线 | IMGUI 能力 | — |
