## 九、核实结论与架构登记（2026-09-15）

### A. 「身份人数趋势」（A1 项）**已核实为 B 类**（附不可做理由）

取证：`ChronicleEventKind = { Other, Death, Battle, Craft, Join, Built, Social }`（`Domain/ChronicleEventDef.cs` 10-20）。

⇒ 事件模型**不含「离档 / 身份变更」语义**（只有 `Join` 入档、`Death` 死亡）。若用 `Join − Death` 回推每季人数：
- 「死亡」≠「离档」（被俘 / 离开 / 转奴都不产生事件）；
- 身份（自由 / 奴隶 / 囚犯）**无变更事件**，三系列无法拆分。

⇒ 按 LAND-009（不编造、不用失真口径冒充史实）**不画该图**，维持 B 类并写明理由。若未来新增 `LeftColony` / `RoleChanged` 事件类型，本项可降级为 A 类落地。

### B. 架构核实：`UICharts` **不是**「归属不当」（先判错误 → 已证伪 → 回退）

**先前判断（错误）**：据「`UICharts` 只被 `MasterControl` 调用、Archive 侧零调用」判定其"归属不当"，建议迁到 `PersonalChronicle.UI`。

**实测证伪**：`using PersonalChronicle.Archive.UI;` 出现在 **77 个文件**中 —— Archive 自身 46 个 · MasterControl 12 个 · `Manufacturing/UI` 13 个 · `Automation` 5 个 · `ChronicleMod.cs` / `ChronicleSettings.cs` 等。⇒ 该命名空间是**全工程事实上的共享 UI 库**（`UITheme` / `UICharts` / `ArchiveUiStyle` 等同类成员共处其中）。

**处置**：已实际执行迁移（移动 + 改 ns）→ **随即回退**。理由：`UICharts` 会成为 `PersonalChronicle.UI` 里**唯一**成员，而其余共享 UI 仍在 `Archive.UI` ⇒ 制造新的不一致；完整迁移需改 77 处 using，代价与收益不成比例。

**真实问题 = 命名历史遗留**（ns 叫 `Archive.UI` / 目录在 `Archive/UI/`，实际是共享库）。**结论：维持现状**；若未来整理，须**整批迁移**（UITheme + UICharts + ArchiveUiStyle + 其余成员）并同步 77 处 using —— 属独立架构任务，不在人员中心范围内。

> **教训**：判定"模块归属"不能只看**调用者是谁**，必须同时看**同命名空间的其他成员**与**全工程 using 分布**；只凭"谁调用"会把**共享库**误判成**越界引用**，进而做出错误的架构改动。（本次因先取证后动手，实际损失为零：迁移→回退→编译 0 错 0 警。）

### I. ⚠️ 实机事故：RUIF 图表组件无法还原预览的「分段语义环」（2026-09-15）

**现象**（用户实机图）：① 身份构成环 → 只画了一段且为**蓝色**、环是**C 形缺口**、环心数字偏左下、副标「在役」落在环底、现役殖民者行位置异常。

**根因（RUIF 组件契约，非本工程 bug）**：

| # | 现象 | 根因（RUIF 侧） |
|---|---|---|
| 1 | 环是**单色蓝**（预览需 自由绿/奴隶红/囚犯黄） | `RUIF.Charts.DonutChart(rect, values, hole01, centerLabel)` **签名里没有 colors 参数** ⇒ 只吃 RUIF 的 **Series 令牌色**，**无法逐段指定语义色** |
| 2 | 环是 **C 形缺口**（不闭合） | RUIF DevDocs 自陈取舍：*"Donut 以**旋转短弧段拼环**"* ⇒ 段与段之间有**固有间隙**；3 段中有 2 段为 0 时，间隙仍占位 ⇒ 视觉缺口 |
| 3 | 环心数字/副标位置异常 | `centerLabel` 的定位由 RUIF 内部按 `hole01` 推导（非 rect 中心），与本工程「数字 + 副标两行」的自定义布局不兼容 |

**⇒ 硬约束**：**RUIF 现有 Charts 组件无法表达"单环多段 + 逐段语义色 + 无间隙"**，而预览正是这种形态。**要求二（必须用 RUIF）与 LAND-001（1:1 还原）在此处直接冲突**，必须裁决。

**可选方案**：

| 方案 | 做法 | 符合要求二 | 1:1 还原 | 代价 |
|---|---|---|---|---|
| **A** | 恢复自研 `UICharts.Ring` | ❌ | ✅ | 违背要求二 |
