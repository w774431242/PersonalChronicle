# Personal Chronicle 殖民地档案馆 · 玩家游戏手册

> 版本：v1.1.4（RimWorld 1.6）
> 定位：一份写给殖民地管理者（你）的"纪传体史书"使用说明书。读完它，你就知道这个模组到底在记录什么、为什么记录、以及哪些数字会变成真实的游戏力量。

---

## 第〇章 · 一句话理解

**Personal Chronicle** 会在你玩游戏的每一刻，静默地记下殖民地里发生的一切——
谁加入了、谁死了、谁造了什么、谁打了什么仗、谁住在哪里、谁又成了某某"大师"。

它不替你决定任何事，只是把事实记成档案。
但有些档案，会反过来给小人真实的加成：**勋章的荣耀、职业的专精、职称的认可。**

---

## 第一章 · 档案馆是什么

### 1.1 入口

启用模组后，游戏主界面底部的标签栏会出现一个 **「档案馆」** 按钮（排在靠后位置，不干扰原版）。
点击它，打开一座四层档案库。

### 1.2 四大类档案

| 分类 | 记录谁 / 什么 | 你能看到 |
|---|---|---|
| **人物** | 每一个殖民者、奴隶、囚犯 | 工时、战斗、社交、足迹、健康、职业、勋章 |
| **物品** | 武器、装备、工坊产物 | 谁造的、谁抢的、谁继承的、它杀过谁 |
| **战役** | 每一场袭击与战争 | 参战双方、关键节点、战果 |
| **地点** | 每一处被访问、被争夺的角落 | 谁长期驻留、谁远征过、谁在此建造/销毁 |

### 1.3 核心概念：事实 ≠ 评价

模组有一条铁律：

> **事实记录只记"发生了什么"，不记"这人有多好"。**

例如，它记"张三在 5510 tick 制造了一件优秀机械部件"（事实），
**不**直接记"张三是优秀工匠"（评价）。
评价，是由职业系统、资格系统、勋章系统**在事实之上**慢慢推算出来的。

这就是为什么：旧档补不回历史——因为事实必须在事件发生的那一刻才被捕捉。

### 1.4 实时记录 vs 历史快照（双轨）

档案馆首页区分两种数据：

- **活读（Live）**：游戏此刻的真实事实（比如当前在场的殖民者）。
- **档案（Archive）**：历史累计的快照记录。

这样能避免把冷冻舱里的人算进"当前人口"，也不会因为临时增援而乱建档。

## 第二章 · 人物档案详解

点开任意一个小人，你会看到一张"六宫格"主面板，以及多个子视图。

### 2.1 六宫格主面板

每一格遵循统一基准：**大数字 + 同行动态指标 + 两行 KPI + 三条固定进度条**（数据为空时显示 `--`，布局不会抖动）。

| 宫格 | 记录内容 |
|---|---|
| **工时** | 生涯累计工时、日均工时 |
| **产出** | 周产出 / 净值、产值构成 |
| **击杀** | 猎物种类、参战战役数、生涯伤害、击杀构成 |
| **损耗** | 累计折银（进食/用药折算）、周/日均、构成 Top3 |
| **足迹** | 主驻地 / 远征、停留地点 Top3 |
| **传承** | 锻造者是谁、传承链上的击杀占比 |

### 2.2 子视图一览

- **概览**：生命阶段、健康残值三维评分、职业快照。
- **编年史**：事件时间轴（加入 / 死亡 / 制造 / 建造 / 战斗 / 社交），点一行可展开描述。
- **生涯**：累计工时（非工作优先级）、劳动强度档位、工作场所与住所（劳模代表）。
- **战斗履历**：击杀边 + 参战名册。
- **社会关系**：恋爱 / 婚姻 / 亲缘的结成与结束（网络图，最多 24 个节点）。
- **足迹**：地点进出履历。
- **健康残值**：肢体 / 精神 / 未衰老三维评分 + 银币估值。
- **职业 / 勋章**：见第三、第四章（职业系统为制造类垂直切片先行）。

### 2.3 劳动强度五档

模组会评估每个人的"牛马程度"（纯函数，阈值由数据驱动）：

| 档位 | 累计工时阈值（约） |
|---|---|
| 核动力驴（T0） | ≥ 12 小时/天 |
| 超级牛马（T1） | ≥ 9 小时/天 |
| 常规牛马（T2） | ≥ 6 小时/天 |
| 劣质牛马（T3） | ≥ 3 小时/天 |
| 社会懒汉（T4） | < 3 小时/天 |

*中途加入的存档，以"模组接入后的天数"为分母计算，绝不崩。*

### 2.4 健康残值估值

模组给每具身体估个价（数据驱动，可被其他 Mod 调整）：

- 基准 1500 银、每年折旧 2%；青春阈值 85、受损阈值 60、下限 50。
- 7 类病症有罚金：哮喘 10% / 驼背 12% / 白内障 8% / 衰弱 15% / 糖尿病 10% / 酗酒 10% / 化学损伤 20%。

## 第三章 · 职业系统（制造类先行）

> 职业系统当前以 **制造类** 作为第一个完整垂直切片，其余 11 个专业（工程/农业/林业/畜牧/医学/武器/矿业/科研/烹饪/艺术/管理）将随各自垂直切片逐步开放。

### 3.1 第一原则：职业 ≠ 原版技能

原版 RimWorld 的"技能（Skill）"是**证据**，不是职业本身。

```
Crafting 16 + Construction 14 + Intellectual 12
        + 你真实做过的制造工作
        + 你造出的成果
        + 你的职业履历
                ↓
        制造类 专业能力
```

> 原版 Skill 是基础能力证据，Professional Skill（专业技能）是模组自己的长期能力模型。

### 3.2 专业四层结构

```
一级专业（12 类之一：制造）
    └── 二级方向（制造类 = 精密 / 武器 / 装备 / 工业）
            └── 专业技能（如：精密制造）
                    ├── 能力维度（加工 / 精度 / 工艺 / 材料 / 质控）
                    └── 专业效果（速度 / 品质 / 配方 / 材料 / 特殊工作）
```

### 3.3 事实层：CareerEvent（职业履历）

每一次真实制造，都会写入一条 **CareerEvent**，记录：

- 谁（PawnId）
- 什么时候（Tick）
- 做了什么（EventType）
- 用的什么配方（RecipeDef）
- 造了什么（ThingDef）
- 什么品质（Quality）
- 造了几件（Quantity）

**职业履历是整个职业系统的"长期事实数据库"**——后面所有评价（能力、评级、资格、职称、勋章）都从它派生，且评价规则改了，历史事实永远不变。

### 3.4 专业能力怎么长出来

你每制造一次，系统按 **「行为 → 能力映射矩阵」** 把经验分给不同能力维度，**不是五维等量增长**：

- 普通武器制造 → 加工 +、工艺 +、质控 少量 +
- 精密机械 → 精度 大量 +、工艺 大量 +、加工 +

能力维度（制造类）：

| 能力 | 含义 | 典型获取 |
|---|---|---|
| 加工能力 | 基本加工操作 | 大多数制造 |
| 精度控制 | 精密操作 | 精密机械、电子件 |
| 工艺理解 | 工艺/流程理解 | 复杂配方、研究关联 |
| 材料应用 | 材料选择与利用 | 高级材料制作 |
| 质量控制 | 品质把控 | 高品质产出/检视 |

### 3.5 经验公式（XP）

```
单次实践 XP =
    基础实践值（默认 10）
    × 配方相关度（匹配 1.0 / 仅工作类型 0.5 / 无匹配 0）
    × 品质系数（普通 1 / 良好 1.2 / 优秀 1.5 / 大师 3 / 传奇 5）
    × 难度系数（首版 1.0）
    × 数量系数（批量产出累加，上限 4）
```

等级提升采用**边际递减曲线**：前期升级快，后期越来越慢，防止数值失控。

### 3.6 二级方向推荐（推荐 ≠ 强制）

系统会按五维算出一个"方向适配分"，给你推荐主修方向：

```
方向分 =
    技能相关度 × 0.35
  + 实践适配   × 0.25
  + 实践质量   × 0.15
  + 成果贡献   × 0.15
  + 专业能力   × 0.10
```

推荐只是建议，你最终想走哪条路，自己选。

### 3.7 专业评级（4 档，由等级派生）

评级**不是**等级，也不是职称。它只是能力水平的一个勋章式标签，**无考试门槛**，由专业等级经软上限曲线自动派生：

| 评级 | 触发等级 | 说明 |
|---|---|---|
| 熟练 | ≥ 10 | 入门档，最低加成 |
| 专业 | ≥ 25 | 中段主力 |
| 高级 | ≥ 38 | 高段 |
| 大师 | ≥ 45 | 顶档，封顶不再增（递减设计） |

> 大师之后等级继续涨，也**不再加加成**——这就是软上限，防止职业数值无限膨胀。

### 3.8 专业效果：从"数据面板"走进"游戏机制"

这是职业系统最关键的一步。专业能力**真实改变**你下一次工作的结果：

- **制造速度**：通过原版 `StatPart` 注入配方的工作速度统计。拥有精密制造技能（等级≥1）且正在制造对应配方时，制造更快。
- **品质倾向**：制造完成后，按专业效果把产物品质**整档偏移**（+1 档起）。

效果全部**数据驱动**，且经三层隔离（Effect → Resolver → Adapter），不直接乱 patch 游戏全世界，安全可关。

> 验收标准只有一句话：
> *玩家看到的不是"制造类 72/100"这个数字，而是"这个人因为真实做过这些工作，所以形成了某种专业能力；专业能力又真实改变了他下一次工作的结果"。*

## 第四章 · 资格、职称与勋章

### 4.1 资格状态机

专业等级**绝不直接等于职称**。要走完一条资格认证流水线：

```
Locked（锁定）
  → Eligible（具备资格）
  → Preparing（准备中）
  → PracticalExam（实践考试）
  → TheoryExam（理论考试）
  → Thesis（论文）
  → Defense（答辩）
  → Qualified（通过）
  → Granted（授予职称）
```

失败会回到 Preparing，而不是删除进度。

### 4.2 五档职称（现实职称体系）

职称挂载在**二级方向**上（如精密制造），分 5 档（由低到高）：

> 员级 → 助理级 → 中级 → 副高级 → 正高级

以精密制造（技能人才通道，技工序列）为例，已落地的 5 档：

| 职称 | 门槛等级 | 生涯时长（tick） | 特殊要求 |
|---|---|---|---|
| 初级技工 | 5 | 60,000 | — |
| 中级技工 | 15 | 200,000 | 前置：初级技工 |
| 高级技工 | 25 | 600,000 | 前置：中级技工 + 考试/论文/答辩（最低分 60/70/80） |
| 技师 | 38 | 1,200,000 | 前置：高级技工 |
| 高级技师 | 45 | 1,800,000 | 前置：技师 + 至少 1 次传奇制造 |

*存档稳定键是 defName，重命名标签不影响旧档。*

### 4.3 考试与论文：在"玩游戏"中完成

模组刻意不做假的"考试按钮"。

- **实践考试** = 真实制造行为证据。报名后，系统要求你在限定时间内制造指定物品 ×N、达到最低品质，你**真实去制造**，系统捕获 CareerEvent 作为证据并评分。
- **理论考试**（阶段一）= 阅读相关书籍 + 研究项目 + 专业能力 + 理论考试活动，加权合成成绩（暂无选择题 UI）。
- **论文** = 由书籍 + 研究 + 专业成果 + 职业履历 + 专家参与共同形成质量，不是"+1 Thesis"。
- **答辩** = 同阵营高专业等级小人自动列为委员，玩家在界面确认/指定，委员会评分。

### 4.4 勋章体系

勋章是**成就的表彰**，分两条路径授予：

1. **阈值勋章**：达到累计指标自动授予（如累计工时、击杀数、产出银、传承代数）。
2. **成就勋章**：由 CareerEvent 聚合出的成就键（如传奇制造次数、大型项目数、已获职称数）触发。

**勋章材质与增益阶梯**（数据驱动）：

| 材质 | 增益（通道 A 已规划 / 通道 B 展示先行） |
|---|---|
| 铜质 | +3% |
| 银质 | +5% |
| 金质 | +10% + 殖民地公告（Letter） + 专属「·金质」后缀 |

勋章分系（部分示例）：

- **劳动系**：劳动模范、先进工作者、生产技术能手
- **战斗系**：战斗英雄、一等功、入伍表彰
- **后勤系**：模范供应员、勤俭标兵
- **传承/装备系**：传承功勋、镇库之锋
- **团体系**（工坊）：先进集体、模范集体
- **排名/荣耀系**（依赖期结算）：劳模标兵、英雄模范

> 授权闭环：职业行为 → 能力 → 成果 → 资格 → 职称 → 贡献 → **勋章**，最终回写 CareerEvent，形成完整事实闭环。

## 第五章 · 物品、战役与地点档案

### 5.1 物品 / 装备档案

- 概览 · 编年史 · 战斗履历 · 流转记录 · **传承链**（谁造的 / 谁抢的 / 谁继承的）。
- 武器始终捕捉；服装按护甲阈值 ≥ 0.20 判定为战斗服装（数据驱动，可被外部 Patch）。
- 装备归档政策由 `ThingArchivePolicy.xml` 定义。

### 5.2 战役档案

- 战役生命周期（开始 / 突袭次数 / 结束三 Hook）、参战双方、关键节点与战果。
- 击杀按派系聚合、去重；个人"参战战役"指标保留在击杀宫格。

### 5.3 地点档案与别名系统

- 实时地点 / 持有者 / 访问聚合（地点地图志）、远征与主驻地。
- **建筑别名**：全局别名 > 个人自定义名 > 原版标签，三级解析。
- **房间角色别名**：同样支持改名。
- 通用改名对话框工坊实例 / 房间共用；DLC 感知（如 Anomaly 活跃 / 亚人类判定）。

## 第七章 · 界面与主题

### 7.1 设计系统

所有界面走两层设计系统：

- **UITheme（令牌层）**：4 套可换肤预设——`epic / gothic / wuxia / steampunk`，只换颜色不换布局，选择持久化。
- **UIComponents（组件层）**：卡片 / 标签 / 进度条 / 阴影文字 / 可点击卡片等可复用绘制单元。

### 7.2 自定义规则

- 中文行高有规范（大卡 ≥ 110 / 小字 ≥ 18），保证中文不挤。
- 所有玩家可见文字走翻译键，跟随游戏语言（简体中文 / English）自动切换。

## 第八章 · 安装与兼容

### 8.1 安装

1. 把整个 `PersonalChronicle` 文件夹放进游戏的 `Mods` 目录。
2. 启动 RimWorld，在 Mod 列表启用 **Personal Chronicle - Archive**。
3. 确保 **Harmony** 已启用且在本模组之前加载。
4. 进入游戏，主界面底部出现「档案馆」按钮即成功。

### 8.2 依赖与兼容

- **版本**：RimWorld 1.6。
- **必需依赖**：仅 Harmony（唯一外部依赖）。
- **语言**：内置简体中文与 English。
- **平台**：Windows / macOS / Linux 均可。
- 与 Character Editor 等 Mod 共存；纯只读记录，不修改游戏核心机制。

### 8.3 存档说明（重要）

- **想要 100% 完整档案，请新开档。** 模组是"实时事件采集"，启用前发生的事补不回来。
- 中途加装也可用：当前在场人口会自动建档，只是缺"加装前的历史"。
- 早期存档会自动迁移到最新对象模型（无损升级）。

## 第九章 · 常见问题

**Q：中途加装老档，已经存在的人会被认出来吗？**
A：会。模组加载时自动为当前全部人口建档，老成员不会被当成"新人"，只是他们的"加入事件 / 历史时间线"是空的。

**Q：会拖慢游戏吗？**
A：不会明显变慢。事件流采用 120-tick 节流刷新，后台仅做轻量补漏建档。

**Q：职业加成会不会破坏平衡？**
A：所有加成 ≤ 10%，且有软上限封顶（大师后不再增长）。能力必须经真实工作积累，无法速成。

**Q：勋章的金色公告会刷屏吗？**
A：不会。金质勋章公告只弹一次（去重）。

## 第十章 · 概念速查表

| 概念 | 一句话 |
|---|---|
| CareerEvent | 职业系统的"事实数据库"，只记发生了什么 |
| Professional Skill | 模组自己的长期能力模型，由原版技能 + 真实行为共同养成 |
| Ability（能力维度） | 技能拆出的细分能力（加工/精度/工艺/材料/质控），独立成长 |
| Rating（评级） | 由等级派生的 4 档标签（熟练/专业/高级/大师），无考试门槛 |
| Qualification（资格） | 通往职称的认证流水线，含考试/论文/答辩 |
