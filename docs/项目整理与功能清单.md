## 3. 架构分层（单向依赖）

```text
      Archive（UI 层，26+3 文件）
            │
      Application（编排层，15 文件）          Api（对外契约，15 文件）
            │                                     │
      Domain（纯逻辑，40 文件）  ←—  Data（持久化，5 文件）
            ▲
      Capture（Harmony 钩子，16 文件，只转调 Service）
```

| 层 | 目录 | 职责 |
|---|---|---|
| 根 | ChronicleMod.cs 等 3 文件 | Mod 入口（Harmony 初始化、主题应用、API 注册）、ModSettings、统一日志 |
| Domain | Domain/ | 纯逻辑领域模型：Pawn/Thing/Battle/Location 档案对象、事件模型、工时强度、累计器、快照、勋章、职业/资格/荣誉 |
| Application | Application/ | ArchiveService（partial：Work/Production/Consumption/Battle/Social/Location/Live/Career/Qualification）、授勋服务、效果服务 |
| Data | Data/ | ChronicleGameComponent（partial：主文件/Sampling/Aliases/Queries）：Scribe 存档、采样、别名表、查询 |
| Capture | Capture/ | Harmony 捕获钩子（16 个，见 §4.1）+ 职业效果适配层（StatPart 注入、品质覆盖） |
| Archive | Archive/ | 主窗口 ArchiveMainTabWindow（20 个 partial）、ITab×2、Dialog×2、ReadModel 快照（4 partial）、UI 设计系统（UITheme/UIComponents） |
| Api | Api/ | 对外门面 PersonalChronicleApi + Provider 注册表 + 4 个领域 Provider 契约 + 内置实现（第三方 mod 无侵入扩展） |
| Tests | Tests/ | Domain 纯逻辑离线单测（NUnit，不依赖游戏运行） |

## 4. 功能清单

### 4.1 事件采集引擎（Capture，16 个 Harmony 钩子）

| 钩子 | 捕获点 | 记录内容 |
|---|---|---|
| Patch_PawnKill | Pawn.Kill | 击杀、传承链 |
| Patch_PawnTakeDamage | Pawn.TakeDamage | 伤害累计（参战/生涯伤害） |
| Patch_BillProduction | Bill_Production.Notify_IterationCompleted | 工坊使用采样（劳模工坊） |
| Patch_ThingIngested | Thing.Ingested | 损耗累计（食物/药品/成瘾品折银） |
| Patch_ThingDestroy | Thing.Destroy | 物品/地点销毁事件 |
| Patch_SetFaction | Pawn.SetFaction | 派系变更记录 |
| Patch_Relations | Pawn_RelationsTracker.Add/RemoveDirectRelation | 社交关系变更 |
| Patch_RaidLordPawnLost | Lord.Notify_PawnLost | 突袭领主流失 |
| Patch_IncidentWorker | IncidentWorker.TryExecute | 事件捕获（战役扩展） |
| Patch_GenRecipe | GenRecipe.MakeRecipeProducts | 制作产出 + 职业 XP/品质偏置 |
| Patch_GenConstruct | Frame.CompleteConstruction | 建造完成 |
| Patch_BuildingLabel / Patch_RoomRoleLabel | Thing.Label / Room.GetRoomRoleLabel | 建筑与房间别名解析 |
| LocationAtlasCapture / IncidentBattleExtension / CapturePatchDiagnostics | — | 地点图谱辅助 / 事件↔战役关联 / Patch 绑定诊断 |

已定义 6 类事件 Def：**Join / Death / Crafted / Built / Battle / Social**（文案全走翻译键，缺失优雅降级）。

### 4.2 档案馆主界面（MainButton「档案馆」，order 78）

- **总览 Home**：分类统计卡片 + 最新 5 条事件流（120-tick 节流刷新）+ KPI 仪表盘。
- **概览 Overview**：人物/物品/战役/地点四大分类卡片网格，点击钻取详情。
- **详情 Detail**：事件时间轴 + 关联档案网络（主/从对象互跳：制造者↔物品、死者↔凶器）。
- **活读双轨 Live Stats**：首页区分「当前殖民者（游戏实时事实）」与「档案记录（历史快照）」，避免冷冻舱虚高计数。
- **阵营图鉴**（v4.3）：敌友关系与关键事件。
- **检视页签**（v4.6）：pawn 检视面板直接打开档案（ChronicleInspectTabInjector 注入 2 个 ITab）。

### 4.3 人物档案（六宫格 + 子视图）

- **六宫格统一基准**（v1.1.4）：大字 + 同行指标 + 2 行 KPI + 固定 3 条进度条（空态 -- 占位，无布局抖动）：
  - 工时（生涯累计工时、日均）、产出（周产出/净值、产值构成）、击杀（猎物种类、参战战役/生涯伤害、击杀构成）、损耗（累计折银、周/日均、构成 Top3）、足迹（主驻地/远征、停留 Top3）、传承（锻造者、传承链击杀占比）。
- **概览**：生命阶段、健康残值三维评分、职业快照。
- **编年史**：事件时间轴（加入/死亡/制造/建造/战斗/社交）。
- **生涯**：累计工时（非优先级）、劳动强度档位、工作场所与住所（劳模代表）。
- **战斗履历**：击杀边 + 参战名册。
- **社会关系**：恋爱/婚姻/亲缘结成与结束（网络图，上限 24 节点）。
- **足迹**：地点进出履历。
- **健康残值**：肢体/精神/未衰老三维评分 + 银币估值（见 §4.10）。

### 4.4 物品/装备档案

- 概览 · 编年史 · 战斗履历 · 流转记录 · **传承链**（谁造的/谁抢的/谁继承的）。
- **装备归档政策**（ThingArchivePolicy.xml）：武器始终捕捉；服装按护甲阈值 ≥0.20 判定战斗服装，支持硬黑名单（Def 驱动，可被外部 Patch）。

### 4.5 战役档案

- 战役生命周期（StartTick/RaidCount/EndTick 三 Hook）、参战双方、关键节点与战果。
- 击杀按派系聚合（图鉴卡片）、击杀去重；IncidentBattleExtensions.xml 扩展事件↔战役关联。
- 个人「参战战役」指标保留在击杀宫格。

### 4.6 地点档案与别名系统

- 实时地点/持有者/访问聚合（地点地图志）、远征与主驻地、物品建造/销毁钩子。
- **建筑别名**：全局别名 > per-pawn 自定义名 > DefLabel 三级解析；**房间角色别名**。
- 通用改名 Dialog（Dialog_RenameWorkplace，工坊实例/房间共用）；DLC 感知（Anomaly 活跃/亚人类判定）。

### 4.7 工时强度五档（Def 驱动）

- 五档：**核动力驴 / 超级牛马 / 常规牛马 / 劣质牛马 / 社会懒汉**（T0~T4，阈值 12/9/6/3 小时，最小采样 5 天）。
- 纯函数评估（WorkIntensityEvaluator）+ 对外 Provider 契约（WorkIntensityContracts.cs）；中途加入存档以「mod 接入后天数」为分母回退，不崩。

### 4.8 生产与损耗账本

- **生产**：产出汇总/按类目聚合/周产出/净值；「榨取总账」与「产出核销」。
- **损耗**：进食/用药经 Thing.Ingested 捕获，按物品基价折银累计（日桶 + 类目聚合，不写高频事件流）。

### 4.9 装备传承链

- 所有权变更链（HolderRecord 节点）+ 退役/拆解记录（DecommissionRecord）；神器传承宫格展示各代击杀占比。

### 4.10 健康残值估值（Def 驱动）

- 基准 1500 银、年折旧 2%、青春阈值 85 / 受损阈值 60、下限 50；7 类病症罚金（哮喘 10% / 驼背 12% / 白内障 8% / 衰弱 15% / 糖尿病 10% / 酗酒 10% / 化学损伤 20%），可被外部 Patch 调整。

### 4.11 社会关系网络

- 直接关系白名单（Lover/Fiance/Spouse/ExLover/ExSpouse/Parent/Child/Sibling/HalfSibling），排除动物羁绊；推导亲属 + 好感度朋友/宿敌（±20，上限 8）；Royalty 头衔与身份映射文档。

### 4.12 勋章体系（Def 驱动，31 枚）

- **阈值勋章 27 枚**（劳动系/战斗系/后勤系/传承系 × 铜银金）+ **成就勋章 4 枚**（传奇制造 Bronze/Silver/Gold、重大项目 Gold）。
- 三档 Buff：工作速度 +3%/5%/10%、战斗 +3%/5%/10%（MedalBuffDef，Hediff 注入 + 金质公告 Letter）。
- 评估纯逻辑（阈值/成就双路径）+ 手动授勋 Dialog + 勋章墙（最高档归并）；授勋回写 CareerEvent(MedalGranted) 闭环。
- 勋章贴图：Textures/Medals/（中文名 png 实存；英文 defName 名贴图在 _backup，见 §9 注意项）。

### 4.13 职业档案系统（制造类垂直切片，P1~P8 已落地）

- **12 个一级专业框架**（工程/制造/农业/林业/畜牧/医学/武器/矿业/科研/烹饪/艺术/管理，前端原型已定，C# 待各垂直切片落地）。
- **精密制造（首个完整闭环）**：Manufacturing_Precision 方向 + ProfessionalSkill_PrecisionManufacturing 技能（源技能 Crafting+Intellectual；练习配方 Make_ComponentIndustrial/Spacer；xpPerPracticeBase=10、xpCap=5000、maxLevel=50）。
- **事实层**：CareerEvent（5 种白名单 + 4 种 DISCLOSE 事实事件）→ CareerData（append-only 挂 PawnObject，不 bump schema）；制造采集点 = Patch_GenRecipe → RecordCareerProduced。
- **XP 公式**：基础 × Recipe 相关度 × 品质系数 × 难度 × 数量，与游戏加成分离；边际递减等级曲线。
- **能力矩阵**：4 能力（加工/精度/工艺/质控）+ 权重映射（AbilityMappingDef）；五维方向评分（基础 0.35/实践 0.25/兴趣 0.15/成果 0.15/成长 0.10）。
- **评级 4 档**（熟练/专业/高级/大师，阈值 10/25/38/45，由 Level 派生，无考试门槛）：效果叠加 value×(1+weight)，Def 缺失回退 P3 行为。
- **效果系统三层**（Def → Resolver 纯函数 → Service → RimWorld 适配）：工作速度 StatPart 注入（+3% 起）+ 品质整档偏置（Postfix 覆盖）；ProfessionalEffectRegistry 启动期索引注入、去重。
- **UI（2026-08-16 高度还原 HTML 原型）**：独立 ITab_Pawn_Career（总览/履历/勋章 3 子页，对齐预览文件）：顶部身份卡（职业徽章/姓名/职业规划/职称/资历）、总览页含职业规划 12 专业适配分析 chips（ProfessionalFitAnalyzer 纯逻辑 + 单测）、职业身份/资格状态/预检/下一职称、简历式履历（resume-block + 工坊汇总 + 当前就职）、勋章墙（图标/档位角标/详情 Dialog/＋授勋复用 Dialog_ManualMedalAward）+ 荣誉贡献结构 + 最近荣誉事件；Tab 尺寸自适应屏幕（上限 640×720，低分辨率自动收缩）；DevMode 随机化测试按钮保留；勋章图标经 MedalDef.iconPath 数据驱动（3 枚劳动模范配图，其余档位色占位）。

### 4.14 资格与职称体系（P5~P8 已落地）

- **资格状态机**：Locked → Eligible → Preparing → PracticalExam → TheoryExam → Thesis → Defense → Qualified → Granted（失败回 Preparing）。
- **5 档职称**（国内现实职称体系，二级方向级挂载）：员级 → 助理级 → 中级 → 副高级 → 正高级；精密制造落地为**初级技工 → 中级技工 → 高级技工 → 技师 → 高级技师**（门槛等级 5/15/25/38/45 + 生涯时长 60000/200000/600000/1200000/1800000 tick + 前置职称串联；高级技工起要求考试/论文/答辩 + 最低分 60/70/80；高级技师要求传奇制造 ≥1）。
- **证据机制**：实践考试=真实制造行为（复用 ItemProduced 采集点）、理论考试=加权合成评分、论文/答辩=书籍证据 + 同阵营高等级自动委员；资格自动授予 autoGrant 开关；存档稳定键=defName（label 重命名不动 defName）。

### 4.15 UI 设计系统

- **UITheme 设计令牌**（Layer 1）：4 套可换肤预设 **epic / gothic / wuxia / steampunk**，主题 ID 持久化（ChronicleSettings.ThemeId），只换色不换布局。
- **UIComponents**（Layer 2）：Card / Pill / ProgressBar / ShadowLabel / ClickableCard 等可复用绘制单元。
- 中文行高规范（大卡≥110 / StatCell≥64 / 小字≥18）；Font/Anchor/GUI.color 配对恢复铁律；窗口只消费 IArchiveUiDataProvider 快照。

### 4.16 第三方 API 契约（Api 层）

- PersonalChronicleApi.TryGet 门面 + Supports 能力探测 + Providers.Register 注册表（异常隔离，单 Provider 失败不影响整体）。
- 查询契约 IArchiveQueryService（建筑/房间别名等）、写入契约 IArchiveEventSink（TryRecord 去重）。
- 4 个领域 Provider：Battle / Place / Production / Relation（接口 + 内置实现），第三方 mod 可无侵入扩展采集与能力。

### 4.17 存档与兼容

- ChronicleGameComponent：Scribe 全量持久化 + SchemaVersion 迁移（当前 v5，早期存档无损升级）。
- **中途加入兼容**：读档 BackfillExistingColonists 自动为当前自由殖民者/奴隶/囚犯建档；人口计数只用 MapPawns Spawned 精选列表（防冷冻舱虚高）。
- **双轨统计**：live（活读游戏事实）+ archive（快照历史）；reconcile 带确认窗防临时增援误建档；120-tick 采样节流，性能友好。
- 纯只读记录，不修改游戏机制；与 Character Editor 共存（LanguageInfo.xml 中文语言身份）。

### 4.18 本地化与发布

- 中/英双语言，所有用户可见文案走 Keyed 翻译键（无硬编码中文）；DefInjected 覆盖分类/主按钮。
- Steam 工坊更新说明与前置依赖文档；发布区白名单同步工作流（dll + 改动翻译键 + Defs/Patches + About）。
