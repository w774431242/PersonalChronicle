## 玩家可见行为

默认开启；入口为 Mod 设置 → 界面 → Pawn 需求聊天气泡。人物头顶显示短句，随人物移动，淡入淡出。每条持续 4.5 秒真实时间，暂停时也会消退；当前地图最多 4 条，新气泡至少间隔 0.75 秒真实时间。世界地图界面隐藏气泡。绘制不接收点击，重叠时向上避让，屏幕边缘放不下则暂不绘制。

| 需求 | 普通缺口台词 | 开始相应任务时的台词 |
| --- | --- | --- |
| 饥饿 | 肚子有点饿了。 | 好饿啊，先吃饭了。 |
| 疲劳 | 有点困了，想歇一会儿。 | 好困啊，先休息一会儿。 |
| 娱乐 | 一直忙着，想找点乐子。 | 放松一下，玩一会儿。 |
| 舒适 | 有点不舒服，想找个舒服的地方。 | 无 |
| 户外 | 待在屋里太久了，想出去透透气。 | 无 |

另有严重缺口台词。行动台词必须对应当前进食、躺下休息或带有 joyKind 的娱乐任务；进食目标必须具有营养。台词表达正在执行该任务，不保证该任务最终成功。已睡着、征召、倒地、精神失常和执行玩家强制任务的人物不显示。首版限地图上可见的自由非奴隶人类殖民者，婴儿排除。

## 触发与边界

读取既有感知缓存的 Needs 组，以统一的 CurrentNeedProjector 验证数值比例。未采集、超过 300 tick、未来数据、无法支持的语义、隐藏需求及明确冻结的读数不产生台词。原版冻结状态在当前采集器中仍为 Unknown；此功能仅过滤明确为 true 的冻结事实，不能宣称已适配所有冻结情况。

以下仅为气泡表现阈值，不改写生活规划目标、需求数值、作息表、账户或任务；此功能不提高需求下降速度。

| 需求 | 进入缺口 ≤ | 恢复并重新允许触发 ≥ | 严重 ≤ |
| --- | ---: | ---: | ---: |
| Food | 0.30 | 0.55 | 0.10 |
| Rest | 0.28 | 0.55 | 0.10 |
| Joy | 0.25 | 0.50 | 0.10 |
| Comfort | 0.25 | 0.50 | 0.10 |
| Outdoors | 0.20 | 0.45 | 0.05 |

同一持续缺口只报一次普通阶段、一次严重阶段、一次行动阶段。普通跨需求台词有 1200 tick 人物冷却；严重升级和行动阶段至少间隔 300 tick。人物冷却与地图并发限制同时适用。未获得显示名额的候选不会消耗触发机会，但持续很短的行动可能在轮询或冷却期间结束，首版不保证捕获每一次任务开始。

每 5 tick 最多处理 8 个已观察人物，人物状态最多 4096 条。表现记忆归属于当前 GameComponent，不写入存档；读档、感知会话变更、时间回退或关闭功能后重建。长期离开观测范围的记忆定期裁剪。

## 验证结果

- 发布构建成功；开发过程中曾遇到一次 DLL 文件映射占用重试，最终构建日志与状态记录在 verification.json。
- 22 项新增触发测试通过：阈值、迟滞、升级、真实行动类型匹配、去重、抑制、陈旧和无效读数、优先级、人物隔离、时间回退、整数溢出。
- 全量离线回归：1254 项通过、1 项既有测试跳过、0 项失败。
- 两种语言的 16 个键集合一致，XML 可解析。
- verification.json 保存构建、源文件和测试报告校验值；deployment.json 记录实际部署及备份结果。

CodeVerified：是。GameVerified：否。离线验证没有运行游戏 GUI；阈值与显示节奏尚未实机调优。

## 游戏验收清单

部署后重启 RimWorld。普通存档与已有长期存档分别验证：

1. 让有 Food 需求的殖民者降至 0.30 以下，出现饥饿短句；继续等待时不反复刷屏。
2. 人物开始有营养食物的 Ingest 任务，满足显示名额与冷却后出现“好饿啊，先吃饭了”；饮用无营养物品不出现该台词。
3. 食物需求恢复至 0.55 以上再降至 0.30 以下，重新允许触发；在 0.30 左右波动不重复。
4. 测试疲劳、娱乐、舒适和户外缺口，以及严重阶段；留意开始睡眠很快的休息任务可能只出现缺口台词。
5. 密集站位、多种缩放、不同 UI 比例、英文长文本、屏幕边缘：文字可读、避让、跟随、选择人物和拖框不受影响。
6. 征召、倒地、精神失常、强制任务、睡眠、地图切换、战争迷雾、世界地图和读档：无错误提示、无悬空或跨地图气泡。
7. 关闭开关后立即隐藏气泡，重开恢复；重启游戏后开关保留。与其他聊天气泡 Mod 共存时检查视觉重叠。
8. 大殖民地观察帧率与 Player.log；没有实测性能数据前，不宣称已完成性能验收。
