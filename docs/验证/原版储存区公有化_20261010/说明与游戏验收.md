# 原版储存区公有化开关

> doc-id: DOC-VERIFY-20261010-VANILLA-STORAGE
> status: new
> supersedes: —
> approved: 2026-10-10 19:00
> author: AI（并行会话）

原版储存区保持原有绘制、优先级、筛选、复制和扩区功能。选中储存区后新增“公有化”开关；开启后出现“设置食品售价”按钮，检查栏显示公有状态和食品售价。

新建储存区与旧存档默认关闭。公有化开启时，当前无主物资和后续存入的无主物资登记为公有。已有私有物资（包括已付款食品）不转移归属，自动搬运也不会把私有库存送进公有储存区。公有库存转入另一个公有储存区或物资架时采用目的地报价。

食品报价默认是“未报价／暂停食品供应”；需设置正售价。启用经济制度时，pawn 自动寻找可达且能支付的食品，实际份额通过现有 M11 结算后进食。开关、库存观察和规划不会创建账户或补发资金。经济制度关闭时，公有食品继续原版免费进食，私有食品仍受所属人物保护。

关闭公有化只停止后续物资登记。关闭、缩区、删区、搬出或拆分都不会清除已有公有归属；关闭后再打开保留已设置的售价。开关和售价保存在当前原版储存区内部，普通存储设置的复制不复制公有化设置。

## 游戏验收（尚待确认）

1. 重启游戏、读取现有存档，选择原版储存区：公有化默认关闭，原版按钮和筛选正常。
2. 放入食品，开启公有化并设价；有足够资金且制度 Active 的 pawn 自动取食，账目显示对应份额支出且没有重复收费。
3. 钱不足、制度未就绪或未设报价时，pawn 不直接免费吃公有食品；自己的私有食品仍可正常食用。
4. 扩区覆盖食品与新搬入食品均受同样规则约束；关闭、缩区、删区或搬出后，已登记公有食品仍需付款。
5. 保存、退出并重读：开关、报价和物资归属保持；未启用的其他储存区不受影响。
